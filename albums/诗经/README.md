
## 三、创作纪律

1. **只唱原文**：歌词=《诗经》原文，别字版仅供模型咬字，标注版供人看唱；
2. **曲风按心境**：悲=art rock、愤=金属/工业、欢=reggae/EDM（沿用楚辞 §11）；
3. **结构标签**：`[段落类型 · 段落名 · 情绪 | 乐器 · BPM]`，一首 4 遍全诗为基准；
4. **配器**：电琵琶+古筝+竹笛（东）对 电吉他+贝斯（西）；重金属/民谣金属为风卷基调；
5. **交付**：mp3 192k + 双版词 + 生成记录 + 封面；不删不破坏，版本追号。

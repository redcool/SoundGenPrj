## 设计说明

1. **4 遍全诗**：P1 清冷建立 → P2 失真推进 → P3 双踩狂烈 → P4 半速苍凉收束；
2. **副歌** = “关关雎鸠，在河之洲 / 窈窕淑女，君子好逑”，每遍收尾回唱，终章叠唱两次；
3. **主奏**：电琵琶与古筝承担主题与对答，电吉他副奏在 P2 起加入失真，贝斯全程低音锚；
4. **间奏**：琴瑟对答（电琵琶 ↔ 电吉他）置于 P1 与 P2 之间；
5. 别字版供模型，标注版供人看唱；两版逐行同构。

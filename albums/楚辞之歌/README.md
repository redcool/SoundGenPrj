# 楚辞之歌 · 系列总册

> 系列定位：**楚辞原典谱曲**——为《楚辞》这部"伟大的作品"本身谱曲、歌唱。
> 独立于"历史摇滚·人物传记"系列（义名之歌/恶名之歌）：那边唱的是**人物故事**，这边唱的是**楚辞原典/文学意象**。
> 风格根基：摇滚为底座，楚声为魂（参见 docs/history-rock/风格配器库.md §9 楚辞启示录）。

## 一、为什么是"一组专辑"

楚辞不是单篇，是**一部总集**（王逸《楚辞章句》十七卷：屈原七篇 + 宋玉《九辩》《招魂》 + 汉人拟骚八篇）。
按篇目规模与情绪气质，拆成 **8 张子专辑**，一张专辑 = 一个意象域：

## 二、创作纪律（在 §9 楚辞启示录之上）

1. **以原典为骨**：歌词尽量贴合楚辞原文语料，但不整篇照搬（上古词不易唱懂）；方法——原文意象+现代白话骨架，经典原句作 hook（呼唤式），参考《求索》样板。
2. **"兮"即呼吸**：兮是拖腔记号，不唱成实词；兮式拖腔点缀在副歌句尾（§9-4）。
3. **乱曰收尾**：长诗末"乱曰"是天然的 Final 爆发段，终曲双倍气势（§9-2）。
4. **意象锤**：每篇抓一个核心意象（香草/美人/昆仑/湘水/魂魄…）反复锤（§9-3）。
5. **时长**：短篇按 3:30-4:10 抓耳版 + 4-7 分钟叙事版双档（沿用"每角色 4 曲制"思想，此处为"每篇 2 档"起点）。
6. **每篇至少 2 版（双风格变体）**：v1a/v1b 差异化 ≥2 维，规则同风格配器库 §0。
7. **不删不破坏**：版本追号 v2/v3…，废弃版标注保留。
8. **出品目录**：output/chuci/（与 output/history-rock 分离）；交付 mp3 320k + 歌词 + ABC + 曲谱HTML 四件套。
9. **易字/别字守则（2026-10-16 用户确立）**：面向 YuE2 中文咬字——**字音优先、双版本隔离**。
   - **别字版（音频专用，最高优先）**：生僻字→**同音同调**的常用别字（毂gǔ→古、殪yì→义、枹fú→扶、怼duì→对、躐liè→列…）。原理：YuE2 对高频字的音绑定牢，唱“古”即得 gǔ，正好命中“毂”的正确读音——**只动音、不动句、不动兮位**；声调必须一致，否则误导模型。
   - **易字版（兜底）**：换不出同音同调时，退而求其次→常用同义/近义字（毂→轮、殪→倒），只动字不动句。
   - **③拆解**：通假/异体→通行简体（被→披、反→返、霾→埋）；长句可拆双四字句保兮位。
   - **双版本隔离**：别字版**只喂模型出音频**；歌词卡/字幕/曲谱**一律用原文正字**——声音取别字的准，文字取正字的美，两头不亏。
   - **判定标准**：一句里凡需查字典的字全部处理；金句/全熟句（路漫漫其修远兮、魂兮归来）纹丝不动。
   - **逼近闭环**：生成→试听→圈出咬错的字→换成更贴的同音别字→再生成，逐轮收敛（结果记入 docs/楚辞/楚辞篇目档案.md 的试验记录）。
10. **歌词双版交付规范（2026-10-16 用户确立）**：每首楚辞**固定两份词稿、两种消费者**——
   - **标注版（给人看/唱）**：正字 + 注音 + 释义，命名 `《篇目》_annotated.txt`（示例：歌名 + 注音 + 每句白话释义）；人看得懂、读得出、唱得动。
   - **别字版（给模型读）**：同音同调高频字唱词，命名 `《篇目》_v{n}bienzi_lyric.txt`（v2 起按"更常见同音字"逐轮逼近）。
   - **交付联动**：音频只认别字版；歌词卡/字幕/曲谱用标注版正字；两版同目录归档、meta 记录对照表。
   - **版本策略（2026-10-16 试听定论）**：主攻方向定为**别字版逐轮逼近**（音映射表，可收敛）；易字版仅兜底，不追高。
11. **歌词结构标签（2026-10-17 用户确立）**：每首歌词按段落标注 `[段落类型 · 段落名 · 情绪 | 乐器 · BPM]`，情绪/乐器直接写进标签——
   - 例：`[Verse 1 · 身世自矜 · 自矜/悲 | 竹笛+古筝+电琵琶 · art rock 72bpm]`、`[Chorus · 长太息 · 悲恸/愤 | 全奏+齐唱 · 112bpm]`；
   - 段落类型：Intro / Verse / Pre-Chorus / Chorus / Bridge / Interlude / Outro；副歌回唱只留标签+“回唱原词”，不重复写词；
   - 标注版与别字版**逐行同构**（同段落、同行数）；标签若被模型唱出，改用无标签版词稿；
   - 规范详见 `docs/楚辞/歌词结构标签规范.md`；原文底本（史料/离骚*.md）保留无标签作行号锚点。

## 三、命名规则

- 专辑目录：albums/楚辞之歌/<NN>-<专辑名>/（NN 为总册序号，稳定排序）
- 单曲文件：《篇目名》_卷属_版本_yue2，例：《国殇》_九歌_v1a_yue2.mp3
- 词稿：input/lyrics/chuci/<篇目>_<版本>_lyric.txt / _style.txt / _meta.md
- 封面：albums/楚辞之歌/<NN>-<专辑名>/封面/<篇目>_封面.png；专辑封面 <专辑名>_专辑封面(_800).png

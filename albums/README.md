# albums/ · 专辑发布包（历史摇滚系列）

> 发布流程：agent 组装本目录 → 用户拿去平台上架（喜马拉雅 / 汽水音乐 等）。

## 布局规范

```
albums/<专辑名>/
├─ 专辑信息.md      # 曲目表 + 发行信息（每张专辑必须有）
├─ 专辑文案.md      # 发布文案：名字/意境 + 标签 + 卖点 + 简介 + 发布清单（跟随专辑移动）
├─ 歌词/            # 每曲 _lyric / _style / _meta
├─ 封面/            # 单曲封面 + 专辑封面（独立概念图，统一 ignis gpt-image 生成、中文标题/歌名）
│                     # 专辑封面命名：<专辑名>_专辑封面_v{n}_{引擎}.png（如 v2_gptimage；1024 + _800 上架用）
│                     # 单曲封面命名：<歌名>_朝代_年代_人名.png（1024 + _800）
│                     # 旧版（Agnes）改名 _v1_agnes 留档不删
└─ 歌曲/            # 每曲 v1/v2… mp3(320k) + 四件套

> 专辑文案主档 = albums/<专辑名>/专辑文案.md（唯一存放处，随专辑发布包走）。
```

## 命名与规模

- 专辑名：`义名之歌-<朝代>-卷N` / `恶名之歌-<朝代>-卷N`（卷号朝代内从 1 起；一个时期可多张；次代重启）
- 规模：**10 首/张**为标准；EP 级 3-5 首亦可（恶名卷常偏薄属正常）
- 单曲：`歌名_朝代_年代_人名`（故事/封面/词/风格/meta 同名同构）
- 版本：`歌名_朝代_年代_人名_v{n}_{引擎}.mp3`

# 渲染引擎：yue2.cpp（YuE2-Studio 引擎）接入记录（2026-10-20）

## 为什么 ComfyUI 慢（已查证）
- ComfyUI-FL-YuE2 = PyTorch/Transformers 实现：2-pass（语义+声学）自回归解码 3B，planning full（额外一遍计划）+ acoustic_steps 32（midpoint solver）+ 每曲节点实例化/模型重载 + 360s → **实测 15-25 分钟/版**。

## yue-server（yue2.cpp）直连
- 引擎：H:\AI\YuE2-Studio-3.6.0-portable-windows-x64\resources\yue2-cpp\yue-server.exe（C++/CUDA，GGUF Q8 权重 3.5GB）
- 启动：`yue-server --model data\models\yue2-cpp\YuE2-3B-Q8_0.gguf --vae data\models\yue2-cpp\YuE2-Vae-F32.gguf --port 8091 --keep-loaded`（后台常驻，logs/）
- API：`POST /synth {style, lyrics, seed, id}` → `{id}`；轮询 `GET /job?id=<id>&result=1` 直到 200 → **multipart/mixed**（application/json 元数据[含 abc 谱面]+ audio/mpeg）
- 实测：弹谤别字版 → **206s/版**（≈3.4 分钟），产出 mp3 360s·48k 立体声·128kbps + ABC 谱面；用户 Studio 实测 ~1 分钟（更短时长/更优默认）
- 分轨/谱面：abc 含 Vocal Melody；flac 母带落 Studio temp（audio-post-*.flac）

## 决策与流程影响
- 主渲染器 → yue2.cpp（脚本化批量，每版 ~3-4 分钟）；ComfyUI 留作 精修/Cover/定位
- 交付不变：别字版词稿喂 /synth；四件套由 mp3+abc 组装；mp3 可由 flac 母带转 320k 保持标准（当前服务输出 128k）
- 目标吞吐：1 卷 46 版 ≈ 2.6h（原 ComfyUI ≈ 15h+）

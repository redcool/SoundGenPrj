# 风格配器库（历史摇滚 · 风格抽取手册）

> 原则：**基调由当前历史主角的身份而定（先看曲风矩阵/人物评价表），搭配从本库抽取且每次力求与众不同**。
> 用法：每曲开写时按「§0 使用流程」走一遍，结果写入该曲 _style.txt 的「配器」节。

---

## §0 使用流程（每曲必走）

1. **定基调**：人物身份 → 曲风矩阵（一人一曲风）→ 人物评价表情绪导向 → 得出【情绪标签】
2. **摇搭配**（从中各取一，尽量不与上一首重叠）：
   - 基座：摇滚（rock/hard/metal 恒为底，保系列识别度）
   - 混搭层：【风格池】选 1-2 个
   - 主奏/副奏/节奏：【乐器池】各选
   - 人声：【嗓音池】选 1 类
   - 情绪：【情绪光谱】定标签
3. **抽 2 卡（双风格变体）**：每曲在「摇搭配」处**抽 2 张卡（变体 A 与 B）**，两张卡的差异必须 ≥2 维（**主奏乐器、嗓音类型必查至少其一不同**；混搭层尽量不同；速度/情绪可构成第三维）——即两版歌词相同，但唱法、曲风、配器各有各的脸
4. **校验**：对比前 1-2 首，主奏乐器、律动源、混搭层至少换掉两个
5. **落盘**：写入 _style.txt 「配器」节（A/B 两张卡）；meta 的曲风行同步（v1a/v1b 标注双风格）

## §8 收尾纪律（2026-10-15 教训：大禹《三过家门》结尾戛然而止）

1. **上游防**：每曲 style 提示追加后缀 `end with a resolving sustained final chord then fade out`；歌词末尾建议留一个 [Outro] 小节（器乐收束或人声吟唱渐弱），给模型"收尾材料"
2. **后期补救**（已用于《三过家门》两版，_outro 后缀）：ffmpeg 反相反响尾音 + 8s 三角渐弱：
   ```bash
   ffmpeg -y -i in.mp3 -af "afade=t=out:st=<DUR-7>:d=7:curve=tri" -c:a libmp3lame -b:a 320k out_outro2.mp3
   ```
3. 原版保留（_outro 为新增版本，不替换）
> ⚠️ 教训（2026-10-15）：勿用 `areverse,aecho,areverse` 整曲挂回声——aecho 作用于全轨，会产生整曲叠层/颤音（听感=两首错位合并）；收尾补救一律用**纯渐弱**（afade 三角曲线），如要残响尾音应只对末尾 10s 片段处理后再拼接。
## §9 楚辞启示录（歌词手法 · 2026-10-15 确立）

> 楚辞本质是配楚声歌唱的歌辞：“兮”是呼吸/拖腔记号，复沓是上古副歌，“乱曰”是终曲爆发。
> 借结构、不搬词句（守住“简单易懂”红线）。

1. **副歌 hook = 呼唤式/执念式短句**（楚辞“魂兮归来”式）：一句执念反复锤，命令/呼唤/悲叹语气最适合唱；例：披甲而战 / 愿者上钩 / 吾将上下而求索
2. **Final Chorus = “乱曰”收尾**：终曲放大——总结全篇意象 + 升调爆发（我们的“双倍气势收尾”即其现代版，保持并自觉化）
3. **意象锤（香草美人比兴）**：每曲给人物一个“意象锚”，主歌铺叙、副歌锤意象、final 升华——至少出现 3 次
4. **兮式拖腔点缀**：重要副歌句尾允许一个长音/拖腔（——延长），即“兮”的摇滚版；不整篇兮兮
5. **神话层/神游语汇**：后羿/刑天等传说人物可用“神游体”（我令金乌坠地 / 羲和弭节式），与正史卷拉开语域
6. **试验曲目**：战国卷 屈原《求索》→ 定型模板；夏卷 后羿《射日》→ 放飞试验
7. **系列落地（2026-10-16）**：楚辞原典谱曲系列 `albums/楚辞之歌/`（8 张专辑 + 篇目档案 docs/楚辞/），本手册 §0 流程 + §9 手法通用
## §10 楚辞摇滚配器 · 谈话式（2026-10-17 用户定调）

> 用户原话： 楚辞摇滚的乐器配合，建议电琵琶、古筝、竹笛与电吉他贝斯的谈话式。
> 含义：**中西两组乐器互为问答/应和**——东方组（电琵琶/古筝/竹笛）与西方组（电吉他/贝斯）像两个人交谈：
> 一句东方语，一句西方答；主歌东方铺叙，间奏东西对句；副歌两组合流齐鸣。

### 谈话式三法
1. **问答句**：主歌每两句一组——上句东方乐器起头（琵琶/筝/笛），下句电吉他/贝斯接话，一东一西轮转；
2. **对句间奏**：器乐间奏写成"对话"——笛/古筝短句 ⇒ 电吉他应答 ⇒ 贝斯低语收束，再交回东方；
3. **合流副歌**：副歌两组合体齐鸣（全奏），与主歌的"一东一西"拉开对比，收拢对话。

### 乐器角色（楚辞卷默认）
| 乐器 | 角色 | 备注 |
|---|---|---|
| 电琵琶 | 主奏·东方声线 | 金戈铁马/叙说，可续可扫（项目 melodeath_pipa 先例） |
| 古筝 | 副奏·琶音/装饰 | 高音震慑，铺垫空间 |
| 竹笛 | 主奏·呼吸线 | + wide reverb = 空旷悲壮 |
| 电吉他/贝斯 | 应答·西方声线 | 对句接话、副歌合流、律动锚 |

### style 文本模板（可替换进引擎）
`call-and-response interplay between electric pipa, guzheng and bamboo flute against electric guitar and bass, eastern instruments ask and western ones answer, full-band chorus, Mandarin Chinese vocals`

### 适用
- 对话体（渔父/卜居）、双神篇（湘君湘夫人）、人神对望（山鬼）最贴；
- 全卷可作为"楚辞摇滚"的配器底声，各篇再叠风格池差异化。
## §11 心境-曲风映射（屈原三态 · 2026-10-17 用户定调）

> 用户原话：屈原的心境，应该有悲伤、愤恨，也有欢快的时刻。根据当时的心境来选择曲风、速度、乐器。
> 曲风基础：**art rock=悲伤 · 重金属/工业=愤恨 · reggae/EDM=欢快**。

### 三态映射（楚辞篇目速查）
| 心境 | 曲风 | 速度 | 乐器倾向 | 典型篇目 |
|---|---|---|---|---|
| 悲伤 | art rock / 抒情 | 慢-中 (60-90) | 竹笛+reverb、古筝、钢琴/弦乐、电琵琶（如泣如诉） | 哀郢、湘夫人、悲回风、九辩、惜誓 |
| 愤恨 | 重金属 / 工业金属 | 快 (120-170) | 失真电吉他、下行贝斯、鼓机、死嗓/嘶吼、唢呐点睛 | 离骚·乱曰、天问、怀沙、国殇、七谏 |
| 欢快 | reggae / EDM / dance | 中快 (96-140) | 反拍吉他/贝斯、手鼓、合成器琶音、笛子欢快句、铜锣收束 | 橘颂、礼魂、东君、少司命、渔父（旷达轻快段） |

### 篇目→心境 全谱（楚辞 17 卷归档）
- **悲伤**：哀郢（亡国之痛）、湘夫人（怅望）、悲回风、九辩（悲秋）、惜誓、哀时命、招隐士之心（隐忧）
- **愤恨**：离骚·乱曰（国无人莫我知）、天问（拷问天地）、怀沙（决绝）、国殇（悲壮而勃发）、七谏（谏君）
- **欢快/明朗**：橘颂（咏橘自喜）、礼魂（送神庆）、东君（日神辉）、少司命（命之神护）、渔父（沧浪逍遥）
- **复合**：离骚主歌（悲愤交织）、九歌诸神（一神多态：湘君怅惘+东皇庄严）、渔父（旷达=酸楚里的亮色）

### 落地规则
1. **一首一篇主心境**，但允许"段级转态"：如 哀郢 主悲、乱曰段可转愤；渔父 主旷、副歌可泛喜；
2. **乐章制（长诗）**：离骚/天问/九辩 按情绪弧拆乐段，每段用对应曲风与速度——同一首歌里"悲→愤→舒"随心境走；
3. 谈话式配器（§10）与心境映射叠加：东问西答的问答结构可承载任何心境，乐器情绪按三态调整音色；
4. 双版抽卡时（§0）优先抽"不同心境"而非"同心境异乐器"，让版本差异直指情绪。

> 例：《橘颂》= 欢快象限 · reggae 反拍 + 手鼓 + 笛子欢句，速度 108，女声或年轻男声明亮；《天问》= 愤恨象限 · 工业鼓机 + 下行贝斯 + 念白嘶吼，130。
### §6 补充 · 曲风偏好实证（2026-10-19 用户听感调查）

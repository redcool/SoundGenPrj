# 人物生平史料 · 先秦（夏商周春秋 · 历史摇滚创作根基）

> 用途：为「历史摇滚」系列（义名之歌 / 恶名之歌）提供**人物本事档案**——按王的时代排序，记录每位王的生平、该时代正面人物、反面人物。
> 定位：比 `人物库.md`（创作管线地图）更完整的**史料正典**；比 `人物评价表.md`（十维评分）更厚的事实剖面。
> 编写纪律（衔接 `docs/搜索流程规范.md` 与「恶名骂法三铁律」）：

- **正史为骨**：主诉一律出自《史记·夏本纪 / 殷本纪 / 周本纪》《尚书》《国语·周语》等传世正史与甲骨卜辞；段落内以〔注〕标出处
- **传说与演义分层**：神话/演义内容（射日、炮烙细节、烽火戏诸侯定形等）一律括注『传说层/演义层』，不冒充史料
- **人名本名**：西周人物用本名（姬昌/姬发/姬旦/姬奭/姬诵…），商代姓名体系不全者沿用通行名（汤/伊尹/盘庚/武丁/傅说/妇好…）——本名于各卷〔注〕注明
- **微瑕人物**：史书有『善恶两面』或『恶名可洗』者（太甲改过、帝乙弱恶名）单独标注，不硬凹脸谱

# 春秋 · 人物生平史料（按诸侯国划分）

> 春秋（前770—前476）：周室东迁、王纲解纽，诸侯争霸。本卷**按诸侯国**分卷；每国结构统一：
> **一、正面人物**（国君 → 臣 → 贵族 → 布衣）｜**二、反面人物**（国君 → 臣 → 贵族 → 布衣）。

## 阶级分类口径（全卷统一）

| 类 | 定义 | 例 |
|---|---|---|
| **国君** | 在位诸侯、篡位者、亡国之君（含夫人/后妃按『君族』处理，见贵族） | 齐桓公、晋文公、楚庄王、卫懿公 |
| **臣** | 卿相、大夫、家臣——以职位受任、出仕任事者（布衣起家者括注出身） | 管仲、晏婴、伍子胥、阳虎、费无极 |
| **贵族** | 公族、公子、世卿——以血统封邑为身份者 | 庆父、共叔段、季文子、崔杼、季札 |
| **布衣** | 士、平民、商人、隐者——无封邑爵位者 | 曹刿、介子推、孔子、弦高、专诸 |

> 一人兼两重身份时按**主要身份**归类并括注（如管仲＝臣·没落贵族出身；子产＝臣·郑公族）。
> 史料主源：《左传》《国语》《史记》各世家（齐太公/鲁周公/晋/楚/宋微子/卫康叔/郑/吴太伯/越王勾践/秦本纪）、《诗经》《论语》互证；传说/寓言（割股、二桃杀三士、叶公好龙等）单列标注。

## 〇、周王室（天下共主 → 形同虚设）

**背景**：前770 平王东迁洛邑，王室失岐丰之地；前707 繻葛之战射王中肩。此后周室仅存名义，霸主代行『尊王攘夷』。

### 正面人物

**国君**
- **桓王 姬林**（前719—前697）：繻葛之战（前707）率王师伐郑，虽败而维持天子用兵之名分——『知其不可而为之』（《左传·桓公五年》）。
- **襄王 姬郑**（前651—前619）：葵丘赐齐桓公胙、践土策命晋文公为伯——霸主须王命认证的最后高光（《左传·僖公九年/二十八年》）。

**臣**
- **王孙满**（前6世纪）：对楚庄王问鼎，『在德不在鼎』『周德虽衰，天命未改』（《左传·宣公三年》）——以言辞退霸主之问。

**贵族**
- **刘康公、单襄公**（前6世纪）：周室卿士（王畿世卿），守礼持正，屡以『礼』折诸侯（《国语·周语》）——礼乐最后的守夜人。

**布衣**
- （无载：王畿无布衣参政之例。）

### 反面人物

**国君**
- **平王 姬宜臼**（前770—前720）：东迁弃宗周故地，以岐西许秦——天子自削王畿（争议：势不得已，《史记·秦本纪》）。
- **庄王 姬佗 / 釐王 姬胡齐**（前696—前677）：命曲沃武公为晋侯（前678）——开『以臣代君而获王命』之例，礼法失守（《史记·周本纪》）。

**臣**
- （无载：王畿卿士无实锤之佞。）

**贵族**
- **王子朝**（前520 之乱）：与悼王、敬王争位，率旧官奔楚，典籍随之南流（《左传·昭公二十六年》）——周室最后一次内乱。

**布衣**
- （无载。）

## 一、鲁国（礼乐之邦 · 秉周礼）

**背景**：周公旦之后（伯禽封鲁）；三桓（季孙、叔孙、孟孙）专政，公室卑弱——『礼乐征伐自大夫出』的典型。

### 正面人物

**国君**
- **僖公 姬申**（前659—前627）：季友相之，鲁国稍安；《诗经·鲁颂》所颂之君（《史记·鲁周公世家》）。
- **定公 姬宋**（前509—前495）：用孔子为大司寇、夹谷之会（前500）以礼折齐（《史记·孔子世家》）。

**臣**
- **展喜**（前7世纪）：齐孝公伐鲁，以『恃先王之命』犒齐师而退之（《左传·僖公二十六年》）——口舌退兵。
- **臧文仲**（前7世纪）：鲁之贤大夫，主『以德绥诸侯』（《左传·僖公》）。

**贵族**
- **季文子（季孙行父）**（前6世纪）：三桓之首，相三君而妾不衣帛、马不食粟；『三思而后行』（《左传·襄公五年》《论语·公冶长》）——世卿中的廉相。

**布衣**
- **曹刿**（前7世纪初）：长勺之战（前684）『一鼓作气』败齐师；『肉食者鄙，未能远谋』（《左传·庄公十年》）——士人参战的典范。
- **柳下惠（展禽）**：『不以三公易其介』（《论语·微子》《孟子》）——正史为『守节直道』；『坐怀不乱』系后世传说层。
- **孔子（孔丘，前551—前479）**：士出身，曾任大司寇、摄相事；堕三都、夹谷之会；后周游列国十四年，返鲁删《诗》《书》、作《春秋》（《史记·孔子世家》）——春秋末最重之正面符号。

### 反面人物

**国君**
- **桓公 姬允**（前711—前694）：弑隐公自立；因文姜与齐襄公私通，被齐使彭生扼杀于车中（《左传·桓公十八年》）——弑君得位、身死名裂。
- **昭公 姬稠**（前541—前510）：伐季氏失败而出奔乾侯，客死于外（《左传·昭公二十五年》）——公室对卿族最后一搏而败（可作悲剧而非纯恶）。

**臣**
- **阳虎**（前6世纪末）：季氏家臣，囚季桓子、窃宝玉大弓，『陪臣执国命』（《论语·季氏》《左传·定公八年》）——权力下沉的样本。

**贵族**
- **公子翚（羽父）**（前8世纪末）：请杀隐公以求太宰，不遂而反谮，弑鲁隐公（《左传·隐公十一年》）——鲁国第一次弑君。
- **庆父**（前7世纪）：与哀姜私通，弑子般、弑闵公（『庆父不死，鲁难未已』《左传·闵公元年》）——『弑君专业户』成语原型。
- **哀姜**（前7世纪）：齐女、鲁夫人，与庆父同谋弑君，后被齐桓公召而杀之（《左传·闵公二年》）。

**布衣**
- （无载。）

## 二、齐国（首霸之国 · 霸业与坠落）

**背景**：太公望之后，滨海鱼盐之利；桓公用管仲成首霸（前685—前643），其后诸子争位、田氏渐强。

### 正面人物

**国君**
- **桓公 姜小白**（前685—前643）：**春秋首霸**——任管仲，『四民分业』『相地而衰征』『尊王攘夷』；救燕、存邢卫、伐戎，九合诸侯、一匡天下；葵丘之会（前651）受周王赐胙（《史记·齐太公世家》《左传·僖公》）。
- **庄公 姜购 / 僖公 姜禄甫**（前794—前698）：西周末入春秋，齐始强，『齐僖小伯』。

**臣**
- **管仲（管夷吾）**（前7世纪）：相齐四十年，改革军政、通货积财；『仓廪实而知礼节，衣食足而知荣辱』（《史记·管晏列传》《国语·齐语》）——制度派（没落贵族出身）。
- **鲍叔牙**（前7世纪）：让相位、荐管仲；『生我者父母，知我者鲍子也』（《史记·管晏列传》）——识才让贤母题。
- **晏婴（晏子）**（前6世纪）：相齐三君，节俭力行、犯颜直谏；谏景公厚敛重刑（『踊贵屦贱』）、拒崔杼之盟（《左传·襄公二十五年》《晏子春秋》）——『晏子使楚』『二桃杀三士』系《晏子春秋》传说层。
- **司马穰苴（田穰苴）**（前6世纪末）：斩监军庄贾以立军威，燕晋之师自退（《史记·司马穰苴列传》）——春秋末兵家先声（田氏庶支）。

**贵族**
- （无突出者：齐之贤者在臣列。）

**布衣**
- （无载。）

### 反面人物

**国君**
- **襄公 姜诸儿**（前697—前686）：与妹文姜私通、杀鲁桓公；『瓜时而往，及瓜而代』失信戍卒，被弑（《左传·庄公八年》）。
- **懿公 姜商人**（前612—前609）：弑君自立，骄奢，被邴歜、阎职弑（《史记·齐太公世家》）。
- **景公 姜杵臼**（前547—前490）：晏婴相之而不能用其言；厚敛重刑、废嫡立庶，为田氏代齐埋因（《左传·昭公三年》）——有为之君而失于奢（争议）。
- **简公 姜壬**（前484—前481）：被田常弑——田氏代齐进入倒计时（《史记·齐太公世家》）。

**臣**
- **易牙、竖刁、开方**（前7世纪）：三奸——易牙烹子献糜、竖刁自宫入侍、开方弃亲事君；管仲谏逐之不听，桓公病中被幽禁饿死，尸虫出户（《史记·齐太公世家》《管子》）——『亲佞远贤』母题。
- **田乞、田常（陈氏）**（前6世纪末—前5世纪初）：以厚施收民心、以弑君夺国政——『田氏代齐』的长期工程（《史记·田敬仲完世家》）。

**贵族**
- **崔杼**（前6世纪）：弑齐庄公；太史书『崔杼弑其君』，杀之，其弟复书，再杀，终不能改（《左传·襄公二十五年》）——史官不屈对照恶人。
- **庆封**（前6世纪）：崔杼同党，专政骄奢，后被田、鲍、栾、高四族逐（《左传·襄公二十八年》）。

**布衣**
- （无载。）

## 三、晋国（百年霸业 · 六卿崛起）

**背景**：唐叔虞之后；献公『并国十七』而骊姬乱政；文公流亡十九年归国称霸（前636—前628），城濮之战败楚；此后灵公被弑、赵氏专权、六卿相争，终分晋。

### 正面人物

**国君**
- **文公 姬重耳**（前636—前628）：**春秋第二霸**——流亡十九年（狄、卫、齐、曹、宋、郑、楚、秦），归国作三军、定霸业；城濮之战（前632）『退避三舍』败楚，践土之盟受策命为伯（《左传·僖公二十三年/二十八年》《史记·晋世家》）。
- **悼公 姬周**（前572—前558）：**晋最后的中兴**——『三驾而楚不能与争』，九合诸侯（《左传·襄公八年/十一年》）。

**臣**
- **狐偃（子犯）**（前7世纪）：从重耳流亡十九年，城濮之战谋主（《左传·僖公二十七年/二十八年》）。
- **赵衰**（前7世纪）：从亡功臣，让卿位、举贤不避；赵氏基业之始（《左传·僖公》）。
- **先轸**（前7世纪）：城濮、崤之战主帅，『一战而霸』；后免胄入狄师而死以自罚（《左传·僖公三十三年》）——刚烈名将。
- **祁奚**（前6世纪）：『外举不避仇，内举不避亲』（《左传·襄公三年》）。
- **叔向（羊舌肸）**（前6世纪）：晋之贤大夫，谏平公勿纵侈、论『国将亡，必多制』（《左传·昭公六年》）。
- **魏绛**（前6世纪）：和戎五利、『居安思危』（《左传·襄公十一年》）。

**贵族**
- （无突出者：晋之贤者多在臣列。）

**布衣**
- **介子推（介之推）**（前7世纪）：文公赏从亡者而不及，遂隐绵山不言禄（《左传·僖公二十四年》）；『割股奉君』『寒食』系传说层（《韩诗外传》等）——士人之隐。

### 反面人物

**国君**
- **献公 姬诡诸**（前676—前651）：『并国十七，服国三十八』；宠骊姬、杀太子申生、逐重耳夷吾（《左传·僖公四年》）——功业与失德并存。
- **灵公 姬夷皋**（前620—前607）：厚敛雕墙、从台上弹人、杀宰夫；被赵穿弑（《左传·宣公二年》）——『不君』典型。
- **厉公 姬寿曼**（前580—前573）：鄢陵之战（前575）胜楚后骄纵，被弑（《左传·成公十七年/十八年》）。

**臣**
- **屠岸贾**（前6世纪）：晋景公宠臣，借『赵盾弑君』旧案诛灭赵氏满门（《史记·赵世家》）——『赵氏孤儿』反派；**《左传》无载，属《史记》系统叙事（学界多判采自传说），标注使用**。
- **赵盾**（前6世纪）：晋国正卿，『赵盾弑其君』董狐直笔之对象（《左传·宣公二年》）——争议人物（忠臣而蒙弑君之名）——**枭雄卷·待开**
- **智伯瑶（荀瑶）**（前5世纪初）：六卿之首，水灌晋阳、骄横索地，被韩赵魏共灭——『才胜德』的枭雄样本（春秋末/战国之交）——**枭雄卷·待开**

**贵族**
- **骊姬**（前7世纪）：晋献公夫人，谮杀太子申生、逐重耳夷吾，立奚齐（《左传·僖公四年》《国语·晋语》）——『骊姬之乱』（可标注：其恶有制度土壤，非独妇人之罪）。

**布衣**
- （无载。）

## 四、楚国（南方霸主 · 问鼎中原）

**背景**：芈姓熊氏，南方大国；武王僭号称王，庄王『问鼎』（前606）；灵王暴虐失国，平王夺媳致伍氏之祸，昭王时几亡于吴。

### 正面人物

**国君**
- **武王 熊通**（前740—前690）：僭号称王（前704，『我蛮夷也，不与中国之号谥』）；伐随卒于师（《史记·楚世家》）——南方自主的开创者。
- **庄王 熊侣**（前613—前591）：**春秋第三霸**——『三年不鸣，一鸣惊人』（《史记·楚世家》）；问鼎中原（前606）；邲之战（前597）大败晋军；用孙叔敖修政（《左传·宣公三年/十二年》）。
- **昭王 熊珍**（前515—前489）：柏举之战（前506）吴军入郢，昭王出奔而能复国——患难之君（《左传·定公四年》）。

**臣**
- **斗谷于菟（子文）**（前7世纪）：令尹，『毁家纾难』（《左传·庄公三十年》）。
- **孙叔敖（蔿敖）**（前6世纪）：令尹，修芍陂水利、佐庄王邲之战大胜；司马迁列为『循吏第一』（《史记·循吏列传》）——布衣起家的贤相。
- **伍举**（前6世纪）：谏楚灵王章华台之奢（《国语·楚语》《左传·昭公》）——直言敢谏。
- **申包胥**（前6世纪末）：吴破郢，哭秦庭七日七夜，秦师乃出（《左传·定公四年》《史记·伍子胥列传》）——『哭秦庭』。

**贵族**
- **沈诸梁（叶公）**（前5世纪初）：楚公族、叶县县公，平定白公胜之乱，安楚室（《左传·哀公十六年》）；『叶公好龙』为寓言（《新序》），非史实。

**布衣**
- （无载。）

### 反面人物

**国君**
- **成王 熊恽**（前671—前626）：泓水之战（前638）败宋襄公；城濮之战（前632）败于晋；欲废太子商臣，反被围而自缢（《左传·文公元年》）——废立取祸。
- **灵王 熊围**（前540—前529）：弑君自立、筑章华台、乾溪之难众叛亲离，自缢（《左传·昭公十三年》）——『穷奢极欲而失国』。
- **平王 熊弃疾**（前528—前516）：为太子建聘秦女而自纳之，听费无极谗杀伍奢、伍尚，逼伍子胥出奔（《左传·昭公十九年/二十年》）——『夺媳杀忠』。

**臣**
- **费无极（费无忌）**（前6世纪）：谗太子建、谗伍奢，致楚国内乱、郢都陷落（《左传·昭公二十年》）——佞臣母题。
- **囊瓦（子常）**（前6世纪）：令尹，索贿唐蔡、失诸侯心，柏举之战（前506）大败于吴（《左传·定公四年》）——贪而丧师。

**贵族**
- **白公胜（熊胜）**（前5世纪初）：楚王族，作乱劫惠王、杀子西，事败自缢（《左传·哀公十六年》）。

**布衣**
- （无载。）

## 五、秦国（西陲崛起 · 霸西戎）

**背景**：平王东迁时襄公始列为诸侯；穆公（前659—前621）用百里奚、蹇叔，东向争霸受挫于晋，转而『霸西戎』，为后世统一奠基。

### 正面人物

**国君**

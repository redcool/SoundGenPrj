# 专辑制作规范（历史摇滚系列 · 2026-10-15 确立）

> 目标：每张专辑在 `albums/<专辑名>/` 内自足成"发布单元"——歌曲/歌词/封面/文案全部齐备，用户可直接拿走上架。


## 0.5 专辑第一文件：人物事迹.md（创作根基 · 2026-10-17 确立）

- **每张专辑（义名之歌 与 恶名之歌 都要）建卷时，第一份要写的文件 = `文案/人物事迹.md`**（先于词/曲/封面）
- 内容：人物“本事”清单——**义名**＝正面人物（梯队分层 + 每人的身份/主要功绩/美德/史料来源）；**恶名**＝反面人物（罪状 + 史料 + 骂法依据，衔接“恶名骂法三铁律”）
- 本质：docs/history-rock/人物库.md 的**丰富版**（人物库=创作管线地图；人物事迹=内容根基）
- 来源标注：每位人物注明检索/文献出处（google 搜索、正史、档案）；**由 agent 负责检索与确认**（义名、恶名都查；搜索通道受限时用既有档案交叉核验，通道恢复后补检索）
- 与体系的衔接：事迹 → 曲风矩阵（气质）→ 歌词（双版）→ 评价表（十维）

## 1. 专辑目录结构（发布单元）

```
albums/<专辑名>/
├─ 专辑信息.md      # 曲目表 + 整卷状态（已有）
├─ 文案/            # 0) 人物事迹.md（第一文件·根基）① 专辑文案.md（喜马拉雅体例）② 每曲 <歌名>_文案.txt
├─ 封面/            # 专辑合集封面.png + 每曲 <歌名>_朝代_年代_人名.png
├─ 歌词/            # **正式版（标准版原文，含方括号标签；人看/交付用，永不放置别字版）**：每曲 _lyric / _style / _meta（+ _narr 等）
├─ 别字歌词/        # 仅放置 别字版（喂 YuE2，同音替换如 闾→吕）；**禁止**放入 歌词/
└─ 歌曲/            # 每曲 v*/n* 四件套（mp3/lyrics/abc/html）
```

**要求：专辑的歌曲（歌词、封面、文案）一律同步进 `albums/<专辑名>/`，不只留在 `output/history-rock/`。**

## 2. 文案规范（体例参考既有：docs/喜马拉雅专辑文案_刀锋入梦.md / 星海漫游指南.md / 战国卷1_求索.md）

- **专辑文案.md 结构**：标题 → 引言（背景散文，1-3 段）→ 卷定位 → 曲目单（含每曲一句话推介）→ 听感指引 → 发布说明
- **每曲文案（推介语）**：1-2 句，写入 `专辑信息.md` 曲目表 + 单独 `文案/<歌名>_文案.txt`
- 语气：人文向、有场景感、不吹不空；正史人物以史料钩子为核（可引〔注〕句）

## 3. 封面规范

- **主通道：ignis gpt-image-2**（可准确生成中文 → 歌名/宣传语可直接入图；接入会话后优先使用；未接入时用 Agnes 兜底）
- 备选：Agnes（免费，图为纯意象、避免文字）
- 文件与位置（全部入 `albums/<专辑名>/封面/`）：
  - 专辑合集封面：`<专辑名>_专辑封面.png`
  - 每曲封面：`<歌名>_朝代_年代_人名.png`
- 图标入图时（ignis）：中文短文案（歌名/副歌金句）可写，注意别字与多字

## 4. 引用规则

- 歌曲生成规则 v1（四件套、中文发声）· 人名规范（文件名用本名）· 时间线审查 · 双版词规（标注版/别字版）· 风格配器库（配器节/楚辞启示录 §9）

> **目录归属铁律（2026-10-19 用户确立）：`歌词/` = 正式版歌词（标准版原文）；`别字版` 只放 `别字歌词/`。交付/展示一律用 歌词/；模型渲染读 别字歌词/。**

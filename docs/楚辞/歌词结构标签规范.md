# 楚辞歌词结构标签规范（v1 · 2026-10-17）

> 适用：楚辞之歌全部歌词（标注版/别字版）。目的：让每一段都自带**段落角色 + 情绪 + 乐器 + BPM**，既供人读，也供生成模型参考。

## 一、标签格式（单行，方括号包裹）

`[段落类型 · 段落名 · 情绪 | 乐器组合 · 风格 BPM]`

示例：
- `[Verse 1 · 身世自矜 · 自矜/悲 | 竹笛+古筝+电琵琶 · art rock 72bpm]`
- `[Chorus · 长太息 · 悲恸/愤 | 全奏+齐唱 · 112bpm]`
- `[Outro · 乱曰 · 决绝/悲绝 | 全奏爆发→渐弱 · 128bpm]`

## 二、字段约定

| 字段 | 取值 |
|---|---|
| 段落类型 | Intro / Verse N / Pre-Chorus / Chorus / Bridge / Bridge N / Interlude / Outro |
| 段落名 | 该段内容锚点（身世自矜/党人当道/长太息/就重华陈词…） |
| 情绪 | 自矜 / 悲 / 愤恨 / 焦虑 / 悲恸 / 坚守 / 温情 / 审判 / 旷远 / 迷惘 / 幻灭 / 旷烈 / 决绝 / 欢快 / 空灵 |
| 乐器 | 电琵琶 / 古筝 / 竹笛 / 电吉他 / 贝斯 / 战鼓 / 编钟 / 合成器 / 唢呐 / 手鼓 / 齐唱 |
| 风格 BPM | art rock / 金属 / world / trance / reggae / folk + 速度 |

## 三、硬规则
1. **每段必须有一行标签**，标签行不参与演唱（模型若把标签唱出，改用无标签版词稿）；
2. **情绪**必须落在 §11 三态框架内或其细分（悲=art rock / 愤=金属工业 / 欢=reggae EDM / 旷=trance world）；
3. **乐器**必须可用 §10 谈话式配器解释（东问西答或合流）；
4. 副歌回唱段可只留标签 +「（回唱 Chorus 原词）」，不重复写词；
5. 标注版与别字版**段落结构逐行一致**，便于对照。

## 四、文件命名
- 标注版：`<曲名>_标注版_结构版.txt`
- 别字版：`<曲名>_别字版_结构版.txt`
- 分段：`<曲名>_别字版_A_<起>-<止>.txt` / `_B_...`

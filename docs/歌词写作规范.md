# 歌词写作规范（以《洪范》公平版为范本 · 2026-10-19 确立）

> 配套：docs/歌词规范.md（分段标注格式）+ 双版词规 v3 + 创作基调 v2 + 楚辞启示录 §9。
> 一句话总纲：**一首歌唱透一个核心，其余全是给核心铺路。**（范本：洪范的核心 = 公平。）

## 1. 核心先行

- 动笔前先定下歌曲的一句话核心（主题/思想），写入 _meta.md；
- 副歌 = 核心的浓缩金句：可独立传诵、对仗庄重、古文今用不隔（示例：“皇建其有极，王道荡荡 / 无偏无党，天下为公”）。

## 2. 副歌重复（重锤核心）

- 短歌副歌 **3-4 次**为宜（用户建议 ×4 亦可）；每次出现都是重锤核心，不换味、不注水；
- 终曲（outro）在副歌之上加一句升华点睛（示例：“——公平，是洪范的纲”）。

## 3. 起承转合结构（每段都有功能）

- 承/背景：为什么不写别人写我（身世·存仁）；
- 转/事理：核心内容铺开（九畴是什么）；
- 钩：加入对话或提问，把听众拉进去（“万物有极——你可愿，中间持平”）；
- 警/升华：警示或境界（五福六极、王道无偏）；
- 合：收尾点题（bridge 东行传说收放 → verse 5 把秤留下 → outro 金句）。

## 4. 意象锤

- 为核心选一个统一意象，≥3 次出现，副歌/尾声升华它（范本：公平 = **秤**——皇极是一杆公平的秤 / 一副秤量每一位王 / 把秤留下 / 王道的秤不问出身）；
- 意象要具体可感、一以贯之，不散。

## 5. 语言：白话叙事 × 文言金句

- 主歌用白话叙事（有人味、易听清：“有人笑我是奴，我说：奴也好”）；
- 副歌与关键句用文言金句（庄重、可诵）；
- 善用问句增加代入与戏剧性。

## 6. 词量纪律（防截断）

- 短歌 4 分钟 ≈ **520-600 字**；慢拍/颂歌类（拖拍风格）压到 **~530** 防撞 max_duration 截断（《洪范》教训：716 字 B 卡颂歌被切尾）；
- 副歌轮次按风格定：快歌 3 次、慢/颂歌 4 次亦可，但总字数必须落在档内。

## 7. 标签与双版（见 歌词规范.md）

- 标准版：每段 [类别，情绪，节奏，乐器，人声]；
- 别字版：官方标签 [Intro/Verse/Chorus/Bridge/Outro] + 逐字高频同音正文，喂 YuE2。

## 8. 范本：洪范 v1b3 公平版（结构拆解）

```
[Verse] 殷的三仁，一个去，一个谏而死 … 武王得了天下，问我治国之方
[Chorus] 皇建其有极，王道荡荡 / 无偏无党，天下为公（×4 轮）
[Verse 3] 万物有极——你可愿，中间持平（提问钩子）
[Bridge] 后来我东走朝鲜之滨，把这只公平的秤，带到了海边
[Outro] …公平，是洪范的纲（点睛）
```

核心：公平｜意象：秤｜钩：问王持平｜收：戒字/纲字。
## 史诗厚度写法 v2（2026-10-23 用户提出「历史厚度不够」后定稿）

### 一、核心矛盾与解法

史料密度 ↑ 与 好唱度 ↑ 通常互斥。解法是**信息靠行数堆、不靠行长堆**：
- 单行 **8-14 字**（可唱、可换气、YuE2 不易赶字）；
- 每段 **6-10 行**（信息量靠行数）；
- 每 4 行成组，**1/2/4 押韵，3 放开**（放开的那句专门放史实转折）。

### 二、每段必带「四要素」

年代 / 地名 / 人名·身份 / 一个具体动作。示例：
> 前六三零年，两国合兵（年代+事件）
> 晋军函陵，秦军氾南（地名）
> 佚之狐开口，举荐一个人（人名·身份）
> 郑伯握住，那只老手（动作）

### 三、八段结构（写一个人的一生，不是写一个场景）

| 段 | 功能 | 内容要求 |
|---|---|---|
| verse 1 | 处境与身份 | 他是谁、被谁忽视、当下危局（2 个史实） |
| verse 2 | 事件链 A | 3-5 个具体动作（谁找谁、说了什么、怎么去） |
| chorus | **一生的定语** | 不是复述事件，是给这个人下定义（金句 4 句，钉死一韵） |
| verse 3 | 事件链 B | 关键对话/原话引用（拆成短行，不整段照抄） |
| verse 4 | 局面翻转 | 结果：谁退了、谁盟了、谁死了（带数字与地名） |
| bridge | 对手视角 | 敌方/旁观者的态度（体现格局与代价） |
| chorus 2 | 历史回响 | 这件事的后果与评价（可与 chorus 换韵） |
| outro | 一句史论 | 抽象成一句可传诵的话 |

### 四、原话引用的处理

- 原文整句（如「臣之壮也，犹不如人」）→ **拆成 2-3 个短行**，保留关键字眼；
- 一段最多 1-2 句原话，且放在段尾（收束力最强）；
- 引用后紧跟一句白话翻译（帮听众听懂）。

### 五、禁止项

- 单行超过 16 字（难唱）；
- 一段塞 5 个以上史实（听不清）；
- 通篇只有情绪没有事件（现在的问题）；
- 为押韵改史实（宁可换韵）。

### 六、自检清单

- [ ] 每段 ≥2 个硬史实（年代/地/人名/原话）
- [ ] 全篇覆盖此人「前—中—后」三段人生
- [ ] 单行 ≤14 字
- [ ] 每 4 行 1/2/4 押韵
- [ ] chorus 是定语而非事件复述

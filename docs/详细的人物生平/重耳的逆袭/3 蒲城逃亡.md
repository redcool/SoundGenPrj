
1. 逃亡背景：骊姬之乱与祸及蒲城

• 祸起萧墙： 晋献公晚年专宠骊姬。骊姬为了让自己的儿子奚齐继承王位，设计陷害太子申生，逼得申生自杀。
• 回防封地： 陷害完太子后，骊姬又诬陷重耳和夷吾两位公子也参与了谋反。重耳当时正在绛都（晋国都城），听闻风声不对，连夜悄悄逃回了自己的封地——蒲城（今山西永济一带）。
• 反遭坐实： 重耳的不辞而别反而让晋献公坚信他“心中有鬼”，于是晋献公勃然大怒，直接派兵攻打蒲城。

2. 蒲城对峙：重耳的“孝道”抉择

• 拒绝抵抗： 当晋国大军压境时，蒲城的百姓和守军群情激昂，纷纷表示愿意誓死保卫重耳，抵抗官军。
• 重耳的台词： 重耳展现了极高的政治情商与道德感，他拦住众人说：“倚仗君父的命令而享受养生的俸禄，才得到属下人民的拥戴；有了属下人民的拥戴，就同君父对抗起来，没有什么比这再大的罪过了。我还是逃走吧！”
（意即：我是靠父亲的恩赐才有了今天，如果今天带着你们和父亲对仗，那就是不忠不孝的大罪。）因此，他下令放弃抵抗，准备出逃。

3. 惊险时刻：斩断衣袖（“勃鞮追杀”）

这是整个蒲城出逃事件中最经典、最惊险的桥段：
• 刺客夜袭： 晋献公派出的先锋是一个叫勃鞮（亦称履辊）的宦官，此人武艺高强、行动神速。他带人趁夜摸进蒲城，直接杀入重耳的住所。
• 翻墙逃命： 重耳听见动静在随从狐毛、狐偃的搀扶下拼命往外跑，企图翻墙逃走。
• 割袍断袖： 勃鞮眼看就要追上，飞身一剑刺去。重耳慌忙挥臂招架并向前一跃，这一剑没刺中要害，却狠狠削掉了重耳的一只衣袖（袍袖）。重耳顾不上疼痛，连滚带爬地翻过城墙，在黑夜中侥幸逃脱。

4. 逃亡去向：奔向狄国

• 带走智囊团： 蒲城沦陷后，重耳并不是一个人在逃亡。赵衰、狐偃、颠颉、魏武子、司空季子等一班忠心耿耿的贤士死心塌地地跟随他，这也为他日后复国保留了核心班底。
• 投奔娘家： 逃出蒲城后，重耳分析了天下大势，决定投奔狄国（翟国）。因为狄国是重耳母亲的娘家，相对安全，而且当时是一股不容小觑的北方游牧力量。
• 长达12年的安居： 重耳到了狄国后，受到了不错的安置，甚至还在那里娶了季隗为妻，生下两个儿子，在狄国一住就是12年，直到后来遭到弟弟晋惠公的二次追杀才继续流亡。

💡 历史评价与思考

蒲城出逃虽然狼狈，但重耳“不与父战”的决定，不仅在道德上占据了“孝”的至高点，避免了背负叛军的骂名，更保护了蒲城的无辜百姓。那只被勃鞮砍下的断袖，也成了这段险象环生历史的标志性见证。

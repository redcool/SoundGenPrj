春秋五霸之一的晋文公（重耳）“勤王尊周”是他确立霸业的关键政治事件。 这一举动不仅让他在名义上获得了周天子的认可，也让晋国在诸侯中树立了极高的政治威望。
以下为您详细讲解重耳“勤王尊周”的背景、经过与历史意义：

1. 历史背景：王室内乱

公元前636年，周王室发生内乱。周襄王的弟弟王子带联合狄人攻打周朝都城。周襄王无力抵抗，被迫逃亡到郑国的汜水一带，并向各诸侯国发出紧急求援（告急）。
此时，重耳刚刚结束了19年的流亡生涯，在秦穆公的帮助下回到晋国继位，是为晋文公。当时晋国刚刚安定，急需一个树立威信、称霸诸侯的机会。

2. 核心过程：决断与出兵

面对周天子的求助，晋国朝廷内部展开了讨论，重耳展现出了高超的政治远见：
• 关键谋臣的建议： 谋士赵衰和狐偃看准了时机。狐偃对晋文公说：“求诸侯，莫如勤王。诸侯信之，且大义也。”（想要号令诸侯，没有比尊奉周天子更好的理由了。这样做不仅能赢得诸侯的信任，而且大义凛然。）
• 果断出兵： 晋文公采纳了建议。为了抢在同样有称霸野心的秦国之前立功，晋国分兵两路：一路前往汜水迎接周襄王，一路直接进攻留在王都的王子带。
• 平定内乱： 公元前635年，晋军迅速击败了王子带及其党羽，将其诛杀，成功平定了叛乱。

3. 结果：护送还朝与天子赏赐

晋文公亲自护送周襄王回到国都洛邑（今河南洛阳）。周襄王为了感激晋文公的救驾之功，举行了隆重的典礼，并赐予晋国丰厚的赏赐：
• 割让土地： 周天子将阳樊、温、原、欑茅（今河南济源、沁阳一带）等大片土地（史称“南阳之田”）赐给晋国。
• 政治特权： 晋文公获得了“侯伯”（诸侯之长）的身份，周天子赐予他彤弓（红色的弓）、玈弓（黑色的弓）以及矢（箭），象征着他拥有代天子征伐不臣的最高军事指挥权。

4. 历史意义：“尊王”变“称霸”

重耳的这次“勤王”在政治上获得了巨大的成功：
• 政治名分： 在春秋时期，虽然周王室衰微，但“尊周”在名义上仍是至高无上的道德制高点。重耳通过“勤王”，打响了“尊王攘夷”的旗号，占据了道义优势。
• 霸业奠基： 随后在公元前632年的城濮之战中，晋国正是凭借这种政治威望和军事实力击败了楚国。战后，晋文公在践土主持诸侯会盟，周襄王正式册封他为霸主。
总结来说： 重耳勤王尊周，名义上是保护周天子（尊周），实际上是以最小的代价换取了最大的政治和领土利益，为晋国长达百年的中原霸业奠定了最坚实的基础。

“贪天之功”是一个出自《左传·僖公二十四年》的著名历史典故，它直接关联着春秋五霸之一——晋文公（重耳）流亡回归后，其忠臣介子推“割股奉君”却拒绝受封、隐居绵山的故事。
这个故事常被后人用来形容把上天成就的功绩或集体的劳苦说成是自己的力量，据为己有。以下是该典故在重耳经历中的全过程讲解：

1. 典故背景：十九年的颠沛流离

晋国公子重耳因“骊姬之乱”被迫逃亡国外，历时19年，辗转狄国、卫国、齐国、楚国等八个诸侯国。
在流亡到卫国最穷困潦倒的时候，重耳一行人断粮挨饿，几近昏厥。跟随他的忠臣介子推为了不让重耳饿死，悄悄从自己大腿上割下一块肉，和着野菜煮成肉汤送给重耳吃（即历史上有名的“割股奉君”）。

2. 核心冲突：论功行赏与功臣争利

公元前636年，重耳在秦国的帮助下终于回到晋国即位，成为晋文公。
大局稳定后，晋文公开始对当年陪伴他流亡的功臣大加封赏。当时赵衰、狐偃等臣子纷纷居功自傲，在朝廷上争夺功劳和赏赐。
然而，在这场分封中，由于各种原因（一说晋文公一时疏忽，一说周朝突发叛乱导致行赏仓促中断），介子推被遗漏了，没有得到任何封赏。

3. “贪天之功”的由来

看到群臣在朝堂上争功，自己却被遗忘，介子推并没有去向晋文公邀功。他的邻居和母亲都劝他：“你受了那么大罪，甚至割肉救主，为什么不去领赏呢？”
介子推说出了一段载入史册、字字珠玑的至理名言：
“天实置之，而二三子以为己力，不亦诬乎？窃人之财，犹谓之盗，况贪天之功以为己力乎？”
• 白话翻译：“上天已经决定要让晋国兴旺，所以才让主公（重耳）当上国君。而那几位大臣却认为是靠自己的力量把主公扶上王位的，这不是自欺欺人吗？偷窃别人的财物尚且叫作强盗，更何况是贪图上天的功劳、把天意化为自己的力量呢？”
在介子推看来，重耳当上国君是天命所归（“天之功”），凡人只是顺应天意做了分内之事，若把这当作自己的盖世神功去向君王讨赏，就是对上天的亵渎和贪婪。

4. 结局与后世影响（寒食节的诞生）

介子推耻于与那些“贪天之功”的狐偃、赵衰等人同朝为官，于是带着年迈的母亲隐居到了绵山之中。
后来，重耳的小臣在宫门上贴出悬书（以龙和五条蛇为喻，讽刺一条蛇割肉奉君却无处安身），重耳这才猛然醒悟，对遗忘了介子推感到万分羞愧。他亲自率人前往绵山寻找，但介子推坚决不肯出山。
为了逼介子推现身，重耳听信了臣子的建议，下令放火烧山（意图留出一条通道让介子推出山）。不料介子推心志坚贞，宁死不愿下山求官，最终与母亲抱在一棵大树上被活活烧死。
重耳悲痛万分，为了纪念介子推，将绵山改名为介山，并下令在介子推死去的这一天，全国禁止生火做饭，只能吃冷食，这便是中国传统节日“寒食节”（后与清明节合流）的由来。

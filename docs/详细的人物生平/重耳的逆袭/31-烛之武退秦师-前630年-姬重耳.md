# 烛之武退秦师(前630年 · 姬重耳)

## 元数据头

- 事件线:歌单「烛之武退秦师」| 时间:前630年(《左传·僖公三十年》,晋秦围郑)
- 体量:34 行;一韵到底(中东辙)
- 立意:一个被冷落一生的老臣,夜里一根缒绳吊下城,一副舌头拆散两国之盟;霸主重耳则以三个"不"字止兵、立公子兰收官——能打是本事,能停才是英雄。
- 边界:郑文公不礼之账见第18曲《天之所启》,本曲是那笔账的讨还与反转;围郑借口为城濮助楚与贰于楚。

## Suno Style 块

- 曲风:夜谈雄辩感武侠摇滚方向,详见同名 .style.txt(v6 英文完整版,粘 Style 框)
- 人声:男声古汉语,苍老低诵的烛之武,低音旁白作郑伯/晋文公;男声齐唱如围城人声;负面链含 no English vocals
- 时长:3-4 分钟

# 就木之约(前655年年 · 姬重耳)

## 元数据头

- 事件线:歌单「就木之约」| 时间:前655—前644年(狄国十二年)
- 体量:34 行;一韵到底(江阳辙)
- 立意:与季隗的十二年温柔与一别;二十五年之约,乱世里最软的一道光。

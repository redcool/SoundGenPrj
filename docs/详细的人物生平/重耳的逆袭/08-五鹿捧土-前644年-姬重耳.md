# 五鹿捧土
**人名**: 姬重耳 | **时代**: 前644年
**年份核实**: 《生平.md》时间线3·卫段——"卫(前644):卫文公不礼;五鹿向农人乞食得土块,狐偃称'天赐也',以土喻得国"。
**立意**: 农夫以土块相赠,狐偃解作得国之兆,屈辱中见天命。
**韵部**: 江阳韵(ang),一韵到底,全篇38行,适配3-5分钟(建议演唱3-4分钟)。

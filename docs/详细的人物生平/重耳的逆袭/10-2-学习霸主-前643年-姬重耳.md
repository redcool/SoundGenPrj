# 学习霸主(前643年 · 姬重耳)

## 元数据头

- 事件线:歌单「齐国厚礼」插章 10-2 | 时间:旅齐五年间(前644—前639),以齐桓公病逝(前643)前后为轴
- 体量:34 行;一韵到底(姑苏辙)
- 立意:齐国既是高级战略研修班,也是政治清醒剂——学首霸怎么赢,看他怎么塌;五年的课堂笔记,他年在晋国一笔一笔兑现。
- 边界:公子沉溺归第11曲《乐不思晋》,桑下密谋与醉遣归第12/13曲,施政落地归第26/27曲;本曲只唱"研学"与"清醒"。

- 曲风:治学感武侠摇滚方向,详见同名 .style.txt(v6 英文完整版,粘 Style 框)

- 注"生平Lx"者出自本目录 0-生平.md 对应行(L9 地位、L15 随行者、L26 勤王、L27/L28 城濮与践土)。

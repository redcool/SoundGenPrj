重耳（晋文公）流亡到齐国时，因沉溺于安逸的生活而不想离开。在著名的「酒醉离开齐国」事件中，他的妻子齐姜与随从们（如赵衰、狐偃）秘密谋划，将重耳灌醉后强行抬上车送走，从而成就了他「志在四方」、最终返国称霸的伟业。
这一经典的歷史故事主要记载于《左传·僖公二十三年》以及《国语·晋语四》，其详细经历与背后「志在四方」的典故如下：

1. 齐国的安逸与重耳的懈怠

重耳因晋国内乱被迫流亡。来到齐国后，当时的中原霸主齐桓公非常器重他，不仅把宗室女齐姜嫁给了他，还赠送了他二十辆马车。
在齐国的五年里，重耳过上了梦寐以求的稳定、富足生活。随着齐桓公去世、齐国内乱，齐国的霸业开始衰落，但重耳在温柔乡中逐渐丧失了返回晋国建功立业的斗志，打算在齐国终老。

2. 齐姜与随从的秘密谋划

重耳的随从们（以狐偃、赵衰为首）深知如果一直待在齐国，重耳将终生无为。于是，他们在齐国的一棵桑树下秘密商议，如何劝说或逼迫重耳离开齐国、继续流亡以图复国。
这个秘密正巧被在桑树上采桑的女奴听到了。女奴回去后告诉了重耳的妻子齐姜。齐姜是一位极具政治远见和贤德的女性，她深知丈夫是一条不该困在小池塘里的巨龙。为了防止泄密，齐姜果断杀掉了这名女奴，并亲自劝说重耳：
「你有开疆拓土、复兴国家的志向（志在四方），沉溺于安逸和怀恋妻子，会毁掉你的功名。」
然而，重耳当时已经丧失了斗志，回答说：「人生就是要追求安乐，我哪儿都不去，一定要死在齐国。」

3. 酒醉被抬走：被迫踏上称霸之路

看到重耳如此决绝，齐姜明白好言相劝已无济于事。为了重耳的前途，她决定采取强硬手段。
• 设宴灌醉： 齐姜与重耳的随从赵衰、狐偃等人联手，设下一场酒宴。在宴会上，齐姜和随从们频频向重耳敬酒，直到将重耳彻底灌得酩酊大醉、人事不省。
• 强行送走： 趁着重耳熟睡，随从们迅速将他抬上马车，套上骏马，连夜驶离了齐国国境。

4. 醒来后的愤怒与释怀

当重耳在颠簸的马车上醒来，发现自己已经离开了齐国，明白过来这是随从们的计谋。他勃然大怒，甚至拿起戈（一种兵器）去追杀出谋划策的舅舅狐偃，喊道：「如果事情办不成，我就吃你的肉！」
狐偃非常冷静地回答：「如果大事不成，我的肉又腥又臊，根本不值得吃；如果大事成了，您享用的是天下的美味，哪里还会看得上我的肉呢？」
重耳听后冷静了下来，心中的怒火化为了羞愧与感激。他终于彻底清醒，摆脱了安逸的束缚，重新燃起了复国的雄心。

「志在四方」的现代启示

这个故事不仅是重耳流亡生涯的重要转折点，也是成语「志在四方」（指有远大的抱负和理想，不局限于狭小的天地）的核心典故来源之一。
• 克服舒适圈（Comfort Zone）： 齐国的安逸生活就是重耳的舒适圈。如果没有齐姜的狠心割爱和随从们的强行推动，历史上就不会有后来城濮之战中退避三舍、一匡天下的春秋五霸之一——晋文公。
• 贤内助与良师益友： 齐姜的「推一把」与狐偃等人的「拉一把」，展现了真正优秀的伴侣和团队，不会放任你沉沦于眼前的安乐，而会在关键时刻逼你走向更广阔的世界。

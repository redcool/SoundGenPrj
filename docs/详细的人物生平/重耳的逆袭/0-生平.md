# 晋文公姬重耳·生平事迹整理（歌曲创作素材）

> 用途：为创作歌曲准备的历史素材汇编。史实以《左传》《史记·晋世家》为据，关键条目已联网复核并标注来源 URL。

## 一、基本信息

- 姓名：姬姓，名重耳，晋献公之子，母大戎狐姬；谥"文"，史称晋文公（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。
- 生卒：约前697—前628年；前655年出奔流亡，前636年归国即位，在位前636—前628年（共9年）（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。
- 地位：春秋五霸之一，齐桓公之后第二位中原霸主（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。

## 二、生平时间线

1. **骊姬之乱（约前656—前655）**：献公宠骊姬欲立奚齐，太子申生被诬自缢，重耳奔蒲、夷吾奔屈（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。
2. **蒲城出逃（前655）**：寺人披（勃鞮）伐蒲，重耳逾垣而走，被斩断衣袖（"斩袪"），始流亡（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。
3. **十九年流亡（前655—前636）**，随行者有狐偃、赵衰、魏犨、颠颉、胥臣等：
   - 狄（前655—前644）：居十二年，娶季隗，许诺"待我二十五年，不来而后嫁"；季隗答"我二十五年矣，又如是而嫁，则就木焉"（[左传·僖二十三年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-san-nian/zhs)）。
   - 卫（前644）：卫文公不礼；五鹿向农人乞食得土块，狐偃称"天赐也"，以土喻得国（[左传·僖二十三年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-san-nian/zhs)）。
   - 齐（前644—前639）：娶齐姜，安于享乐；齐姜言"怀与安，实败名"，与狐偃计谋醉载而行，重耳醒后持戈逐子犯（[左传·僖二十三年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-san-nian/zhs)）。
   - 曹（前639）：曹共公窥其骈胁；大夫僖负羁馈食置璧，重耳受飧返璧，记恩不贪财（[左传·僖二十三年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-san-nian/zhs)）。
   - 宋（前638）：宋襄公新败于泓，仍赠马二十乘以助行（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。
   - 郑（前637）：郑文公不礼，叔詹谏而不听（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。
   - 楚（前637）：楚成王以礼相待；重耳许诺他日两军若遇，"其辟君三舍"——退避三舍之约（一舍三十里，三舍九十里）（[左传·僖二十三年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-san-nian/zhs)）。
   - 秦（前636）：秦穆公纳女五人（含怀嬴）；怀嬴奉匜沃盥被挥而怒："秦晋匹也，何以卑我"（[左传·僖二十三年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-san-nian/zhs)）。
4. **归国即位（前636）**：秦穆公发兵护送入晋，杀晋怀公（子圉）于高梁，重耳即位，时年六十二（[维基·晋文公](https://zh.wikipedia.org/wiki/%E6%99%8B%E6%96%87%E5%85%AC)）。
5. **平定吕郤之乱（前636）**：吕省、郤芮欲焚宫作乱；昔日追杀他的寺人披以"齐桓公置射钩而使管仲相"求见告变，文公微服会秦伯于王城，乱平（[左传·僖二十四年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-si-nian/zhs)）。
6. **勤王尊周（前635）**：王子带之乱，周襄王出居郑地氾；狐偃献策"求诸侯，莫如勤王"，晋师杀太叔带、迎襄王复位，得阳樊、温、原等河南之地（[左传·僖二十五年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-wu-nian/zhs)）。
7. **城濮之战（前632）**：楚围宋，晋救宋；文公为践旧诺令晋军退避三舍至城濮，战前有"表里山河"之论；先轸统帅，胥臣蒙马以虎皮破陈蔡之师，栾枝曳柴扬尘、狐毛伪遁诱敌，大破子玉，子玉自杀（[维基·城濮之战](https://zh.wikipedia.org/wiki/%E5%9F%8E%E6%BF%AE%E4%B9%8B%E6%88%98)）。
8. **践土之盟（前632）**：五月会盟于践土，周襄王亲临，册命晋侯为"侯伯"，赐大辂、戎辂与彤弓玈弓；晋文公正式称霸；冬又会于温，记作"天王狩于河阳"（[维基·践土之盟](https://zh.wikipedia.org/wiki/%E8%B7%B5%E5%9C%9F%E4%B9%8B%E7%9B%9F)）。
9. **逝世（前628）**：冬，晋文公卒，在位九年，殡于曲沃（[左传·僖三十二年](https://ctext.org/chun-qiu-zuo-zhuan/xi-gong-er-shi-er-nian/zhs)）。

## 四、可用于歌词的典故意象

1. **退避三舍**：先守九十里之诺再战，以退为进、以信立身的克制。
2. **割股奉君**：饥寒途中割股肉以充君食，至烈至诚的追随。
3. **志在四方**：齐姜"怀与安，实败名"——离安乐窝赴远方的少年志气。
4. **贪天之功**：介子推讥把苍天之功据为己有，功成不居者的反衬。
5. **秦晋之好**：联姻结盟、两姓世代交好的代名词。
6. **寒食节**：为介子推禁火冷食，一炷冷烟里的忠义纪念。
7. **表里山河**：内山外河、退可守的地利，喻胸中自有山河底气。
8. **五鹿受土**：乞食得土块，受辱处反成"天赐"吉兆。

## 六、歌词可用素材清单

- **地名叙事链**（可作主歌逐段推进）：蒲城→狄→卫·五鹿→齐→曹→宋→郑→楚→秦→归晋。
- **核心意象**：退避三舍（九十里）／割股奉君／志在四方／贪天之功／秦晋之好／寒食冷烟／表里山河／五鹿之土／斩袪断袖／醉遣之路。
- **金句原材料**（可化用为歌词）：
  - "怀与安，实败名"（齐姜劝行）。
  - "天赐也"（土块为吉兆）。
  - "险阻艰难，备尝之矣"（文公自述流亡）。
  - "莫余毒也已"（子玉死后文公之叹）。
  - "窃人之财，犹谓之盗，况贪天之功以为己力乎"（介子推）。
- **人物对唱/视角建议**：重耳×齐姜（醉遣离别）、重耳×介子推（不言禄、绵山火）、重耳×楚成王（三舍之诺）、重耳×秦穆公（渡河归国）。
- **情绪落点**：流亡之苦→逢迎之辱（窥骈胁、不礼）→恩义之暖（馈璧、赠马）→归国之决→称霸之信→寒食之憾，可构成完整叙事弧。

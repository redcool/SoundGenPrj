# 歌曲生成规则（Song Generation Rules · v1）

> 状态：生效（2026-09-21）
> 适用范围：本工程所有"歌曲/乐曲生成"流程（scripts/generate.py、extend_audio.py、cover_audio.py 及后续工具）。
> 目标：让每一次生成都**可听、可看、可复现**，产出四件套交付。

---

## 规则 1：默认中文发声

- **默认语言：中文（普通话）演唱**。style 描述中必须显式包含 `Mandarin Chinese vocals`（或 `中文人声`），歌词默认用中文书写。
- 英文/其他语言为显式例外：仅当用户明确要求时才切换（如 "English version" / "用英文唱"）。
- 中文歌词建议遵循工程惯例：
  - 歌词驱动（不锁谱）时，模型按歌词量作曲，中文咬字最准；
  - 锁谱时歌词音节数 ≈ 声乐线音符数，可明显改善咬字；
  - 用户对"重排/微改词"可接受（"完稿"即收），但主题与叙事须保持。
- 纯器乐（--no-lyrics）不受本条限制，但输出也应是默认中文风格语境（如配器、调性）。

---

## 规则 2：保存四件套（音频 / 歌词 / ABC 曲谱 / 曲谱 HTML）

每次歌曲生成，除音频本身外，**必须同时保存以下三份可见产物**，缺一不可：

| # | 产物 | 文件名约定 | 说明 |
|---|---|---|---|
| 1 | 交付音频 | `<name>.mp3`（**192kbps**，默认；见 docs/Studio渲染规范.md §五） | 交付目录：`output/yue2/`；flac 仅存引擎原生输出 |
| 2 | 歌词 | `<name>.lyrics.txt` | 最终送入模型的歌词原文（UTF-8） |
| 3 | ABC 曲谱 | `<name>.score.abc` | 从 ComfyUI Plan 节点输出提取的 `score_abc` 全文 |
| 4 | 曲谱 HTML | `<name>.html` | 用 `tools/abc-render`（abcjs v6）渲染的一页曲谱（可看/播/打印） |

### 2.1 命名
- 同一次生成的四件套共用一个主名 `<name>`（如 `三号宿舍`、`一夫当关_续写版8min`）。
- 音频交付 `output/yue2/<name>.mp3`；另三件默认放同目录（`output/yue2/`）：
  - `output/yue2/<name>.lyrics.txt`
  - `output/yue2/<name>.score.abc`
  - `output/yue2/<name>.html`

### 2.2 提取与渲染链路
1. **歌词**：即脚本输入的 --lyrics 文件内容（复制落地）。
2. **ABC**：生成提交后从 `GET /history/{prompt_id}` 的 `outputs["2"]["ui"]["text"][0]` 提取
   （FL_YuE2_Plan 节点的 ui 文本 = 状态前缀 + score_abc 全文，需剥离 "Score limit reached..." 前缀）。
3. **HTML**：调用 `node tools/abc-render/render_sheet.mjs <abc> <out.html> <title>` 渲染。

### 2.3 边界情况
- **pure 器乐 / planning=off**：若 Plan 无谱面（score_abc 为空或 "Direct generation"），ABC+HTML 允许缺省，但歌词文件仍保存（可留空占位并在 SESSION 注明）。
- **失败/截断**：即使 Render 报 `Duration limit reached`，已有的 ABC/歌词照常保存，交付说明里注明截断即可。

## 规则 3：工具落地

- `scripts/generate.py` 增加 `--save-package`（默认**开启**）：完成后自动输出四件套。
- `scripts/extend_audio.py` / 未来 `cover_audio.py` 同样遵循：续段/cover 的谱面与歌词一并保存。
- `SESSION.md` 成品索引每条记录四件套路径（音频为主，附 abc/html/歌词若有）。

---

## 规则 4：参数记录（可复现性）

- 每次生成在 `logs/` 追加一条 JSON：输入音频 sha256（若有）、style、lyrics 摘要、seed、planning、duration、
  渲染状态（complete/truncated）、四件套路径、BPM/调性分析（若有）。
- seed 固定即可复现；换词保旋律固定 seed；时长改变旋律全变（见 SESSION.md Music3 根因实验）。

---

## 变更与维护

- 规则变更需同步更新：本文档、AGENTS.md（若涉及约定）、SESSION.md（生效记录）。
- v1 起生效；四件套保存由工具自动完成，人工交付也必须自查四件套是否齐全。

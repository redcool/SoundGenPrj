# 歌词规范（分段标注版 · 2026-10-19 确立）

> 适用：input/lyrics 各曲 _lyric.txt（标准版·人看/编排用）。**每段必须以方括号标记：类别 + 该段情绪、节奏、乐器、人声**。

## 1. 每段格式

```
[verse 1，情绪，节奏，乐器，人声]
主歌歌词…

[pre-chorus，情绪，节奏，乐器]
副主歌歌词…

[chorus，情绪，节奏，乐器]
副歌歌词…

[bridge，情绪，乐器]
桥段词…
```

## 2.5 段标唯一性铁律（2026-10-19 事故后确立）

- 别字版/标准版的**段标签必须唯一**：[Verse]/[Verse 2]/[Verse 3]… 按出现顺序递增编号，禁止同名重复（[Verse 4]×8 事故：模型把重复段标当歌词唱出“verse 4”）；[Chorus]/[Chorus 2]…、[Intro][Bridge][Outro] 同理；
- **自动补段（pad）时标签不得重复**——补足循环每次插入的段必须带新序号；
- 文案：备用 fix 入口见 scripts/fix_segment_tags（JS 内联曾用）。

## 2. 类别词表（统一复用）

- 主歌：verse（可 verse 1/2/3…）
- 副主歌、过渡：pre-chorus / pre
- 副歌：chorus（重复可标 chorus 2）
- 桥段：bridge
- 终曲/尾声爆发：乱曰（楚辞收尾）或 outro
- 念白/旁白：念白 / spoken（标注 男中音/女声/群白）
- 间奏/华彩：间奏 / interlude（器乐段）

## 3. 必填与选填

- 必填：类别；该段情绪（一两个词：燃/悲/智/狂/暖…）
- 选填：节奏（BPM 或 快/中/慢/散板）、乐器（主奏+副奏，如 编钟+齐唱 / 古筝+电贝司）、人声（男中音/女声/死嗓/齐唱/对唱）
- 例：[chorus，燃·齐吼，中快 108，电吉他+战鼓+低音大鼓，齐唱]

## 4. 双版关系（2026-10-19 更新：别字版带标签）

> **目录归属铁律（2026-10-19 用户确立）**：`albums/<卷>/歌词/` 只放**正式版**（标准版原文+标签，人看/交付）；**别字版**只放 `albums/<卷>/别字歌词/`（喂 YuE2）。

> 实证：YuE2 官方**支持方括号段标**（本地仓 examples/song.json、src/yue2/cli.py 的 lyrics 即 [Verse]/[Chorus] 格式；官方 Prompting Guide 要求每段方括号标注并空行分隔）。段标还给模型结构锚点，有助段对齐（长歌“对不上”的缓解剂）。

- 标准版 _lyric.txt：含方括号标签（人看/编排/交付）。
- 别字版（喂 YuE2）：**保留方括号段标**（官方词表：[Verse] / [Pre-Chorus] / [Chorus] / [Bridge] / [Outro]；乱曰→[Outro]），正文逐字换高频同音字；标情绪/乐器的扩展注释可省略（模型用不到）。"标准版"含全部中文注释标签供人看。
> 配合：双版词规 v3 · 创作基调 v2（mid-tempo/中西配器）· 楚辞启示录 §9。
## 押韵规则（2026-10-23 用户定 · 强制）

### 核心韵式：四句一组，「1 韵、2 韵、3 可不韵、4 韵」

- 即 AABA 式（传统绝句的押韵骨架）：第 1、2、4 句**句尾押韵**，第 3 句可放开。
- 六句段可作 AAB AAB 或 AAB CCB（第 3、6 句自由）。
- 押韵看**句尾最后一个字**（韵脚），不要求每句字数相同——不是格律诗，只取韵。

### 四条硬要求

1. **段内一韵到底**：同一段（verse/chorus）内韵脚尽量同辙（如 an/ang/ai/ou 同一韵部），不混押。
2. **副歌固定韵**：chorus 反复 3-4 次，韵脚必须稳定同韵——这是记忆点的来源；不同段落可换韵。
3. **禁硬凑**：宁可换韵不可造词；为押韵牺牲语义或史实，一律不取。
4. **别字版同步**：同音替换不改变韵脚，替换后仍需押韵（替换字读音须与原字一致）。

### 写作顺序（推荐）

1. 先定**副歌金句 + 韵辙**（如 an 韵：川/山/还/寒）；
2. 主歌围绕该韵觅词，第 3 句放开写事（不必押）；
3. 全篇检查：连续两句以上句尾同字 → 视为偷懒，改写；
4. 交 audit 前自查韵脚表（每段末尾四字列出来看）。

### 常见韵辙对照（普通话）

| 韵辙 | 例字 |
|---|---|
| a（发花） | 家/花/下/杀 |
| o/e（波歌） | 河/歌/客/色 |
| i/u/ü（一七·姑苏） | 起/死/子/路/古 |
| ai（怀来） | 来/开/白/在 |
| ei（灰堆） | 谁/泪/北/罪 |
| ao（遥条） | 高/刀/老/好 |
| ou（由求） | 头/后/走/守 |
| an（言前） | 山/川/还/寒 |
| en（人辰） | 人/门/深/心 |
| ang（江阳） | 王/亡/上/长 |
| eng/ing（中东） | 城/兵/命/醒 |

> 生效范围：**此后所有新词稿强制**；已完成的旧词按需改写（不强制回改）。
## 双版歌词规则（2026-10-23 用户确认 · 强制）

### 一、两个文件，两种用途

| 文件 | 用途 | 内容 |
|---|---|---|
| `<曲>_lyric.txt` | **正常字版**：审阅 / 歌词页 / 人工演唱 / 校对 | 中文段标 `[verse 1，情绪，节奏，乐器，人声]`，保留全部正式用字与史料原话 |
| `<曲>_v1_bz_lyrics.txt` | **别字版**：**喂音频模型（yue-server / yue2.cpp / Suno）** | 段标英文化 `[Intro]/[Verse]/[Chorus]/[Bridge]/[Outro]` + 逐字同音易字 |

### 二、别字版生成（工具化，禁止手改）

```bash
python scripts/make_bz.py <曲>_lyric.txt <曲>_v1_bz_lyrics.txt
```

两步处理：
1. **段标英文化**：中文段标整条替换为官方英文标签，**段标内的情绪/节奏/乐器/人声提示全部丢弃**（否则模型会把「黑嗓」「战鼓」唱出来）；
2. **逐字同音易字**：按 `EASY` 表把难读字换成同音常用字（翚→辉、骊→梨、浞→捉、豷→意、嚭→匹、虢→国、缒→坠、佚→义、氾→凡、缯→增、邾→朱、郢→影、隗→伟、嬖→必、姒→四…）。

### 三、易字铁律

1. **只换读音不换义**：同音/近音替换，语义核心词（弑、崩、薨、诛）**不动**；
2. **人名易字后仍须一一对应**（正文易字，文案/歌词页保留原名）；
3. **替换后仍要押韵**（同音替换天然满足）；
4. 表里没有的难字：先查读音，再补进 `scripts/make_bz.py` 的 EASY 表，**不要临时手改文件**。

### 四、渲染检查（每次渲染前）

- [ ] `yue_render.py --lyrics` 指向的是 **`_v1_bz_lyrics.txt`**（不是 `_lyric.txt`）
- [ ] 该 bz 文件由 `make_bz.py` 生成（段标为英文、无表演提示、难字已易）
- [ ] `audit_lyrics.py` 结论 PASS（会同时校验 bz 使用官方段标）

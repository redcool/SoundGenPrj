# 歌词规范（分段标注版 · 2026-10-19 确立）

> 适用：input/lyrics 各曲 _lyric.txt（标准版·人看/编排用）。**每段必须以方括号标记：类别 + 该段情绪、节奏、乐器、人声**。

## 1. 每段格式

```
[verse 1，情绪，节奏，乐器，人声]
主歌歌词…

[pre-chorus，情绪，节奏，乐器]
副主歌歌词…

[chorus，情绪，节奏，乐器]
副歌歌词…

[bridge，情绪，乐器]
桥段词…
```

## 2. 类别词表（统一复用）

- 主歌：verse（可 verse 1/2/3…）
- 副主歌、过渡：pre-chorus / pre
- 副歌：chorus（重复可标 chorus 2）
- 桥段：bridge
- 终曲/尾声爆发：乱曰（楚辞收尾）或 outro
- 念白/旁白：念白 / spoken（标注 男中音/女声/群白）
- 间奏/华彩：间奏 / interlude（器乐段）

## 3. 必填与选填

- 必填：类别；该段情绪（一两个词：燃/悲/智/狂/暖…）
- 选填：节奏（BPM 或 快/中/慢/散板）、乐器（主奏+副奏，如 编钟+齐唱 / 古筝+电贝司）、人声（男中音/女声/死嗓/齐唱/对唱）
- 例：[chorus，燃·齐吼，中快 108，电吉他+战鼓+低音大鼓，齐唱]

## 4. 双版关系（2026-10-19 更新：别字版带标签）

> **目录归属铁律（2026-10-19 用户确立）**：`albums/<卷>/歌词/` 只放**正式版**（标准版原文+标签，人看/交付）；**别字版**只放 `albums/<卷>/别字歌词/`（喂 YuE2）。

> 实证：YuE2 官方**支持方括号段标**（本地仓 examples/song.json、src/yue2/cli.py 的 lyrics 即 [Verse]/[Chorus] 格式；官方 Prompting Guide 要求每段方括号标注并空行分隔）。段标还给模型结构锚点，有助段对齐（长歌“对不上”的缓解剂）。

- 标准版 _lyric.txt：含方括号标签（人看/编排/交付）。
- 别字版（喂 YuE2）：**保留方括号段标**（官方词表：[Verse] / [Pre-Chorus] / [Chorus] / [Bridge] / [Outro]；乱曰→[Outro]），正文逐字换高频同音字；标情绪/乐器的扩展注释可省略（模型用不到）。"标准版"含全部中文注释标签供人看。

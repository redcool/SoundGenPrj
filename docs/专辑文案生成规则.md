# 专辑文案生成规则 v2（2026-10-15 确立 · 六节标准体例）

> 配套：docs/history-rock/专辑制作规范.md。本文=「文案+封面」成文规则；正式体例见下，用户已建文案（夏/西周 Vol.1）保留不覆盖。

## 0. 硬性要求
- **每张专辑根目录必须有 `albums/<专辑名>/专辑文案.md`**（发布主件；`文案/专辑文案.md` 同内容同步）
- **用户已建的根目录文案一律保留、不覆盖**；生成器“先查存在、只补不缺”
- 封面全量进 `albums/<专辑名>/封面/`；曲目推介语进 `文案/<歌名>_文案.txt`

## 1. 专辑文案.md · 六节标准体例（顺序固定）

### 一、专辑名字 | 意境
- 专辑名（如 义名之歌·战国 Vol.1）+ 副标题
- 意境：一句话（地点/意象/情绪，如“云梦泽畔·汨罗江·楚辞神游·战国开卷”）

### 二、专辑简介（喜马拉雅简介，约 200-300 字）
- 前言散文 + 本卷立意 + 卷首人物 1-2 句 + 声音概览

### 三、专辑标签（喜马拉雅推荐 ≤20）
- 逗号分隔，≤20 个（如 历史摇滚,楚辞,战国,屈原,求索,古典文学,中文摇滚,民族摇滚,古风,史诗,人文,历史…）

### 四、卖点（专辑页卖点区 / 图文卡）
- 曲目与推介语表（`| # | 曲目 | 人物 | 一句推介 |`）
- 听感指引（按情绪/场景推荐曲）
- 数据点（版本数/时长范围/四件套齐备）

### 五、封面图（Agnes / GPT Image 2 生成首选）
- **主通道：ignis GPT Image 2**（可写中文→专辑名/歌名可入图）；**Agnes 兜底**（免 key，纯意象不加字）
- 命名：专辑《专辑名>_专辑封面.png`；歌曲 `<歌名>_朝代_年代_人名.png`；全入 `albums/<卷>/封面/`
- 此节写明：封面现状 + ignis 提示词（供用户侧运行，跑完替换）

### 六、发布清单（Checklist）
- 逐项：专辑信息.md ✓ / 专辑文案.md ✓ / 封面（专辑+各曲）✓ / 歌曲四件套（mp3 320k/歌词/ABC/HTML）✓ / 时长≥格式达标 ✓ / 人名规范（本名）✓ / 时间线审查 ✓ / 别字版（标准版不动）✓ / 双版词 ✓ / 发布时间待定

## 2. 语气与长度
- 简介 200-300 字；卖点可到 500 字（含表）；标签 ≤20；其余节可短
- 人文向、有场景感、以史料钩子为核、不做夸张承诺

## 3. 封面规则（重申）
- ignis GPT Image 2 首选（中文可入图）；Agnes 兜底（意象为主、避免文字）
- 命名与位置见“五”；产出即入专辑目录

# 歌词审核规范（2026-10-19 确立 · 每曲写词后必审，全过才进渲染）

> 用法：每写完一份歌词（标准版 + 别字版），照本文件逐条打勾；**任一未过 → 先改到过再审**，通过后才允许渲染。

## A. 结构审核

- [ ] 标准版每段以方括号开头，含 [类别，情绪]（可加：节奏、乐器、人声）
- [ ] **段标唯一性**：全文件 [Verse]/[Chorus] 等标签无重复名（[Verse]/[Verse 2]/[Verse 3]…严格递增）
- [ ] 类别用既定词表：verse / pre-chorus / chorus / bridge / 乱曰(outro) / 念白(spoken) / 间奏(interlude)
- [ ] 别字版标签用官方词表：[Intro]/[Verse]/[Verse N]/[Pre-Chorus]/[Chorus]/[Chorus N]/[Bridge]/[Outro]，同样唯一递增
- [ ] 段间空行分隔

## B. 词量审核（短歌）

- [ ] 标准版不含标签正文 **≈520-620 字**（4 分钟档；慢拍/颂歌类压到 ~530 防截断）
- [ ] 副歌重复 ≤4 次；重复块标签按轮次编号（Chorus/Chorus 2/…）
- [ ] **禁止同文垫段**：补满词量只能用真人物事件/新画面，不得整段重复相同文字（auto-pad 曾同一段插 8 次=事故）
- [ ] 无自动 pad 造成的标签重复（pad 补段每次必带新序号）

## C. 内容与史料审核

- [ ] 含“一句话核心”（写入 meta）；副歌=核心金句
- [ ] 意象锤 ≥3 次（统一意象）；起承转合结构；有提问/对话钩子
- [ ] 白话叙事 × 关键句文言金句；鼓励向（悲不沉溺，唤醒后人）
- [ ] 史料先行：《歌名_…_史料检索.md》已入 stories；正史/演义分层标注
- [ ] 时间线审查：同句并列人物须同代；后世人物带“数百年后/后世”时间框架
- [ ] 人名规范：文件名用本名（姬昌/姜尚…）；商代通行名沿用并注明

## D. 别字版审核

- [ ] 标准版为唯一母版（永不改动）；别字版逐字映射高频同音（同调优先）
- [ ] 易字守则：生僻→常用；通假→通行（被→披、反→返）；多音人名别字（傅说→傅悦）；专名保留
- [ ] 别字版不得包含人看的扩展注释/情绪词（除官方标签）
- [ ] 目录归属：`歌词/`=正式版；`别字歌词/`=别字版

## E. 自动工具

- [ ] 跑 scripts/audit_lyrics.py <标准版> <别字版>：查 段标重复 / 词量带 / 官方标签词表 / 常见占用字符 ‖ 结果全绿方准渲染

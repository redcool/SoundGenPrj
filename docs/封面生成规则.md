# 专辑封面生成规则（2026-10-23 定稿）

## 一、基本规则

1. **每个专辑只出 1 张专辑封面**（旧规则），**不再生成单曲封面**（旧单曲封面保留不删）。
2. **封面 2 抽制**（2026-10-23 用户定）：每张封面生成两版，双通道并行取优：
   - **抽 1 = ignis（gpt-image）**
   - **抽 2 = Agnes（agnes-image-2.5-flash，免费）**
3. 两版**全部保留**（不删不破坏），择优标注为主推，另一版留档对比。
4. **可选第 3 抽 = MOSS-Image（本机 ComfyUI）**：6-10 秒/张，质量接近 gpt-image2，适合快速试稿与多版本对比；用法见 `docs/MOSS出图指南.md`，命名 `<专辑>_专辑封面_v3_moss.png`。

## 二、命名与尺寸

- 命名：`<专辑名>_专辑封面_v<N>_<通道>.png`
  - 通道标识：`gptimage`（ignis）/ `agnes`（Agnes）
  - 例：`义名之歌-春秋卷1_专辑封面_v1_gptimage.png` / `..._v2_agnes.png`
- 尺寸：原图（ignis 2048×2048 / agnes 1024×1024）→ 输出 **1024×1024** 与 **800×800** 两档
- 存放：`albums/<专辑>/封面/`

## 三、抽 1：ignis（gpt-image）

```powershell
$env:USERPROFILE='H:\Works\FeiTuPrj_H3\.tools\fake-home'
& 'H:\Works\FeiTuPrj_H3\.tools\ignis\node_modules\.bin\ignis.cmd' imagine "<英文 prompt>" --model gpt-image --ar 1:1 --out H:\Works\SoundGenPrj\tmp\ignis_out
```
- 下载物在 `tmp/ignis_out/`，用 ffmpeg 缩放到 1024/800 后入库。
- **限流**：Cloudflare `origin_bad_gateway / retryable: true / retry_after 60` → **等 ≥120 秒重试一次**。
- **中文标题风险**：gpt-image 渲染中文易成乱码，建议 prompt **不写标题文字**，标题后期叠加或人工确认。

## 四、抽 2：Agnes（agnes-image-2.5-flash）

- 工具：`agnes_generate_image`（MCP），参数：`prompt`（英文/中文均可，自动翻译）、`size: "1024x1024"`、`model: "agnes-image-2.5-flash"`。
- 结果返回 URL + 本地 `agnes-output/` 副本；取本地文件缩放 1024/800 入库。
- 若需多版，可同 prompt 重抽（seed 不固定），取最好一版。

## 四点五、文字规则（2026-10-23 用户定 · 强制）

1. **封面上只出现专辑名一行**（如「恶名之歌·春秋」）。
   - **不要**副标题、不要「Vol.1」、不要曲目数、不要作者名、不要英文。
2. **字体必须有气势**：书法体或超粗黑体，不用常规黑体/宋体。
   - 可用（本机）：`STXINGKA`（华文行楷）、`STHUPO`（华文琥珀·超厚）、`STLITI`（隶书）、`FZSTK`（方正舒体）、`STKAITI`（楷体）、`msyhbd`（粗黑）
   - 推荐工艺：**金属渐变填充（金/朱砂红/钢银）+ 黑色描边 + 高斯阴影**，字号 130-170（1024 画布）。
3. 两条实现路线：
   - **A. 模型直出**（MOSS / gpt-image）：在 prompt 里写书法字体与材质，靠模型出字形；字形需目验；
   - **B. 底图 + 程序叠字**（`scripts/cover_text.py`）：字形 100% 准确，风格可控（渐变/描边/位置）。
4. 定稿标准：标题一眼压得住画面，其余信息一律放专辑文案里。

## 五、Prompt 结构（两通道共用）

1. **主题**：专辑朝代/人物/核心意象（如：春秋=盟坛/编钟/竹简/戈与酒爵）
2. **构图**：方形 1:1，主体居中偏下，上方留标题位
3. **风格**：水墨质感 × 现代摇滚海报颗粒；青铜金 / 玄黑 / 朱砂红 主色
4. **光效**：戏剧性边缘光，电影感
5. **负面**：不要文字、不要乱码、不要多手多指、不要现代物件

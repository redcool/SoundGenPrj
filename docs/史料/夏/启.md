# 启

## 基本信息
- 时代：夏初（约前 21 世纪）
- 身份：禹之子、夏后氏第二王；「家天下」（世袭制）的开创者
- 关键事件：甘之战（伐有扈氏）、钧台之享

## 生平年表
1. **继位之争**：禹崩，本应禅位于伯益；「诸侯皆去益而朝启」——启遂即天子位（《史记·夏本纪》）；另说启杀益夺位（《竹书纪年》系统，属后世异说）。
2. **甘之战**：有扈氏不服，启伐之，作《甘誓》：「有扈氏威侮五行，怠弃三正，天用剿绝其命」；战于甘，灭有扈氏（《尚书·甘誓》《史记·夏本纪》）。
3. **钧台之享**：启在钧台（今河南禹州）大会诸侯，确立共主地位。
4. **晚年**：好音乐（「启九辩与九歌」《楚辞·离骚》）；子太康继位，夏政渐衰。

## 主要事迹
- **家天下之始**：由「禅让」转「世袭」，中国政治制度史的最大转折之一。
- **《甘誓》**：中国最早的军令/战前动员文献之一，确立「恭行天罚」的战争正当性话语。
- **有扈氏之灭**：以武力压服反对派，巩固新制度。

## 金文/考古佐证
- 二里头文化早期（约启—太康）出现宫殿基址、青铜礼器与绿松石龙形器，与该时期的「王朝化」相符。
- 「甘」地望有陕西户县、河南洛阳等说。

## 传说层辨析
- **得位方式**：禅让（《史记》《孟子》）vs 夺位（《竹书纪年》《韩非子》）——两说并存，本档并列。
- **「启九辩九歌」**：《楚辞》所述，属文学化记忆。
- **「启母石」**：神话层。

## 后世评价
- 儒家对「家天下」评价复杂：承认「继世」之实，却以「选贤与能」为理想（《礼记·礼运》）。
- 「大人世及以为礼」——启是这一礼制的起点。

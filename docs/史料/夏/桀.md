# 桀（履癸）

## 基本信息
- 时代：夏末（约前 17 世纪，传统系年前 1652—前 1600 在位）
- 身份：夏后氏第十七王、夏朝末代君主；名履癸，谥桀（一说「桀」为恶谥）
- 定性：与商纣并称中国「暴君之首」的原型

## 生平年表
1. **继位**：发之子履癸即位；时夏室已衰，诸侯多叛。
2. **暴政**：「桀不务德而武伤百姓，百姓弗堪」（《史记·夏本纪》）；以力役、征伐耗民。
3. **酒池长夜**：传统叙事记其「以酒为池，悬肉为林」「长夜之饮」，为后世暴君母题的定型细节（《史记·殷本纪》记纣事更详，桀事细节多经《列女传》《帝王世纪》层累）。
4. **拒谏杀贤**：关龙逢直谏，桀焚其黄图而杀之（《韩诗外传》等）；太史令终古抱图法奔商（《吕氏春秋·先识》）。
5. **鸣条之战（约前 1600）**：商汤兴师，作《汤誓》，与桀战于鸣条；夏师败绩，桀走南巢（一说死于鸣条），夏亡。
6. **结局**：「汤遂伐三嵕，俘厥宝玉，放桀于南巢」（《史记·夏本纪》）。

## 主要事迹
- **末代暴君的形象**：拒谏、杀贤、纵欲、虐民——成为后世「亡国之君」的模板。
- **鸣条之战的败者**：中国历史上第一次有明确记载的「革命」式改朝换代的对手。
- **「时日曷丧」**：民众诅咒语「时日曷丧？予及汝皆亡」（《尚书·汤誓》），是民怨的直接记录。

## 金文/考古佐证
- 二里头文化（河南偃师，多数学者视为夏文化）晚期与夏商交替相关；桀本人无直接器物。
- 鸣条地望有山西夏县、河南封丘等说。

## 传说层辨析
- **酒池肉林、长夜之饮**：细节多属后世层累（《列女传》系统），《史记·夏本纪》对桀的描写远简于纣。
- **妹喜（末喜）**：正史仅记「有宠」；「祸水亡夏」为后世建构，本工程不单列其恶名曲。
- **「桀作瓦屋、为璇室」**：传说层。

## 后世评价
- 《尚书·汤誓》以「天命」定其罪；孟子谓「汤武革命，顺乎天而应乎人」。
- 与纣并称「桀纣」，成为暴政的代名词。
- 现代史学：夏亡是长期积弱与东方商族崛起的结果，桀的个人失德是叙事性归因之一。

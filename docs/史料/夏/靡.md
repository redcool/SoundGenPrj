# 靡

## 基本信息
- 时代：夏中前期（少康时，约前 19 世纪）
- 身份：夏之遗臣、有鬲氏之臣；少康复国的核心助力
- 文献：《左传·哀公元年》

## 生平年表
1. **夏亡之际出奔**：寒浞篡政、杀相之后，靡逃奔有鬲氏（今山东德州一带）。
2. **收夏众**：靡在有鬲氏「收二国之烬」（收聚夏之遗民），积聚力量。
3. **佐少康灭浞**：「靡自有鬲氏收二国之烬，以灭浞而立少康」（《左传·哀公元年》）。
4. **复国之后**：少康中兴，靡为功臣（具体职位不详）。

## 主要事迹
- **保存火种**：在夏室几近灭绝时，以遗臣身份收聚残众，是复国的组织基础。
- **「二国之烬」**：与有鬲氏、有仍氏等夏之同姓/姻亲势力联合，形成反寒浞联盟。

## 金文/考古佐证
- 有鬲氏地望（山东德州）考古线索有限；靡本人无器物。

## 传说层辨析
- **「二国」所指**：一说斟灌、斟鄩（夏之同姓），一说有鬲与有仍，学界有讨论。
- 《左传》记载极简，「收烬」的具体过程不详。

## 后世评价
- 传统：忠臣复国的典范——不是主角，却是「不可或缺的人」。
- 与关龙逢（死谏）、终古（弃官）构成夏代士人的三种选择：死、去、留而图复。

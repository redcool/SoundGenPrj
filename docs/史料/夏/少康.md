少康（姒姓，夏后氏）是中国夏朝的第六任君主，是大禹的玄孙、夏启的曾孙、夏后相的儿子。他开创了中国历史上著名的“少康中兴”，是夏朝生死存亡之际扭转乾坤的关键人物。

一、 传奇的身世与流亡背景

• 太康失国与寒浞代夏：夏朝传至太康、仲康、相时，国势渐衰。东夷部落的有穷氏首领后羿趁机夺取政权（史称“后羿代夏”）。随后，后羿被其亲信寒浞所杀，寒浞不仅篡位，还派子浇和豷赶尽杀绝夏后氏的后代。
• 遗腹子逃亡：当时，夏后相已被寒浞杀害，相的妻子后缗（有仍氏之女）已经怀有身孕，她从狗洞爬出逃往娘家有仍氏，生下了遗腹子——少康。
• 艰难成长：少康从小在母亲和有仍氏的庇护与教导下长大。母亲经常向他讲述先祖大禹开创夏朝的丰功伟绩，激励他胸怀复国大志。由于寒浞势力仍在搜捕，少康被迫辗转逃往有虞氏（虞思处），并得到有虞氏的大力支持，将两个女儿嫁给他，并给了他纶邑作为根据地，当时他手下仅有一成田、一旅之师（约500人）。

二、 少康中兴的主要过程

少康以微弱的实力起步，采取了极具谋略的复国手段：
1. 争取旧臣：联络夏朝的忠臣旧部，如早年逃脱的夏朝大臣伯靡。
2. 使用间谍：派女艾去探听敌方（浇、豷）的虚实。
3. 内外配合：派儿子季抒诱杀敌方将领豷，自己则率军对寒浞及其儿子发起致命攻击，最终彻底消灭了寒浞父子，收复了过、戈等失地。
4. 重建夏朝：少康重新恢复了夏后氏的统治，定都于纶邑（后又迁都），史称“少康中兴”，这也是中国历史上第一个被称为“中兴”的时代。

三、 历史功绩与影响

• 延续国脉：少康在位期间勤政爱民、选贤任能，恢复并巩固了夏朝的世袭统治制度，使险些覆灭的夏王朝重新强盛起来。
• 后世地位：少康的逆境重生与卧薪尝胆 式复国，被后世儒家典籍与历史学家高度赞誉，其子杼继承王位后，夏朝国力达到了极盛。

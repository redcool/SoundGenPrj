# 赵梁

## 基本信息
- 时代：夏末（桀时，约前 17 世纪）
- 身份：夏桀之相国/宠臣，谄媚进言之佞臣
- **史料性质：正史《史记·夏本纪》无赵梁之名**；其事主要见于汉代以下文献（《说苑》《新序》《帝王世纪》一系）与类书转引 → **属「后出文献」层，本档明确标注，非当世实录**。

## 事迹（据后出文献归纳）
1. **教桀为无道**：怂恿桀大兴土木（璇室、瑶台）、纵酒长夜，以「王天下者当极耳目之欲」之说进谄。
2. **排挤直臣**：与关龙逢等直谏之臣对立，助桀拒谏；关龙逢献黄图而被杀，赵梁被视为推手之一。
3. **助纣为虐的模板**：后世以「桀有赵梁，纣有费仲」并称，作为「佞臣亡国」的对称叙事。

## 史料辨析（重要）
- **可靠性**：先秦可靠文献（《尚书·汤誓》《左传》《国语》）均未提及赵梁；《史记》亦无。其名始见于汉人杂史与说苑类书，故**只能作为『后世附会的佞臣形象』使用**，不可当作夏代信史人物。
- **为何仍入册**：本卷为「恶名」主题，赵梁是「谄媚亡国」母题在这一时代最常被引用的符号；本工程按「后出文献·标注使用」处理（与《灭赵》屠岸贾同类做法）。
- **不可做的事**：不给他编造夏代官职细节、不虚构他与关龙逢的具体对话场景（歌词以母题化方式处理）。

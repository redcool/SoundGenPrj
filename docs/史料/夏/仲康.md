# 仲康

## 基本信息
- 时代：夏初（约前 20 世纪）
- 身份：太康之弟、夏后氏第四王；后羿所立之傀儡君主
- 相关：中国最早的日食记录（「仲康日食」，学界有争议）

## 生平年表
1. **后羿立之**：太康失国，后羿立仲康为夏王（《史记·夏本纪》）。
2. **夏政名存实亡**：仲康在位，政令出自后羿。
3. **「仲康日食」**：《尚书·胤征》载「乃季秋月朔，辰弗集于房」——传统视为仲康时的日食记录（学界对具体年份有争议，一说前 2137 年，一说为伪古文尚书所造）。
4. **崩**：子相即位。

## 主要事迹
- **傀儡之君**：中国最早的「名义君主」样本之一。
- **日食记录**：若成立，是中国最早的日食记载，天文史意义重大（真伪有争议）。

## 金文/考古佐证
- 无直接器物；日食记录依赖文献。

## 传说层辨析
- **仲康日食**：出自《古文尚书·胤征》，晚出文本，学界多认为不可靠，但天文史学界有推算尝试。
- 仲康本人的事迹几乎空白。

## 后世评价
- 传统：失国之君序列中的过渡人物。
- 政治学角度：名义君主与实际权力的分离，是中国政治史的早期样本。

## 交叉索引
- 相关：太康（兄）、后羿（实际掌权者）、相（子）
- 曲目：可并入恶名-夏-卷1《代夏》（后羿）叙述

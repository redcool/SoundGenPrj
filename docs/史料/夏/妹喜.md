# 妹喜（末喜）

## 基本信息
- 时代：夏末（桀时，约前 17 世纪）
- 身份：有施氏之女、夏桀之妃（一说元妃）
- 定性：中国传统「红颜祸水」叙事的源头之一；本工程按「被污名者」处理，**不单列恶名曲**

## 生平年表
1. **有施氏献女**：桀伐有施，有施氏进妹喜以请降（《国语·晋语一》「昔夏桀伐有施，有施人以妹喜女焉」）。
2. **得宠**：妹喜有宠，桀纵其欲；传说「妹喜好闻裂缯之声」「好观酒池」等（后出文献）。
3. **「与伊尹比而亡夏」**：《国语·晋语》「妹喜有宠，于是乎与伊尹比而亡夏」——一说其为商汤间谍，属传说层。
4. **结局不详**：夏亡后下落不明（一说随桀奔南巢）。

## 主要事迹
- 正史中她几乎没有独立行动，全部依附于桀的宠爱。
- 「裂缯」「酒池」等细节出自《帝王世纪》《列女传》一系，属后世层累。

## 金文/考古佐证
- 无。二里头文化无与妹喜相关的任何证据。

## 传说层辨析（重点）
- **「红颜祸水」叙事**：先秦仅《国语》一句「有宠」，将亡国归因于女性是汉代（刘向《列女传》）的系统建构。
- **「与伊尹比」**：若成立，妹喜是「女间谍」，则其形象彻底反转——学界对此说多持谨慎态度。
- **本工程立场**：同妲己、褒姒，不单列恶名曲，在《长夜》（桀）中作「被历史甩锅者」一笔带过。

## 后世评价
- 传统：亡夏的祸首之一（与桀并列）。
- 现代：史学界普遍认为夏亡是长期积弱与商族崛起，妹喜被过度归因。

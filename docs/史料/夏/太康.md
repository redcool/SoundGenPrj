# 太康

## 基本信息
- 时代：夏初（约前 20 世纪）
- 身份：启之子、夏后氏第三王
- 结局：因游猎失国，夏政为后羿所夺

## 生平年表
1. **继位**：启崩，太康即位（一说启五子争立，太康得位）。
2. **盘于游田**：「太康盘于游田，不恤民事」，畋于洛水之表，「十旬弗反」（《尚书·五子之歌》《史记·夏本纪》）。
3. **失国**：有穷氏后羿「因民弗忍，距于河」，太康不得归国，夏政遂失。
4. **流亡以终**：太康居洛汭，其弟五人作《五子之歌》以怨之（《尚书·五子之歌》）。

## 主要事迹
- **失国之君**：夏朝第一次中断（太康失国—后羿代夏—寒浞篡政，历数十年）。
- **反面教材**：后世以「太康失邦」与「启之子」的对照，说明「家天下」的守成难题。

## 金文/考古佐证
- 二里头文化早期（启—太康时）考古可见都邑与礼制形成，但无法对应具体王世。
- 洛水一带（今河南洛阳）有相关地望传承。

## 传说层辨析
- **「十旬弗反」**：数字为叙述性概括。
- **《五子之歌》**：古文《尚书》篇目，学界多认为晚出（伪古文），但「民惟邦本，本固邦宁」的思想价值不可废。
- **后羿代夏的性质**：篡政而非改朝（有穷氏仍奉夏后氏之名）。

## 后世评价
- 传统：失德失国的第一例，「逸豫可以亡身」的早期样本。
- 与桀并列，构成夏「兴—衰」叙事的中段。

在夏朝历史中，“浇”（jiāo）与“豷”（yì）是夏朝“太康失国”至“少康中兴”期间的关键反派人物。他们是篡位者寒浞（hán zhuó）的两个儿子，也是夏朝复国路上的主要覆灭对象。
以下为您带来关于“浇”与“豷”的详细中文历史讲解：

1. 历史背景与身世

夏朝建立初期，大禹的孙子太康沉迷打猎、荒废政事，东夷有穷氏的首领后羿（即神话中后羿的原型）趁机发动政变，控制了夏朝，史称“太康失国”或“后羿代夏”。
然而，后羿夺权后也同样沉迷于畋猎，不理朝政。他重用了一个叫寒浞的人。寒浞野心勃勃，勾结后羿的部下杀死了后羿，夺取了政权并自立为王。
寒浞篡位后，生了两个儿子，即浇和豷：
• 浇（寒浇 / 过浇）： 被封在“过”地（今山东莱州西北），建立了“有过氏”。
• 豷（寒豷）： 被封在“戈”地（今河南商丘、新郑一带），建立了“有戈氏”。

2. 浇与豷的特征与罪行

在史书记载中，这两兄弟尤其是浇，拥有极强的武力，但性格残暴。
• 寒浇： 传说他力大无穷，甚至能“陆地行舟”（在陆地上推着船走）。他作为寒浞的急先锋，为了斩草除根，率兵攻打并杀死了当时流亡的夏朝君主“相”（少康的父亲），并残酷消灭了拥护夏朝的斟灌氏和斟寻氏部族。
• 寒豷： 相对其兄长，关于他的个人勇武记载较少，但他镇守戈地，与兄长一东一西，成为寒浞政权统治中原的两大军事支柱。

3. “少康中兴”与两人的结局

夏王“相”被杀时，他的妻子（缗）怀着身孕从墙洞逃走，生下了少康。少康长大后，立志复国，积蓄力量。要恢复夏朝，就必须除掉寒浞及其两只“鹰犬”——浇和豷。
少康和他的部下通过极其精妙的谋略，将两兄弟分别击破：
• 女艾谍浇（少康灭浇）：
少康派出中国历史上记录的第一位女间谍——女艾，潜入浇的封地（过地）进行刺探和分化瓦解。在掌握了浇的行踪和弱点后，少康亲自带兵大举进攻有过氏。少康在打猎时放出猎犬咬伤了浇，最终将其斩杀，灭亡了有过氏。
• 季杼诱豷（杼杀豷）：
消灭浇之后，少康的儿子季杼（后来的夏王杼）负责解决镇守戈地的豷。季杼采用诱敌、设伏的计策，成功在戈地杀死了豷。

总结

随着浇和豷两兄弟被彻底消灭，寒浞彻底孤立无援，最终被夏朝遗臣靡和少康的大军攻杀，断绝了寒氏一族。
少康成功夺回了禹的基业，重登天子之位，史称“少康中兴”。在《论语·宪问》中，甚至提到了“奡（浇）荡舟，不得其死然”，以此来警示人们，空有武力而无德行的人，最终不会得到好下场。

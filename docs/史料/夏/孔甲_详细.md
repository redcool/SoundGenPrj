孔甲（生卒年不详）是夏朝的第十四任君主。他在中国历史上非常有名，但名声大多不好，被《史记》等古籍记载为夏朝由盛转衰的关键转折人物（即“孔甲乱夏”）。
关于孔甲，最核心的讲解可以分为以下四个部分：

1. 王位的“失而复得”

孔甲的父亲是帝不降（夏朝在位时间最长的君主）。按照世袭制，孔甲本该直接继承王位，但他生性乖僻、喜好鬼神、不务正业。他的父亲担心他治理不好国家，便打破常规，将王位传给了弟弟扃（孔甲的叔叔）。
扃死后，传位给儿子廑（孔甲的堂弟）。然而，廑在位时天灾不断，群臣认为这是没有让长房长子孔甲继位、违背了天意，于是在廑死后，绕了一大圈的王位最终还是传回到了孔甲手中。

2. 荒淫乱政：夏朝衰落的开端

孔甲继位后，并没有珍惜得来不易的王位，而是变本加厉：
• 迷信鬼神： 他极其沉迷于占卜和祭祀，甚至喜欢自己装扮成鬼神，搞得朝廷乌烟瘴气。
• 肆意淫乱： 终日沉湎于美酒、歌舞与享乐之中。
• 诸侯叛离： 因为他的荒唐统治，原本臣服于夏朝的各部落首领和诸侯纷纷选择背叛，夏朝的统治根基开始动摇。《国语》评价他：“孔甲乱夏，四世而陨”，意思是孔甲扰乱了夏朝，传了四代（孔甲 → 皋 → 发 → 桀）夏朝就灭亡了。

3. 最著名的历史典故：“孔甲养龙”与“食龙肉”

这是关于孔甲流传最广、最具神话色彩的故事（记载于《左传》和《史记》）：
• 天降双龙： 传说上天降下了两条龙（一雌一雄），孔甲非常高兴，但他自己不会养，一时间也找不到专门养龙的“豢龙氏”。
• 刘累充数： 陶唐氏（尧帝）的后裔刘累曾学过几天驯龙术，便跑来为孔甲效力，孔甲高兴地赐他姓氏为“御龙氏”。
• 偷烹雌龙： 谁知刘累学艺不精，没多久就把那条雌龙给养死了。刘累害怕被治罪，索性“一不做二不休”，把死龙肉做成美味的肉酱（醢）献给孔甲吃。
• 孔甲食龙： 孔甲吃后大加赞赏，觉得人间美味，没过几天又向刘累讨要龙肉酱。刘累实在变不出来，害怕事情败露，便连夜收拾行李逃亡到了鲁县（今河南鲁山）。
💡 历史学家的推测： 现代学者普遍认为，上古传说中的“龙”大概率不是神话中的五爪金龙，而是某种当时极为罕见或体型巨大的水兽（如巨型鳄鱼、扬子鳄等），刘累实际上是一个早期驯兽师。

4. 文化的另一面：东方音乐的始祖

虽然在政治上是个昏君，但孔甲在文艺上却颇有天赋。根据《吕氏春秋》记载，孔甲曾因为怜悯养子的悲惨遭遇，感叹之余创作了《破斧之歌》。这首乐曲被认为是中国历史上有记载的“东音”（东方音乐风格）的开端。

总结

孔甲是历史长河中一个典型的“文艺青年当皇帝”的悲剧。他性格乖张、迷信荒唐，虽然在音乐上留下了痕迹，但在政治上却彻底撕开了夏王朝走向灭亡的裂口。他的曾孙，就是中国历史上大名鼎鼎的末代暴君——夏桀。

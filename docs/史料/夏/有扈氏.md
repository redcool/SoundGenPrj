# 有扈氏

## 基本信息
- 时代：夏初（约前 21 世纪）
- 身份：夏后氏同姓诸侯（姒姓，一说为东夷集团），封地在扈（今陕西户县一带）
- 事件：不服启继位而起兵，战于甘，败灭（《尚书·甘誓》《史记·夏本纪》）

## 生平年表
1. **禹崩启继**：禹崩，启以世袭继位，有扈氏不服。
2. **起兵**：「有扈氏不服，启伐之，大战于甘」（《史记·夏本纪》）。
3. **《甘誓》**：启作誓师之辞，斥有扈氏「威侮五行，怠弃三正」。
4. **败灭**：有扈氏战败，「遂灭有扈氏，天下咸朝」（《史记·夏本纪》）。

## 主要事迹
- **世袭制的第一次抵抗**：有扈氏之叛，是「禅让 vs 世袭」之争的武力表现。
- **《甘誓》的对手**：因这场战争，「恭行天罚」的战争话语被发明。

## 金文/考古佐证
- 「甘」地望（陕西户县）有考古线索；有扈氏器物未见。

## 传说层辨析
- **有扈氏的身份**：传统认为同姓诸侯（姒姓），部分学者认为属东夷集团。
- **「威侮五行，怠弃三正」**：罪名为誓辞所定，实际争端核心是继位合法性。

## 后世评价
- 传统：叛逆者的早期典型。
- 政治史角度：其实是「制度变革中的牺牲者」——旧秩序（禅让）的最后抵抗。

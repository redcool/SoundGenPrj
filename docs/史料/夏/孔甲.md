# 孔甲

## 基本信息
- 时代：夏中晚期（约前 18—前 17 世纪）
- 身份：夏后氏第十四王（不降之子，一说扃之子）
- 定性：「孔甲好方鬼神，事淫乱，夏后氏德衰，诸侯畔之」——夏由盛转衰的分界

## 生平年表
1. **继位**：不降崩（不降传位与弟扃，扃传子廑，廑崩后孔甲继位——世系有异说）。
2. **崇鬼神**：「好方鬼神，事淫乱」，荒于政事，诸侯离心（《史记·夏本纪》）。
3. **豢龙传说**：天降二龙（一说雌雄），孔甲不能食（饲养），求陶唐氏之后刘累豢龙，赐氏「御龙」（《左传·昭公二十九年》）。
4. **衰世之始**：「夏后氏德衰，诸侯畔之」——夏自此不振，至桀而亡。

## 主要事迹
- **转折点**：夏朝由「少康中兴—杼—槐」的稳定期转向衰亡期的标志性君主。
- **豢龙氏**：中国最早的「御龙」传说，后世成为姓氏（御龙氏→豕韦氏）源流故事。

## 金文/考古佐证
- 二里头文化三期以后出现的变化（都邑废弃、区域中心转移）可与「夏政衰」对读，但无法直接对应孔甲。
- 「孔甲」之名见于《史记》，无器物。

## 传说层辨析
- **豢龙**：显然是神话/传说层（龙为神话动物），但「御龙氏」的族氏记忆可能有史影。
- **孔甲的世系**：不降之子 vs 扃之子，古书异说并存。

## 后世评价
- 传统：荒政崇鬼的失德之君，夏衰的起点。
- 与桀相区别：孔甲是「衰之始」，桀是「亡之终」。

# 后羿（有穷氏）

## 基本信息
- 时代：夏初（约前 20 世纪）
- 身份：有穷氏（今山东德州一带）之君、善射者；乘太康失德代夏政
- 重要的同名异人辨析：此「后羿」为历史人物（夏代篡政者）；「羿射九日」为神话人物，二者本非同源，汉以后渐混

## 生平年表
1. **有穷氏之君**：「羿」为东夷有穷氏首领，以善射名。
2. **因民弗忍**：太康游猎不恤民，羿「因民弗忍，距于河」，遂代夏政（《史记·夏本纪》《左传·襄公四年》）。
3. **立仲康、相**：羿立太康之弟仲康为傀儡，后又立相；夏政名存实亡。
4. **「不修民事」**：羿代夏后「恃其射也，不修民事，而淫于原兽」，弃用贤臣武罗、伯因等，而信寒浞（《左传·襄公四年》）。
5. **被寒浞所杀**：寒浞行媚于内、施赂于外，乘羿田猎而归时杀之，烹其子（《左传·襄公四年》）。

## 主要事迹
- **代夏**：以善射之能乘民心之怨，成为夏代第一次权力中断的执行者。
- **被弑**：以「不修民事」失众，最终被家臣寒浞反噬——「以力取之，以力失之」的早期寓言。

## 金文/考古佐证
- 有穷氏地望（山东）考古线索有限；羿其人无器物。
- 二里头文化与东夷（岳石文化）的互动，可作夏初权力更迭的考古背景。

## 传说层辨析（重点）
- **羿射九日、嫦娥奔月**：神话层，出自《淮南子》《楚辞·天问》等，与本条篡政之「后羿」不属同一层。本工程分列：神话入「神话卷」，篡政入恶名卷。
- **「后羿」之「后」**：一说为「王」之义（后即君），非姓氏。
- **寒浞杀羿**：《左传》所载，细节（烹子、食之）为叙述性强化。

## 后世评价
- 传统：乘乱代夏的权臣/篡位者，因其「不修民事」而迅速败亡。
- 文学：因神话混淆，形象长期被「射日英雄」覆盖，历史的羿与神话的羿需分清。

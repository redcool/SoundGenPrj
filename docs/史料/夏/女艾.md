# 女艾

## 基本信息
- 时代：夏中前期（少康时，约前 19 世纪）
- 身份：少康之臣（一说为女官/女间谍）、中国最早的「间谍」记载人物
- 文献：《左传·哀公元年》

## 生平年表
1. **受命为间**：少康复国前，派女艾潜入寒浞之子「浇」之处，探其虚实（《左传·哀公元年》「使女艾谍浇」）。
2. **侦得内情**：女艾回报浇的动向与弱点，为少康的军事行动提供情报。
3. **配合季杼**：少康另派子季杼诱豷（寒浞另一子），女艾与季杼一内一外。
4. **复国成功**：少康灭浇、杀豷、诛寒浞，女艾之功不可没（具体封赏史载不详）。

## 主要事迹
- **中国最早的间谍记录**：「谍」字在此首次用于具体的军事侦察行动。
- **以女入间**：女性参与军政情报，在早期文献中极为罕见。

## 金文/考古佐证
- 无直接器物；夏代情报活动只能从文献推知。

## 传说层辨析
- **女艾的身份**：一说为「女艾」为女性（女官），一说「女」为氏、艾为名；学界多倾向女性说，但无确证。
- **《左传》记载**简略，具体行动细节不详。

## 后世评价
- 军事史意义：间谍战的鼻祖级人物。
- 现代视角：其形象常被用作「女性参与早期政治军事」的例证。

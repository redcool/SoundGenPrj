鲧（gǔn）是中国上古神话传说中的一位重要人物，他是大禹的父亲，也是夏后氏部落的首领，以治理洪水失败而闻名。
以下是关于“鲧”的详细讲解：

1. 核心身份与背景

• 大禹之父：他是华夏族的重要先祖，其子大禹后来因治水成功并建立了中国历史上第一个王朝——夏朝。
• 黄帝后裔：根据《史记·夏本纪》等史料记载，鲧是黄帝的玄孙，属于颛顼（zhuān xū）一系，身份极为高贵。
• 封地：他曾被封于崇地（今河南嵩山一带），因此也被称为“崇伯鲧”。

2. 鲧治水的神话故事

在尧帝时期，天下遭遇了极大的洪水，庄稼被淹没，百姓流离失所。
• 临危受命：尽管尧帝起初认为鲧违背天命、任用同族，但在四岳（部落首领们）的强烈推荐下，尧还是派鲧去治理洪水。
• 治水方法（堵）：鲧治水的主要方法是“堵”。他筑起高大的堤坝和土垄，试图把洪水挡住。
• 盗取息壤：神话传说中，鲧为了阻挡洪水，未经天帝允许，偷走了天庭的宝物“息壤”（一种能自生自长、永无止境的土壤）。他用息壤填埋洪水，虽然一度见效，但最终洪水越积越高，大堤彻底崩溃，灾情反而更加严重。
• 治水结果：鲧治水历时九年，最终以失败告终。

3. 鲧的结局

因为治水失败且盗窃天宝，鲧遭到了严厉的惩罚：
• 流放与诛杀：舜帝摄政后，进行大刀阔斧的整顿。他认为鲧治水无功，将鲧流放到羽山（今江苏、山东交界处），并将其诛杀（一说被祝融所杀）。
• 化为黄能（nái）：传说鲧死后尸体三年不腐。后来有人用吴刀剖开他的肚子，大禹便从他的腹中诞生。而鲧的尸体则化为一条“黄能”（神话中一种像熊或大鳖的三足动物），投入了羽山的深潭之中。

4. 历史与文化评价

• 功亏一篑的悲剧英雄：虽然鲧治水失败了，但在中国传统文化中，他往往被视为一个充满悲剧色彩的英雄。他为了拯救百姓不惜违抗天帝，其九年治水的经验也为后来大禹“疏导”治水的成功奠定了基础。
• 成语“鲧禹治水”：这个成语常用来形容父子相继、历经艰辛治理水患的历史功绩。

5. 字形与读音提示

• 读音：gǔn（音同“滚”）。
• 字形：左边是“鱼”，右边是“系”，在古语中也有大鱼的意思，这与其最终化身为水中神兽的神话结局相呼应。

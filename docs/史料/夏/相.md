# 相

## 基本信息
- 时代：夏初（约前 20 世纪）
- 身份：仲康之子、夏后氏第五王；为寒浞所害，夏室几绝
- 相关：其妻后缗逃归有仍，生少康（遗腹子）

## 生平年表
1. **继位**：仲康崩，相即位；时后羿、寒浞相继专权。
2. **依同姓**：相先后依于斟灌、斟鄩（夏之同姓），图存。
3. **寒浞篡政**：寒浞杀后羿自立，又使其子浇伐斟灌、斟鄩，杀相（《左传·哀公元年》）。
4. **后缗逃亡**：相之妻后缗（有仍氏之女）自墙洞逃出，奔有仍，生少康。
5. **身后**：少康长大后灭寒浞，复夏祀——相以「遗腹子」的方式延续了夏室。

## 主要事迹
- **夏室存亡的断点**：相被杀是夏朝最危险的时刻（「夏室几绝」）。
- **遗腹子叙事**：从相到少康的这段历史，是「中断—复兴」的经典结构。

## 金文/考古佐证
- 无直接器物。斟灌、斟鄩的地望（河南/山东交界）有考古讨论。

## 传说层辨析
- **后缗出逃的细节**（「逃出自窦」）见于《左传》，可信度较高但细节有叙述性。
- **斟灌、斟鄩**：夏之同姓诸侯，其地望与灭亡过程史载简略。

## 后世评价
- 传统：亡国之君序列中的「受害者」——不同于太康的失德，相是无辜被杀。
- 结构意义：为少康中兴提供了「复仇—复国」的合法性叙事。

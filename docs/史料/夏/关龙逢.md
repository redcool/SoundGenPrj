# 关龙逢（关龙逄）

## 基本信息
- 时代：夏末（桀时，约前 17 世纪）
- 身份：夏桀之大夫（一说为豢龙氏之后）
- 定性：中国最早的「直谏忠臣」之一，与商之必干并称「龙逢比干」

## 生平年表
1. **事桀**：为夏桀之臣，见桀暴虐、拒谏，国势危殆。
2. **直谏**：「桀为酒池糟堤，纵靡靡之乐，一鼓而牛饮者三千人；关龙逢进谏曰：古人之君，身行礼义，爱民节财，故国安而身寿。今君用财若无穷，杀人若恐弗胜，君若弗革，天殃必降，而诛必至矣」（《韩诗外传》卷二所载谏辞）。
3. **献黄图**：一说关龙逢献「黄图」（图法/舆图）以讽，桀焚图而杀之（《尚书》正义引、后出文献）。
4. **被杀**：「桀杀关龙逢」（《史记·夏本纪》正义引）——立而不去，谏而死。

## 主要事迹
- **死谏**：中国谏诤传统的最早样本之一（早于比干）。
- **「爱民节财」之谏**：把「节用爱民」作为君主合法性标准，思想史意义重大。

## 金文/考古佐证
- 无直接器物。相关记载主要见于《韩诗外传》《尚书》正义等，时代较晚。

## 传说层辨析
- **谏辞原文**：汉代文献所载，非当时实录，可能经儒生加工。
- **「黄图」细节**：后出文献，可靠性较低，但「直谏被杀」的核心史事在先秦已有流传（《庄子》《荀子》均提及关龙逢之死）。

## 后世评价
- 与比干并称「龙逢比干」，为「忠谏而死」的双璧。
- 《庄子·胠箧》：「龙逢斩，比干剖」——以之与暴政并论。

# 五子（太康五弟）

## 基本信息
- 时代：夏初（约前 20 世纪）
- 身份：夏启之子、太康之弟五人（合称「五子」）
- 文献：《尚书·五子之歌》（古文尚书，晚出）

## 生平年表
1. **太康失国**：太康游猎洛水之外，十旬不返，后羿拒之于河。
2. **五子侍母**：五子奉其母徯于洛汭，候太康不归。
3. **作歌以怨**：「五子咸怨，述大禹之戒以作歌」（《尚书·五子之歌》序）。
4. **《五子之歌》**：五首，其一曰「皇祖有训：民可近，不可下；民惟邦本，本固邦宁」——中国最早的政治训诫诗。

## 主要事迹
- **「民惟邦本」**：中国民本思想最早的文献表述之一（虽为晚出文本，思想源流甚古）。
- **以歌谏兄**：以诗的形式批评君主的失德，开「诗谏」传统。

## 金文/考古佐证
- 无直接器物。《五子之歌》属《古文尚书》，学界主流认为是东晋梅赜所献的晚出文本，但其思想内核（民本）与西周以来的民本传统相符。

## 传说层辨析（重要）
- **《五子之歌》的真伪**：古文《尚书》二十五篇为晚出（明清辨伪已成定论），但「五子作歌」的传说在先秦已存在（《墨子》《楚辞》均引）。
- **五子的名字**：史书未载。

## 后世评价
- 思想史地位：民本话语的源头引用之一（「民惟邦本」成为历代谏诤的口头禅）。
- 文学史地位：「歌以怨」的诗谏传统。

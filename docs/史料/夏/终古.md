# 终古

## 基本信息
- 时代：夏末（桀时，约前 17 世纪）
- 身份：夏之太史令（掌图法、天文、记事）
- 事迹：见桀暴虐，抱图法奔商——中国最早的「弃暗投明」记录之一

## 生平年表
1. **任太史令**：掌夏之图籍法度。
2. **谏桀不听**：见桀「暴虐愈甚」，屡谏不听。
3. **奔商**：「夏太史令终古，出其图法，执而泣之。夏桀迷惑，暴乱愈甚，太史令终古乃出奔如商」（《吕氏春秋·先识览》）。
4. **商汤喜而告诸侯**：「夏王无道，暴虐百姓，穷其父兄，耻其功臣，轻其贤良，弃义听谗，众庶咸怨，守法之臣，自归于商」——以终古之奔作为夏失天命的证据。

## 主要事迹
- **「图法奔商」**：典籍与制度随人转移，成为「天命转移」的象征性事件。
- **史官的选择**：与关龙逢的「死谏」形成对照——一死一去，构成早期士人的两种政治选择。

## 金文/考古佐证
- 无直接器物。夏代史官制度的存在，可从二里头文化的礼器与刻画符号间接推测。

## 传说层辨析
- **《吕氏春秋》的记载**属战国文献，可能有加工，但「终古奔商」的核心叙事在先秦流传。
- **「图法」的内容**（图籍、法度、历法）不可详考。

## 后世评价
- 传统：识天命、知去就的贤者，与关龙逢互补。
- 政治文化意义：为后世「良臣择主而事」提供了最早的例证之一。

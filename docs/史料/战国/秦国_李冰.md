# 秦国 · 李冰

## 基本信息
- 时代：战国末期（秦昭王时，前 3 世纪）
- 身份：秦国蜀郡守
- 关键事件：主持修建都江堰（约前 256—前 251），使成都平原成为「天府」

## 生平年表
1. **为蜀守**：秦昭王时任命为蜀郡守（具体年份史无明载，约前 3 世纪中）。
2. **修都江堰**：以「鱼嘴」分水、「飞沙堰」泄洪排沙、「宝瓶口」引水，建成无坝引水工程。
3. **治水方略**：据《华阳国志》，「壅江作堋，穿郫江、检江」，并立「深淘滩，低作堰」之则。
4. **凿崖通航**：凿平青衣江溷崖（一说乐山乌尤），通正水路。
5. **身后**：蜀人「祠之」，历代续修；两千二百余年仍在灌溉。

## 主要事迹
- **都江堰**：世界水利史上唯一沿用两千余年、至今仍在使用的大型无坝引水工程；2000 年列世界文化遗产。
- **「深淘滩，低作堰」**：六字治水诀，被历代堰工奉为圭臬。
- **石人水则**：以石人测水位（「水竭不至足，盛不没肩」），是中国最早的水位标尺之一。

## 史料辨析
- 李冰事迹主要见《史记·河渠书》（简略）、《华阳国志·蜀志》（较详）；后者成书较晚（东晋），需注意层累。
- 都江堰的始建年代与工程形制，考古与文献互证仍在进行（鱼嘴位置历代有迁移）。

## 后世评价
- 传统：「功在当代，利在千秋」的工程典范，被蜀人奉为「川主」。
- 现代：以「不建坝、顺水性」的生态工程智慧被反复研究。

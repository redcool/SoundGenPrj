# 齐国 · 后胜

## 基本信息
- 时代：战国末（齐王建时，前 3 世纪）
- 身份：齐王建的相国（后胜，一作「后胜」，齐王后族）
- 关键事件：受秦重金，劝齐王建不修战备、不救五国、最终不战而降

## 生平年表
1. **为齐相**：齐王建在位四十余年，政事多决于后胜。
2. **受秦金**：秦以重金赂后胜及其宾客，后胜遂劝齐王「朝秦」、不助五国、不修攻战之备（《史记·田敬仲完世家》）。
3. **五国相继亡**：秦灭韩、赵、魏、楚、燕，齐坐视不救。
4. **齐亡（前 221）**：秦将王贲自燕南下袭齐，齐王建听后胜之计，不战而降；秦以齐为郡。
5. **齐王建饿死**：秦迁齐王建于共，处之松柏之间，饥饿而死，齐人歌之曰「松耶柏耶？住建共者客耶」（《史记》）。
6. **结局**：后胜之下场史无明载。

## 主要事迹
- **「不战而降」**：战国最后一国的灭亡方式，是四十年和平换来的麻痹。
- **贿赂灭国**：秦用金钱买下一个国家的决策层，成本远低于战争。
- **齐人之歌**：那首歌怨的不是秦，是「住建共者客」——把王送进绝地的自己人。

## 史料辨析
- 记载主要见《史记·田敬仲完世家》，较简；《战国策·齐策》有相关叙述。
- 「后胜」的身份与族属（后族）有讨论；其受贿细节为史家概括。

## 后世评价
- 传统：卖国相国的典型，与郭开并称「战国两大内应」。
- 战略视角：齐国四十余年不修战备，是长期「绥靖」的代价样本。

# 魏国 · 信陵君 魏无忌

## 基本信息
- 时代：战国末期（魏安釐王时，前 3 世纪）
- 身份：魏昭王少子、安釐王异母弟；战国四公子之一
- 关键事件：窃符救赵、率五国之师破秦、晚年遭忌

## 生平年表
1. **养士**：仁而下士，食客三千；「不以下交贫贱为耻」。
2. **窃符救赵（前 257）**：秦围邯郸，赵求魏救；魏王使晋鄙将兵十万观望不进。信陵君用侯嬴之计，请如姬盗兵符，至军杀晋鄙，夺军救赵，秦军退。
3. **留赵**：自知得罪魏王，留赵十年；与平原君交，闻毛公、薛公之贤而与之游。
4. **归魏（前 247）**：秦伐魏急，魏王召之；信陵君率五国之师败秦于河外，追至函谷关，秦兵不敢出。
5. **遭忌**：秦行反间，散布「诸侯徒闻信陵君，不闻魏王」；魏王疑之，夺其兵权。
6. **晚年**：谢病不朝，日夜饮酒近妇人，四岁而卒（《史记·魏公子列传》）。

## 主要事迹
- **窃符救赵**：以「义」僭越君权，是战国「士」之伦理的最高表达。
- **合纵破秦**：战国后期唯一一次真正打到函谷关的合纵。
- **礼贤下士**：侯嬴（守门老者）、朱亥（屠者）、毛公（博徒）、薛公（卖浆者）——皆下层而受尊礼。

## 史料辨析
- 《史记·魏公子列传》为司马迁倾注情感之作（「天下诸公子亦有喜士者矣，然信陵君之接岩穴隐者，不耻下交」），叙述带明显褒扬倾向。
- 窃符细节（如姬盗符、侯嬴自刭）文学性强，但主干可信。

## 后世评价
- 传统：四公子之首，「义」的化身；李白《侠客行》「千秋二壮士」即咏侯嬴、朱亥。
- 政治史：其悲剧在于「有救国之能而无自处之道」——功高震主，终被弃用。

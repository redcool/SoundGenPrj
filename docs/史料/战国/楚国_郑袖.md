# 楚国 · 郑袖

## 基本信息
- 时代：战国中期（楚怀王时，前 4 世纪末）
- 身份：楚怀王宠姬（夫人）
- 关键事件：谗害魏美人（「掩鼻」之计）、与靳尚共谗屈原

## 生平年表
1. **得宠**：怀王宠姬，权倾后宫。
2. **魏女入楚**：魏王遗怀王美人，怀王甚悦之；郑袖恐失宠。
3. **「掩鼻」之计**：郑袖伪善告魏女「王爱子之美，然恶子之鼻，见王常掩鼻」；魏女从之。怀王问郑袖「何故掩鼻」，袖曰「似恶闻王之臭」（《战国策·楚策》）。
4. **刖魏女**：怀王怒，命劓（一说刖）魏女，郑袖复专宠。
5. **共谗屈原**：与上官大夫、靳尚同谗屈原（《史记·屈原贾生列传》所载「夺稿」事与《战国策》叙述可互参）。
6. **结局**：其终，《史记》《战国策》均未明载。

## 主要事迹
- **掩鼻之计**：中国宫廷阴谋中最经典的「反向话术」案例。
- **借刀杀人**：不动手，让国君自己动手。
- **后宫政治**：其行为暴露「无制度约束的宠爱即权力」的风险。

## 史料辨析
- 主见《战国策·楚策四》（掩鼻事）；《韩非子·内储说下》亦有类似记载（细节不同），属「说体」材料的典型层累。
- **此类故事常被诸子用作论证工具**，具体细节可靠性有限，本档标注「战国策/韩非子系统」。

## 后世评价
- 传统：妒妇误国的典型，「掩鼻」成为典故（骆宾王「掩鼻谁相问」）。
- 现代：被视为后宫制度与信息不对称共同作用的产物。

# 秦国 · 张仪

## 基本信息
- 时代：战国中期（秦惠文王时，前 4 世纪末—前 3 世纪初）
- 身份：魏国人，纵横家；秦相、魏相
- 关键事件：连横破合纵、以「商於六百里」欺楚怀王

## 生平年表
1. **入秦**：与苏秦同师（传说），初仕魏，后入秦为客卿，前 328 年为秦相。
2. **连横**：主张秦与六国分别结盟，破坏苏秦的合纵。
3. **欺楚（前 313）**：以「献商於之地六百里」诱楚绝齐；楚绝齐后，张仪改口「六里」，楚怀王大怒发兵，败于丹阳、蓝田（《史记·张仪列传》）。
4. **相魏**：一度为魏相，为秦利益行事。
5. **秦武王时失势**：武王不喜其术，去秦相魏，后卒于魏。

## 主要事迹
- **连横**：以「各个击破」破解合纵，是秦统一的外交底色。
- **商於六百里**：中国外交史上最著名的「承诺陷阱」。
- **舌头的价值**：张仪被诬盗璧遭笞，谓妻「视吾舌尚在不」，妻笑曰「舌在也」，曰「足矣」——以舌为业的自况。

## 史料辨析
- 《史记·张仪列传》与《战国策》互见，但**纵横家言多夸张**，学界普遍认为《战国策》部分篇章为后人拟托。
- 苏秦、张仪「同学」之事，1973 年马王堆帛书《战国纵横家书》出土后，学界多认为苏秦晚于张仪，传统「同学」说不确。

## 后世评价
- 传统：纵横家的代表，智谋与欺诈并存；儒家多贬其「无行」。
- 现代：被视为「外交即交易」的早期实践者，其手段与后果常被并置讨论。

# 楚国 · 靳尚

## 基本信息
- 时代：战国中期（楚怀王时，前 4 世纪末）
- 身份：楚怀王近臣、上官大夫（一说靳尚即上官大夫，学界有异说）
- 关键事件：与屈原争宠、受秦贿赂阻楚联齐、促成怀王入秦

## 生平年表
1. **与屈原同列**：屈原为左徒，「入则与王图议国事」，靳尚与之争宠而心害其能（《史记·屈原贾生列传》）。
2. **夺稿之谗**：怀王使屈原造宪令，稿未定，靳尚见而欲夺之，不与，遂谗「王使屈平为令，众莫不知，每一令出，平伐其功」，怀王怒而疏屈原（《史记》）。
3. **受秦赂（前 313 后）**：张仪欺楚以商於之地，楚欲杀张仪；张仪至楚，厚赂靳尚，靳尚说怀王宠姬郑袖，郑袖说王，张仪得释（《史记·张仪列传》）。
4. **劝王入秦（前 299）**：秦昭王约怀王会武关，屈原谏「秦虎狼之国」，怀王稚子子兰劝行，靳尚附之；怀王入秦被拘，死于秦。
5. **结局**：其终未详载；一说怀王被拘后楚人咎之。

## 主要事迹
- **谗屈原**：「夺稿」是屈原见疏的直接导火索。
- **受贿释张仪**：一人受贿，改了楚国的外交方向。
- **劝王入秦**：直接导致怀王客死。

## 史料辨析
- 主见《史记·屈原贾生列传》《张仪列传》。「上官大夫」与「靳尚」是否同一人，学界长期有争议，本档并记并注。
- 《屈原列传》带明显褒屈倾向，其政敌叙述需对照《楚世家》《战国策》读。

## 后世评价
- 传统：谗臣的代表，与郑袖、子兰并列屈原悲剧的三推手。
- 史学提醒：屈原之放，是楚国「亲秦派 vs 联齐派」路线斗争的结果，非单纯小人陷害。

# 秦国 · 赵高

## 基本信息
- 时代：秦末（始皇至二世，前 3 世纪末）
- 身份：赵国王族远支之后（一说「诸赵疏远属」），宦者；中车府令 → 郎中令 → 丞相
- 关键事件：沙丘之变、指鹿为马、逼杀二世、被子婴所诛

## 生平年表
1. **为宦官**：通狱法，事始皇，任中车府令，兼行符玺令事；教胡亥狱律（《史记·蒙恬列传》）。
2. **沙丘之变（前 210）**：始皇崩于沙丘，赵高与李斯合谋，矫诏立胡亥，赐死扶苏、蒙恬。
3. **专权**：杀蒙毅、李斯等，为郎中令、中丞相，事皆决于高。
4. **指鹿为马（前 207）**：献鹿于二世，曰「马也」；二世问群臣，或默、或言马以阿顺、或言鹿者，高阴中以法（《史记·秦始皇本纪》）。
5. **逼杀二世**：遣阎乐攻望夷宫，二世自杀。
6. **被诛**：立子婴（去帝号），子婴称疾不与，高自往请，子婴遂杀之于斋宫，夷三族。

## 主要事迹
- **沙丘之变**：中国历史上最著名的「矫诏夺位」，直接导致秦亡加速。
- **指鹿为马**：以荒谬测试忠诚，是「权力测验」的极端样本。
- **「秦之亡，亡于内」**：秦的崩溃不在战场，而在宫廷。

## 史料辨析
- 《史记》三处互见（秦始皇本纪、李斯列传、蒙恬列传），细节略有出入。
- 「赵高为宦者」的传统说法，现代学者有「非阉人、乃宦（仕宦）」之辨，学界未定论。

## 后世评价
- 传统：奸宦的代名词，「指鹿为马」成为固定成语。
- 现代：其崛起被视为秦制「无制衡的皇权 + 秘府近臣」的结构性风险。

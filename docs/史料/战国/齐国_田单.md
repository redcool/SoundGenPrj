# 齐国 · 田单

## 基本信息
- 时代：战国后期（齐湣王至齐襄王，前 3 世纪）
- 身份：齐国宗室远支，临淄市掾（小吏），后为安平君
- 关键事件：即墨守城、火牛阵破燕、复齐七十余城

## 生平年表
1. **为市掾**：湣王时不受知，任临淄市掾（管理市场的小官）。
2. **安平脱难**：燕破齐，田单令族人断车轴之末端、裹以铁笼，得脱；众人车轴折而被俘，独田氏得免。
3. **即墨守城（前 284—前 279）**：即墨大夫战死，众推田单为将；坚守五年。
4. **反间去乐毅**：散布「乐毅畏诛不敢归」之谣，燕惠王以骑劫代乐毅。
5. **火牛阵（前 279）**：收牛千余，束兵刃于角、灌脂束苇于尾，夜烧牛尾，牛狂奔突燕营；五千壮士随击，燕军大溃，骑劫死。
6. **复国**：乘胜追击，七十余城尽复；迎襄王入临淄，封安平君。
7. **晚年**：入赵为将，后归齐，事迹渐略。

## 主要事迹
- **火牛阵**：中国战争史上最著名的奇计之一，以千牛破燕军。
- **五年守孤城**：以一座即墨城撑住齐国国祚。
- **心理战**：先散谣言去敌之良将，再用「神师」之说鼓舞己方士气。

## 史料辨析
- 《史记·田单列传》记载完整；火牛阵的细节（牛数、束兵方式）或有夸张，但战术思路可信。
- 即墨守城的时间与燕军围城规模，各家记载略有出入。

## 后世评价
- 传统：复国功臣，「奇计」的代名词。
- 军事史：以弱复强的经典案例；火牛阵被反复引用（虽实际复制极少）。

# 魏国 · 西门豹

## 基本信息
- 时代：战国初（魏文侯时，前 5 世纪末—前 4 世纪初）
- 身份：魏国邺令（一说西门氏，名豹）
- 关键事件：破除「河伯娶妇」、开漳水十二渠、惩治豪强

## 生平年表
1. **为邺令**：魏文侯时受任，至邺见「田荒民贫」而市井繁华，问其故。
2. **河伯娶妇**：三老、廷掾与巫祝勾结，每年敛财数百万，选民女投漳河，谓之「嫁河伯」。
3. **投巫入河**：西门豹至河边，以「女不好，烦巫入报」为由，投大巫及三弟子入河，又欲投三老，众人叩头流血乃止（《史记·滑稽列传》褚少孙补）。
4. **开渠灌田**：发民凿十二渠，引漳水溉邺田，民初怨苦，后皆受益。
5. **治政**：清查豪强，行教化，邺地大治。

## 主要事迹
- **以巫治巫**：不辩论鬼神是否存在，直接把「代表鬼神说话的人」送进河里——中国最早的「反迷信行政案例」。
- **十二条渠**：把水患变水利，邺地成为魏国粮仓。
- **「今日苦，子孙享」**：工程伦理的早期表述。

## 史料辨析
- 主要见《史记·滑稽列传》褚少孙所补（非司马迁原文），《说苑》《淮南子》亦有异文；细节（投几人、数目）各本不同。
- 十二渠的具体形制与后世「西门渠」的沿革，有考古与方志互证，但始建规模难确考。

## 后世评价
- 传统：循吏典范，与李冰并称古代水利名臣。
- 现代：被视为「破除迷信 + 公共工程 + 吏治」三合一的治理样本。

# 赵国 · 赵括

## 基本信息
- 时代：战国末（赵孝成王时，前 3 世纪）
- 身份：赵奢之子，赵国将领
- 关键事件：长平之战代廉颇为将，四十余万赵军被坑

## 生平年表
1. **少学兵法**：自小读兵书，谈兵事「天下莫能当」，然其父赵奢不以为能，谓「兵，死地也，而括易言之」（《史记·廉颇蔺相如列传》）。
2. **代廉颇（前 260）**：秦使反间于赵，曰「秦独畏马服君之子赵括」；赵王遂以括代颇。
3. **其母谏**：赵括母上书言括不可用，赵王不听（《史记》）。
4. **长平之败**：赵括至军，尽改廉颇约束、易置军吏，出兵击秦；秦将白起佯败而绝其粮道，围赵军四十六日。
5. **战死**：赵括率锐卒搏战，被射死；赵军降，白起坑之，四十余万（数字有争议）。
6. **身后**：「纸上谈兵」成为其定格形象。

## 主要事迹
- **代将之败**：战国最大规模的歼灭战，赵国从此不能再与秦争。
- **「纸上谈兵」**：中国最著名的空谈误国典故（成语晚出，定型于明清，但源出此事）。
- **父亲与母亲的预言**：两条家族内部的警告，都被君主忽略。

## 史料辨析
- 《史记》记载清楚（含母谏、赵奢评语）。
- 「四十余万」的坑卒数字，学界有讨论（可能含夸张与统计口径问题），但赵军主力尽失是定论。
- 「纸上谈兵」四字非当时语，为后世概括。

## 后世评价
- 传统：空谈误国的典型。
- 现代：更强调「赵王决策失误 + 国力不支」的结构性原因，赵括是结果而非唯一原因。

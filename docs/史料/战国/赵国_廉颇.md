# 赵国 · 廉颇

## 基本信息
- 时代：战国后期（赵惠文王至悼襄王，前 3 世纪）
- 身份：赵国名将，与白起、王翦、李牧并称「战国四大名将」
- 关键事件：伐齐取阳晋、长平拒秦、负荆请罪、晚年奔魏楚

## 生平年表
1. **伐齐立功（前 283）**：率军伐齐，破其一军，取阳晋，拜为上卿，以勇闻于诸侯。
2. **长平拒秦（前 262—前 260）**：秦攻上党，廉颇坚壁清野、固守三年，秦不能破；赵王中秦反间，以赵括代之，遂有长平之败。
3. **负荆请罪**：不服蔺相如位在其上，后闻「先国家之急而后私仇」之言，肉袒负荆至门谢罪。
4. **破燕（前 251）**：燕乘赵衰来攻，廉颇破之，杀栗腹，围燕都，燕割五城请和。
5. **晚年失势**：赵悼襄王立，使乐乘代之，廉颇怒攻乐乘，出奔魏；魏不能用。
6. **「尚能饭否」**：赵王欲复用之，遣使者视其体；郭开贿使者，使者还报「顷之三遗矢矣」，赵王遂不召（《史记》本传）。
7. **卒于楚**：后入楚为将，无功，卒于寿春。

## 主要事迹
- **守势大师**：长平三年坚守，是战国防御战的最成功案例之一——赵国之败不在战场而在庙堂。
- **负荆请罪**：以名将之尊向文臣谢罪，「知过能改」的千古典范。
- **「尚能饭否」**：一代名将的晚景，成为「英雄迟暮」的文学母题；辛弃疾「廉颇老矣，尚能饭否」即出于此。

## 史料辨析
- 《史记》本传记载完整；长平之战的细节（赵括代颇、白起坑卒）主要依《史记》。
- 「三遗矢」之事，后世多认为是郭开行贿、使者诬报的政争结果。

## 后世评价
- 传统：忠勇而性刚的名将，「负荆」与「尚能饭否」两典并传。
- 军事史：其坚守战略被后世视为「以时间换空间」的早期范例。

# 齐国 · 齐湣王 田地

## 基本信息
- 在位：前 300—前 284
- 身份：齐宣王之子，齐国末期的强势君主
- 关键事件：灭宋、骄暴失诸侯、五国伐齐、出奔被杀

## 生平年表
1. **即位**：宣王卒，田地立；初期任孟尝君田文为相，齐国强盛。
2. **灭宋（前 286）**：齐灭宋，宋王偃死；齐势极盛，亦招诸侯之忌。
3. **骄暴**：史称其「矜功不休」，杀谏臣、辱诸侯；《战国策》载其「欲为天子」。
4. **五国伐齐（前 284）**：燕昭王合五国之师，乐毅为将，济西大破齐军，乐毅长驱入临淄。
5. **出奔**：湣王走莒，被楚将淖齿所杀（一说抽筋悬梁，见《战国策》）。
6. **身后**：齐国几亡，赖田单复国，然元气大伤，再不能争天下。

## 主要事迹
- **灭宋自骄**：以一场胜利换来五国合围。
- **骄暴失士**：杀谏臣、疑大臣，人心尽失。
- **死于外将**：楚将淖齿以「天、地、人」三问数其罪而杀之（《战国策·齐策》）。

## 史料辨析
- 《史记·田敬仲完世家》《战国策·齐策》互见；淖齿杀湣王的具体方式（抽筋悬于庙梁）记载戏剧化，可信度有限。
- 齐灭宋的年份与过程，各本略有差异。

## 后世评价
- 传统：骄暴亡国的典型，与宋康王并称「桀宋齐湣」。
- 战略史视角：齐国由「可与秦争天下」到「几亡」，转折点正是灭宋后的骄横。

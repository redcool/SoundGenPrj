# 齐国 · 孙膑

## 基本信息
- 时代：战国中期（齐威王时，前 4 世纪）
- 身份：兵家，孙武之后；齐威王军师
- 关键事件：桂陵之战（围魏救赵）、马陵之战（杀庞涓）

## 生平年表
1. **同学于鬼谷**：与庞涓同学兵法（《史记·孙子吴起列传》）。
2. **膑刑**：庞涓仕魏为将，忌其才，召至魏，诬以罪，断其足、黥其面（「膑」即去膝盖骨）。
3. **奔齐**：齐使载之归齐，为田忌门客；以「田忌赛马」显其智（下驷对上驷之策）。
4. **桂陵之战（前 353）**：魏伐赵，赵求救于齐；孙膑献策「批亢捣虚」，直趋魏都大梁，魏师回救，败于桂陵——「围魏救赵」。
5. **马陵之战（前 341）**：魏伐韩，齐救韩；孙膑用「减灶诱敌」，庞涓轻进，夜至马陵，齐军万弩齐发，庞涓自刭（一说被射杀）。
6. **晚年**：著《孙膑兵法》（1972 年银雀山汉墓出土竹简证实其书实存）。

## 主要事迹
- **围魏救赵**：中国军事史上「攻其必救」的经典范式。
- **减灶诱敌**：以假象操控敌方判断，心理战的早期样本。
- **身残而智全**：以刑余之身成为一国之军师，是中国「智胜于力」的原型人物。

## 史料辨析
- 《史记》本传记载桂陵、马陵二役；《孙膑兵法》竹简出土后，其军事思想得到实物印证（此前曾被疑为伪书）。
- 「马陵」地望有今山东莘县、河南范县等说，学界尚有讨论。

## 后世评价
- 传统：兵家亚圣（仅次于孙武），与孙武并称「孙子」。
- 军事教育：「围魏救赵」写入各国军事教材。

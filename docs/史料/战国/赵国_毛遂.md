# 赵国 · 毛遂

## 基本信息
- 时代：战国末期（赵孝成王时，前 3 世纪）
- 身份：平原君赵胜门下食客，三年无所知名
- 关键事件：毛遂自荐、殿上定盟、说楚王合纵救赵

## 生平年表
1. **为门客**：居平原君门下三年，未有所称。
2. **自荐（前 258）**：秦围邯郸，平原君欲合纵于楚，约与门下食客二十人俱，得十九人，余无可取；毛遂自荐补足（《史记·平原君虞卿列传》）。
3. **「锥处囊中」**：平原君质疑其三年无名，毛遂答「臣乃今日请处囊中耳。使遂蚤得处囊中，乃颖脱而出」。
4. **殿上劫盟**：平原君与楚王言合纵，日出至日中不决；毛遂按剑历阶而上，以「十步之内，王不得恃楚国之众」相胁，并陈白起破郢、烧夷陵之楚仇，楚王乃许（《史记》）。
5. **歃血**：毛遂奉铜盘，请楚王、平原君及己依次歃血，定纵于殿上。
6. **归赵**：平原君叹「毛先生一至楚，而使赵重于九鼎大吕」，遂以为上客。

## 主要事迹
- **毛遂自荐**：中国最著名的「自我推荐」典故。
- **锥处囊中**：以喻人才需机会方能显露。
- **以利害代道义**：不说「请救赵」，而说「楚之仇」——把请求变成共同利益。

## 史料辨析
- 主要见《史记·平原君虞卿列传》，叙述生动；《战国策·赵策》有异文，细节（言词、歃血次序）略异。
- 「三年无名」与「一说即中」的反差，可能有史公的文学强化。

## 后世评价
- 传统：士人自荐的典范；亦有人讥其「一逞口舌」。
- 现代：被视为「机会只给开口的人」的经典案例；其谈判术（把对方利益前置）常被引用。

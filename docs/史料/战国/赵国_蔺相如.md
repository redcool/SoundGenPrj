# 赵国 · 蔺相如

## 基本信息
- 时代：战国中后期（赵惠文王、孝成王时，前 3 世纪）
- 身份：赵国宦者令缪贤之舍人，后为上卿
- 关键事件：完璧归赵、渑池之会、将相和（负荆请罪）

## 生平年表
1. **出身**：缪贤舍人，以「臣请完璧归赵」自荐（《史记·廉颇蔺相如列传》）。
2. **完璧归赵（前 283）**：秦昭王愿以十五城易赵之和氏璧；相如奉璧入秦，见秦无意偿城，持璧睨柱、欲撞碎之，终使从者怀璧归赵。
3. **渑池之会（前 279）**：秦王与赵王会于渑池，秦王请赵王鼓瑟以辱之；相如逼秦王击缻，以「五步之内，相如请得以颈血溅大王」相胁，秦不能加胜。
4. **拜上卿**：以功拜上卿，位在廉颇之上。
5. **将相和**：廉颇不服，宣言辱之；相如每朝称病避让，谓「先国家之急而后私仇」；廉颇闻之，肉袒负荆请罪，遂为刎颈之交。
6. **晚年**：长平之战前后，赵王不用其谏（一说其已卒），赵国由盛转衰。

## 主要事迹
- **以弱使强**：三次外交（完璧、渑池、拒秦）皆以智与勇补国力之不足。
- **「先国家之急而后私仇」**：把「将相和」变成中国政治文化中「团结」的原型叙事。
- **智勇的定义**：不是不怕死，是「知其不可而为之」的精确计算——持璧睨柱而不真撞。

## 史料辨析
- 《史记》本传文学性强（对话生动），细节或经加工；大事（完璧、渑池、将相和）与《战国策》互见，可信度较高。
- 「完璧归赵」的具体交涉过程，两书略有出入，本档取《史记》叙述。

## 后世评价
- 传统：智勇双全的使臣典范，「完璧归赵」成为成语。
- 文化意义：与廉颇共同构成「文武相济」的理想模型；负荆请罪成为「知过能改」的符号。

# 宋国 · 宋康王 戴偃（宋王偃）

## 基本信息
- 在位：前 328—前 286
- 身份：宋国末代君主（宋君偃）
- 关键事件：射天笞地、伐齐攻楚、诸侯称「桀宋」，齐灭宋
- **史料性质：其「暴虐」细节多见于《战国策》《吕氏春秋》《新序》等，多采传说与诸子寓言 → 标注使用**

## 生平年表
1. **夺位**：逐其兄剔成（一说攻之），自立为君（《史记·宋微子世家》）。
2. **图强**：东败齐，取五城；南败楚，取地三百里；西败魏军；与齐、魏为敌。
3. **称王**：自号为王（一说「偃」称王）。
4. **「射天笞地」**：盛血于韦囊，悬而射之，曰「射天」；以长鞭笞地；斩社稷而焚之，曰「威服天下鬼神」（《史记·宋微子世家》）。
5. **暴虐**：为长夜之饮，室中人呼万岁，堂上应之，堂下应之，门外应之，一国之内莫敢不呼（《战国策·宋策》）。
6. **亡国（前 286）**：齐湣王伐宋，宋王偃出奔，死于温（一说被杀）；宋亡，地入齐、魏、楚。

## 主要事迹
- **射天笞地**：中国史上最著名的「对神宣战」叙事。
- **万岁之声**：从宫中传到全国，是「谄媚回音壁」的原型。
- **「桀宋」**：诸侯以此称之，与夏桀并提。

## 史料辨析（重要）
- 「射天」事见《史记·宋微子世家》，但《吕氏春秋》《新序》等叙述更夸张。
- 现代学者多认为宋王偃的「暴虐」形象有**战国诸子借宋喻政**的成分（宋为殷后，常被用作反面例证），需标注传说层。
- 宋亡的直接原因是齐的扩张，非单独因其暴。

## 后世评价
- 传统：暴君符号，「桀宋」成为成语。
- 史学提醒：小国在大国夹缝中的挣扎，常被写成「昏暴亡国」的单一叙事。

# 魏国 · 庞涓

## 基本信息
- 时代：战国中期（魏惠王时，前 4 世纪）
- 身份：魏国将军
- 关键事件：妒害孙膑（膑刑）、桂陵之战、马陵之战自刭

## 生平年表
1. **同学于鬼谷**：与孙膑同学兵法（《史记·孙子吴起列传》）。
2. **仕魏为将**：先于孙膑出仕，为魏惠王将。
3. **召孙膑而害之**：以「同学」之名召孙膑入魏，恐其贤于己，诬以罪，断其足、黥其面。
4. **桂陵之败（前 353）**：魏伐赵，齐救赵，孙膑「围魏救赵」，魏军败于桂陵。
5. **马陵之败（前 341）**：魏伐韩，齐救韩；孙膑减灶诱敌，庞涓轻进，夜至马陵，中伏，自刭（一说被射杀）。
6. **遗言**：「遂成竖子之名！」（《史记》）

## 主要事迹
- **妒贤**：中国「同学相害」叙事的最早原型之一。
- **两次败于同一人**：桂陵、马陵，一生之敌即昔日同门。
- **马陵的雨与火**：万弩齐发的夜战，成为兵法教材的经典案例。

## 史料辨析
- 《史记》记载明确；马陵地望（今山东莘县、河南范县等）有争议。
- 减灶细节（十万→五万→三万）为文学化的叙述，实际战术可信但数字或夸张。

## 后世评价
- 传统：妒贤忌能、自取灭亡的典型。
- 反面教材价值：孙膑的伟大，一半由庞涓的嫉妒衬托。

# 赵国 · 郭开

## 基本信息
- 时代：战国末（赵悼襄王至赵王迁，前 3 世纪）
- 身份：赵王迁的宠臣，为相
- 关键事件：受贿谗廉颇（「三遗矢」）、受贿谗李牧（赵之长城自毁）

## 生平年表
1. **事悼襄王**：为太子偃（后之赵王迁）之伴，得宠。
2. **谗廉颇（前 245 前后）**：赵王欲复召廉颇，遣使者视其可用否；郭开多与使者金，令毁之，使者还报「廉将军虽老，尚善饭，然与臣坐，顷之三遗矢矣」，赵王遂不召（《史记·廉颇蔺相如列传》）。
3. **谗李牧（前 229）**：秦将王翦攻赵，李牧御之，秦不能下；秦以重金赂郭开行反间，郭开谗李牧欲反，赵王使人代之，李牧不受命，遂杀之。
4. **赵亡（前 228）**：李牧死，赵军大败，邯郸陷，赵王迁被虏。
5. **结局**：邯郸破后，郭开携金归秦，途中为盗所杀（一说被盗劫财杀，见《史记》注引）。

## 主要事迹
- **两次受贿**：一次毁一将，两次毁掉赵国的两根支柱（廉颇、李牧）。
- **「三遗矢」**：一句诬报，断送一代名将的晚节机会。
- **灭国的价格**：赵国之亡，一半在战场，一半在郭开的账上。

## 史料辨析
- 主要见《史记·廉颇蔺相如列传》《赵世家》；李牧被谗事的细节各本略有出入。
- 郭开之死（盗杀）见注疏，可靠性次于本传。

## 后世评价
- 传统：卖国的内奸典型，「谗言亡国」的活标本。
- 政治学价值：反间计的成立条件——「敌人买通一个能进入决策圈的人」。

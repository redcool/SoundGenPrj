# 燕国 · 乐毅

## 基本信息
- 时代：战国后期（燕昭王至惠王，前 3 世纪）
- 身份：魏将乐羊之后，燕国上将军、昌国君
- 关键事件：合五国之兵伐齐，下齐七十余城；被反间去职，奔赵

## 生平年表
1. **入燕**：燕昭王筑黄金台招贤，乐毅自魏入燕，为亚卿。
2. **合纵伐齐（前 284）**：燕昭王悉起兵，乐毅为上将军，合赵、楚、韩、魏五国之师伐齐；济西之战大破齐军。
3. **下齐七十余城**：独率燕军长驱，破临淄，取宝器，齐湣王出奔被杀；唯莒、即墨未下。
4. **围而不攻**：围莒、即墨五年，宽政收齐民心（「修整燕军，禁侵掠，礼齐之贤者」）。
5. **反间去职（前 279）**：燕昭王卒，惠王素不喜乐毅；齐田单纵反间，惠王以骑劫代之，乐毅奔赵。
6. **报燕惠王书**：赵封其为望诸君；惠王悔而致书，乐毅作《报燕惠王书》——「善作者不必善成，善始者不必善终」。
7. **卒于赵**：终老于赵。

## 主要事迹
- **下七十城**：战国最成功的灭国级战役之一（几亡齐国）。
- **宽政收心**：军事胜利后用政治手段稳固，是「以德服人」的早期实践。
- **《报燕惠王书》**：中国书信体政论的典范，名句「君子交绝，不出恶声」。

## 史料辨析
- 《史记·乐毅列传》全文收录《报燕惠王书》，是研究其思想的第一手文本（虽经史公整理）。
- 「七十余城」的数字各家略有出入；围莒、即墨五年不下的原因，学界有「有意缓图」与「力不足」两说。

## 后世评价
- 传统：名将而兼政治家，「善始者不必善终」成为功成身退的警示。
- 诸葛亮自比「管仲、乐毅」，可见其在后世士人心中的地位。

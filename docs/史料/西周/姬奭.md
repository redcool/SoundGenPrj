# 姬奭（召公奭）

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王庶子（一说同族）、周初太保、燕国始祖、与周公旦并称「二公」
- 封地：初封于召（今陕西岐山西南），后封于燕（今北京房山琉璃河一带）
- 活动：武、成、康三朝

## 生平年表
1. **佐武王克商**：武王伐纣，召公与周公同列三公；克商后封于燕（《史记·燕召公世家》）。
2. **成王初立，与周公摄政**：成王年幼，周公摄政当国，「召公疑之」，周公作《君奭》释疑，二公同心辅政（《尚书·君奭》《史记·燕召公世家》）。
3. **分陕而治**：「自陕以西，召公主之；自陕以东，周公主之」——周初双头执政格局（《史记·燕召公世家》《公羊传·隐公五年》）。
4. **巡行听讼，甘棠遗爱**：巡行乡邑，于棠树下决狱政事，「自侯伯至庶人各得其所，无失职者」（《史记·燕召公世家》）。
5. **康王时仍居三公**：成王将崩，召公与毕公高同受顾命，辅康王（《尚书·顾命》）。

## 主要事迹
- **甘棠决狱**：不扰民、就地听讼，民思其德，作《甘棠》——《诗经·召南·甘棠》「蔽芾甘棠，勿翦勿伐，召伯所茇」。
- **分陕之治**：以陕为界，周公主东、召公主西，是中国早期「分区治理」的实例。
- **君奭释疑**：以《君奭》确立周公摄政的正当性，避免周初内裂（《尚书·君奭》）。
- **燕国始封**：封召公于北燕，镇抚殷遗与北土；召公留朝未就国，子克（燕侯克）就封（琉璃河出土「克盉」「克罍」铭文佐证）。

## 金文/考古佐证
- 北京房山琉璃河遗址 M1193 出土「克盉」「克罍」，铭文记「令克侯于匽（燕）」，印证召公封燕与周初分封。
- 「太保」器（如太保簋）多与召公相关联。

## 传说层辨析
- 「甘棠」为《诗经》所载史事，非传说；
- 召公断狱细节（树下决讼、民不劳扰）见于《史记》，后世家训化叙述有增饰，但核心史实成立。

## 后世评价
- 与周公并称「周召」，「周召共和」中的「召」即其后裔召穆公（姬虎）一系（注意：共和之召公非姬奭本人）。
- 「甘棠遗爱」成为后世称颂循吏爱民的固定典故（如白居易《甘棠馆》）。
- 孔子以「周召」为礼乐政治的典范。

# 姬发（周武王）

## 基本信息
- 时代：商末周初（生年不详—约前 1043 卒）
- 身份：周文王次子、周朝开国君主（约前 1046—前 1043 在位）
- 母：太姒；弟：姬旦（周公）等
- 关键事件：孟津观兵、牧野之战、封建诸侯

## 生平年表
1. **继位**：文王卒，发继位，以太公望为师、周公旦为辅，「修文王绪业」。
2. **孟津观兵（前 1048？）**：载木主（文王神主）东观兵，诸侯不期而会者八百，「皆曰纣可伐矣」；武王曰「未知天命」，还师（《史记·周本纪》）。
3. **牧野之战（约前 1046）**：纣杀比干、囚箕子；武王率戎车三百乘、虎贲三千、甲士四万五千，会诸侯于牧野，作《牧誓》；商师倒戈，「纣师虽众，皆无战心」，纣自焚于鹿台。
4. **克商之政**：封纣子武庚以续殷祀；散鹿台之财、发钜桥之粟；释箕子囚、封比干墓、表商容闾；封功臣昆弟（封尚父于齐、周公于鲁、召公于燕）。
5. **忧患而卒**：克商后「自夜不寐」，忧天下未定；约前 1043 崩，子诵（成王）年幼继位，周公摄政。

## 主要事迹
- **牧野一战定天下**：以少胜多，终结商六百年统治。
- **《牧誓》**：战前动员，「牝鸡无晨」斥纣听妇言、弃祭祀、不用亲族——中国最早的战前檄文之一。
- **封建与善后**：封殷续祀、散财发粟、表忠释囚——以宽政收服殷民。
- **九鼎迁周**：象征天命转移（后世叙事）。

## 金文/考古佐证
- **利簋**（陕西临潼出土，现藏国博）：铭文「武王征商，唯甲子朝，岁鼎，克昏夙有商」，直接印证牧野之战与甲子日，是断代工程的关键器物。
- **何尊**：「唯武王既克大邑商，则廷告于天」。
- 牧野地望（今河南卫辉）有考古讨论。

## 传说层辨析
- **白鱼跃舟、赤乌流火**等祥瑞（《史记》所载）为当时占卜/征兆话语，属叙事层。
- **孟津观兵年份**与「八百诸侯」数字有夸张成分。

## 后世评价
- 司马迁：「武王克殷，天下宗周」（《史记·周本纪》）。
- 儒家以武王为「汤武革命」的典范（孟子：「闻诛一夫纣矣，未闻弑君也」）。
- 与文王并称「文武」，成为周人立国的双重象征。

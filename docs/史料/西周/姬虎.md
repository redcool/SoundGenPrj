# 姬虎（召穆公·召伯虎）

## 基本信息
- 时代：西周中晚期（约前 9 世纪—前 8 世纪初）
- 身份：召公奭后裔、周厉王与宣王之卿士、共和行政二相之一
- 又称：召穆公、召伯虎
- 相关铜器：召伯虎簋（五年琱生簋、六年琱生簋等，学界多与召伯虎关联）

## 生平年表
1. **厉王专利**：厉王好利，近荣夷公，召穆公与芮良夫谏，不听。
2. **弭谤之谏（约前 845）**：厉王使卫巫监谤，召穆公谏曰「防民之口，甚于防川。川壅而溃，伤人必多……是故为川者决之使导，为民者宣之使言」（《国语·周语上》）。
3. **国人暴动（前 841）**：国人攻王宫，厉王奔彘；太子静（后来的宣王）藏于召公家。
4. **以子代太子**：国人围召公之宅索太子，召公曰「昔吾骤谏王，王不从，以及此难」，遂以其子代太子，太子得脱（《史记·周本纪》）。
5. **共和行政（前 841—前 828）**：厉王出奔，召公与周定公共理国政，号「共和」；中国历史确切纪年自此始（另有「共伯和干政」异说）。
6. **宣王中兴（前 828 后）**：共和十四年，太子静即位为宣王，召公与周定公辅之，「修政，法文、武、成、康之遗风，诸侯复宗周」。
7. **征伐**：《诗经·大雅·江汉》「江汉浮浮，武夫滔滔……匪安匪游，淮夷来求」，记召虎受命征淮夷；召伯虎簋铭文亦记其受王命整军、征伐。

## 主要事迹
- **防民之口，甚于防川**：中国政治思想史上关于言论与治乱关系的经典论断。
- **以子易太子**：以身家保王室血脉，被视为「臣道之极」。
- **共和行政**：无王而治十四年，是中国历史上第一次「虚君共治」的实践。
- **宣王中兴的支柱**：与尹吉甫、虢季子白、方叔等共成中兴。

## 金文/考古佐证
- 召伯虎簋（琱生簋）铭文涉及土田狱讼与王命，可与《诗经·江汉》互证召伯虎其人其事。
- 《诗经·大雅·江汉》《小雅·黍苗》均涉召穆公经营南国。

## 传说层辨析
- **「共和」之「共」**：一说为「共伯和」（共国国君和）摄政，一说为「周召共和」二相共治；《史记》取二相说，本档并列注明。
- **以子代太子**：《史记》所载，细节（围宅、交子）后世有渲染。

## 后世评价
- 与周公并称「周召」，为后世「贤相」的代名词。
- 「防民之口」被历代谏臣引用，成为言论自由的古典依据。
- 共和元年（前 841）为中国确切纪年的起点，其政治意义远超个人。

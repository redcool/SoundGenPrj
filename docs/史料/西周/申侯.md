# 申侯

## 基本信息
- 时代：西周晚期（周幽王时，前 8 世纪）
- 身份：申国（今河南南阳一带，一说陕西眉县）之君、申后之父、宜臼（周平王）之外祖父
- 关键事件：引犬戎攻周，杀幽王于骊山（前 771），西周亡
- 性质：争议人物——「有委屈的复仇者」与「引外族亡国的罪人」并存

## 生平年表
1. **联姻王室**：其女为幽王后（申后），外孙宜臼为太子。
2. **废后之变**：幽王嬖褒姒，废申后与太子宜臼，立褒姒子伯服——申侯的政治利益与家族尊严同时受损。
3. **谏而不听**：申侯入谏，幽王不听（《史记·周本纪》未详载谏辞）。
4. **引戎攻周（前 771）**：联合缯国与西夷犬戎攻镐京；幽王举烽火而诸侯不至，被杀于骊山，褒姒被掳。
5. **拥立平王**：与鲁、许等诸侯共立宜臼为平王；平王东迁洛邑（前 770），东周始。
6. **身后的评价**：被视为「引狼入室」的始作俑者；亦有「为女复仇」的同情解读。

## 主要事迹
- **私仇引外兵**：西周灭亡的直接军事原因。
- **平王东迁的推手**：其行动间接促成周室东迁与东周格局。

## 金文/考古佐证
- 申国地望（南阳）有考古线索；「申」器（如申公簋等，多春秋）可见申国存在，早期材料有限。
- 骊山、镐京遗址的毁弃与周室东迁可对读。

## 传说层辨析
- **烽火戏诸侯**：与申侯行动同属「西周灭亡叙事」，前者为传说层，后者为史实框架。
- **申侯的动机**：史书以「怒」记之，具体政治交易（与缯、犬戎的盟约）不详。

## 后世评价
- 传统史评：以「引戎」为罪，属亡国责任的承担者之一。
- 现代史学：强调其行为的宗法逻辑（废嫡立庶违背礼制），但「引外族」的手段仍受谴责——本工程按「争议人物」处理，曲中两面并存。

# 姬昌（周文王）

## 基本信息
- 时代：商末（约前 1112？—前 1050 前后在世）
- 身份：古公亶父之孙、季历之子、商末西伯（西方诸侯之长）、周朝奠基者，追尊文王
- 都邑：岐周（今陕西岐山）
- 配偶：太姒；子：伯邑考、姬发（武王）、姬旦（周公）等十子

## 生平年表
1. **继位为西伯**：季历被商王文丁所杀，姬昌继位，笃行仁政。
2. **德政聚人**：「笃仁，敬老，慈少，礼下贤者，日中不暇食以待士」，伯夷、叔齐、太颠、闳夭、散宜生、南宫括等归之（《史记·周本纪》）。
3. **羑里之囚（约前 1060）**：崇侯虎谮于纣，纣囚西伯于羑里；七年中「盖益《易》之八卦为六十四卦」（《史记·周本纪》——演易为传统说法）。
4. **获释**：散宜生等献美女奇物于纣，纣释之，赐弓矢斧钺，使专征伐。
5. **剪商布局**：伐犬戎、密须、耆国、邗、崇侯虎；「三分天下有其二，而犹服事殷」（《论语·泰伯》）。
6. **迁都丰邑**：自岐迁丰（今陕西西安西南），为武王克商铺路。
7. **卒**：约前 1050 前后卒，子发继位；后追尊文王。

## 主要事迹
- **演《易》**：羑里七年演六十四卦，为《周易》传统叙事的核心（学者多认为《易》成书非一人一时，文王与《易》的关系为传统说法）。
- **渭水求贤**：「西伯将出猎，卜之……果遇太公于渭之阳，与语大说」（《史记·齐太公世家》）。
- **断虞芮之讼**：虞、芮之人争田，入周见耕者让畔、行者让路，惭而归，诸侯闻之曰「西伯盖受命之君」。
- **三分天下有其二**：以德服人而非以力，成为儒家「王道」的原型。

## 金文/考古佐证
- **墙盘**（西周中期，宝鸡扶风出土）铭文开篇「曰古文王，初盩和于政」，为周人自述文王德政的最早实物之一。
- 周原遗址（岐山、扶风）甲骨与青铜器，为文王时期岐周都邑提供考古背景。

## 传说层辨析
- **「文王受命称王」**：传统说法，但《史记》未明言其称王；学界有「生称王/追尊」之争，本档取「追尊」并注明。
- **「文王百子」**：《诗经》「则百斯男」为修辞，实见于记载者十子左右。
- **「画地为牢」**等故事为后世传说。

## 后世评价
- 孔子：「文王既没，文不在兹乎」（《论语·子罕》）。
- 《诗经·大雅·文王》：「文王在上，於昭于天」——周人自我认同的精神图腾。
- 儒家以文王为「内圣外王」的起点。

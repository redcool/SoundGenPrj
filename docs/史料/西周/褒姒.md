# 褒姒

## 基本信息
- 时代：西周晚期（周幽王时，前 8 世纪）
- 身份：褒国（今陕西汉中一带）之女、周幽王之后、伯服之母
- 正史记载：极简——「幽王嬖爱褒姒」「褒姒不好笑」
- 定性：本工程按「被污名者」处理，不单列恶名曲（同妲己）

## 生平年表
1. **入宫**：幽王伐褒，褒人献褒姒以赎罪（《史记·周本纪》）。
2. **得宠生子**：生子伯服，幽王爱之。
3. **废后立己**：幽王废申后及太子宜臼，立褒姒为后、伯服为太子——直接触怒申侯。
4. **「不好笑」与烽火**：史称褒姒不好笑，幽王为博一笑举烽火戏诸侯（《史记》，细节为后世层累）。
5. **亡国被掳（前 771）**：犬戎破镐京，幽王死，褒姒被掳（一说被杀），下落不明。

## 主要事迹
- 正史中她几乎没有独立行动，全部事迹都依附于幽王的决策。
- 「红颜祸水」叙事的主要承载者——但这一叙事成型于后世（尤其《列女传》系统）。

## 金文/考古佐证
- 无。褒姒不见于金文；西周灭亡的考古证据（镐京毁弃）与她的个人行为无直接关联。

## 传说层辨析（重点）
- **烽火戏诸侯**：先秦文献（《左传》《国语》）未见；烽燧大规模使用年代存疑，学界多判为后世层累的「失信亡国」母题。
- **「褒姒不好笑」**：《史记》有载，但「不笑—举烽火—大笑」的因果链是叙事构造。
- **《列女传》的褒姒**：刘向系统将亡国归咎于女性，是汉代政治伦理的投射。
- **龙漦（龙涎）生褒姒**：《国语·郑语》所载神话，属神话层。

## 后世评价
- 传统：亡国祸水（《诗经·小雅·正月》「赫赫宗周，褒姒灭之」——已是当世或近世的归因）。
- 现代：史学界普遍认为西周的灭亡是制度、军事、外交（申侯引戎）多重因素，褒姒被过度归因。
- 本工程立场：不单列恶名曲，在《烽火》中作「被历史甩锅者」一笔带过。

# 姬宫湦（周幽王）

## 基本信息
- 时代：西周晚期（在位前 781—前 771）
- 身份：宣王之子、西周最后一任王
- 后妃：申后（申侯之女）、褒姒；子：宜臼（平王，被废）、伯服（褒姒所生，立为太子）
- 佞臣：虢石父

## 生平年表
1. **即位（前 781）**：宣王崩，子宫湦即位；时西周已「丧南国之师」，国力疲弱。
2. **嬖褒姒**：伐褒，褒人献褒姒；幽王宠之。
3. **废后立妾**：废申后及太子宜臼，立褒姒为后、伯服为太子——结怨申侯（《史记·周本纪》）。
4. **烽火戏诸侯（传说层定形）**：褒姒不好笑，幽王为博一笑，数举烽火，诸侯至而无寇，褒姒乃大笑；后诸侯不至（《史记·周本纪》，细节后世增饰）。
5. **任用佞臣**：以虢石父为卿，「善谀好利」，国人皆怨。
6. **犬戎之祸（前 771）**：申侯怒，与缯、西夷犬戎攻周；幽王举烽火，诸侯兵不至；被杀于骊山之下，褒姒被掳（一说被杀），西周亡。
7. **二王并立**：宜臼（平王）与余臣（携王）一度并立，十余年后平王东迁洛邑。

## 主要事迹
- **废嫡立庶**：直接触发申侯之怒，是西周灭亡的近因。
- **失信于诸侯**：无论烽火细节真伪，「失信」是后世对其核心定性。
- **骊山之死**：西周终结的标志性事件。

## 金文/考古佐证
- 幽王时期青铜器较少且多争议；骊山、宗周（镐京）遗址的毁弃层可与犬戎之祸对读。
- 「烽火」制度在西周是否存在，学界有质疑（烽燧大规模使用或晚至战国秦汉），这是「烽火戏诸侯」可靠性的关键疑点。

## 传说层辨析
- **烽火戏诸侯**：《史记》有载，但先秦文献（《左传》《国语》）未见；烽燧制度年代存疑，学界多判为后世层累的「失信亡国」母题故事。
- **褒姒「不好笑」与「红颜祸水」**：正史仅记其不好笑；「祸水」为后世建构，本工程不单列褒姒恶名曲（同妲己处理）。
- **伯服/宜臼之争**：史实框架成立，细节有增饰。

## 后世评价
- 《诗经·小雅·正月/十月之交》等变雅之作，多被视为对幽王时的讥刺。
- 与厉王并称西周「二恶」，但幽王是「亡国之君」的原型。
- 现代史学更强调制度与外力（申侯引戎、王室衰微），而非「一笑倾国」。

# 姬旦（周公旦）

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王第四子、武王之弟、周初摄政、鲁国始祖、后世尊为「元圣」
- 采邑：周（今陕西岐山北），故称周公
- 活动：武王、成王两朝（摄政七年）

## 生平年表
1. **佐武王克商**：武王即位，周公为辅；牧野之战后，「周公旦把大钺，毕公把小钺，以夹武王」（《史记·周本纪》）。
2. **克商后的安置**：封纣子武庚禄父以续殷祀，令管叔、蔡叔、霍叔监殷（三监）。
3. **武王崩，摄政当国**：成王年幼，「周公恐诸侯畔周，公乃摄行政当国」（《史记·周本纪》）；管叔、蔡叔疑其篡位，流言四起。
4. **东征三年**：奉成王命东征，诛武庚、杀管叔，放蔡叔，宁淮夷东土（《史记·鲁周公世家》）。
5. **营成周（洛邑）**：成王五年营洛邑，为东都，殷遗民迁居，周室东控天下的枢纽。
6. **制礼作乐**：确立宗法、封建、礼乐体系，「六年制礼作乐」（《尚书大传》）；孔子终身推崇。
7. **致政成王**：七年还政，北面就臣位（《史记·鲁周公世家》）。
8. **晚年**：成王十一年卒（约前 1032？）；葬于毕。

## 主要事迹
- **东征平叛**：三监之乱是周初最大危机，周公以三年平定，保住新王朝。
- **封建诸侯**：「立七十一国，姬姓独居五十三人」（《荀子·儒效》），以宗法血缘固天下。
- **制礼作乐**：礼别尊卑、乐和同异，奠定三千年礼乐文明的骨架。
- **吐哺握发**：「我一沐三捉发，一饭三吐哺，起以待士，犹恐失天下之贤人」（《史记·鲁周公世家》）。
- **《尚书》诸篇**：《大诰》《康诰》《酒诰》《梓材》《召诰》《洛诰》《多士》《无逸》《君奭》《立政》多与周公相关。

## 金文/考古佐证
- 禽簋（周公东征）、克盉克罍（分封）、何尊（「宅兹中国」营成周）等铭文，与周公东征、营洛、分封的记载互证。
- 洛阳成周城址考古（汉魏故城下早期城址）为营洛提供实物线索。

## 传说层辨析
- **「周公解梦」**：与周公无关，系后世托名。
- **「周公之礼」**：礼乐制度为史实，但具体仪节多经后世（孔子及汉儒）整理增饰。
- **摄政称王问题**：学界有争议（摄政 vs 称王），《尚书·大诰》等文本与金文（如何尊「唯王五祀」）是核心争论点，本档取「摄政」说并注明争议。

## 后世评价
- 孔子：「久矣，吾不复梦见周公」（《论语·述而》）——以周公为理想政治象征。
- 孟子以「周公思兼三王」称其集大成。
- 贾谊、司马迁均以周公为臣道极致（《史记·鲁周公世家》赞）。

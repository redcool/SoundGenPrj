# 姬处（霍叔）

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王之子、武王之弟、霍国（今山西霍州一带）之君、三监之一
- 结局：三监之乱后被废为庶人（一说降爵），史载简略（《史记·管蔡世家》附见）

## 生平年表
1. **受封于霍，监殷**：武王封霍叔于霍，位列三监。
2. **从乱（约前 1042）**：管蔡作乱，霍叔附从。
3. **被废**：周公东征后处置三监，「霍叔降为庶人」（史载简略，具体处置有异说：有「废」「降」「迁」等说）。
4. **霍国 later**：霍国后仍存（一说由其后裔续封），至春秋时为晋所灭（前 661 年晋献公灭霍）。

## 主要事迹
- **三监之三**：史书着墨最少的一位，是「背景板」式人物的典型。
- **霍国与霍姓**：霍国虽小，霍姓由此流出（后世霍去病等即出此系，谱系有追述成分）。

## 金文/考古佐证
- 霍州（山西霍县）有霍国故城遗址与考古调查；霍叔本人器物未见。

## 传说层辨析
- **霍叔的处置**：《史记》仅「降为庶人」一语，后世有「废」「流」等异说。
- **霍姓源流**：以国为氏的传统叙述，具体世系有缺环。

## 后世评价
- 传统史评：三监之乱中最无声的一位；其价值在于揭示「无主见者亦担责」。
- 与管蔡并称「三监」，成为宗室作乱的固定符号。

# 闳夭

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王四友之一、周初重臣
- 文献：《史记·周本纪》

## 生平年表
1. **归周**：与散宜生、南宫括、太颠同归文王。
2. **救文王**：文王囚羑里，闳夭与散宜生「求美女奇物」以献纣（《史记·周本纪》）。
3. **克商护卫**：「散宜生、太颠、闳夭皆执剑以卫武王」（《史记·周本纪》）。
4. **周初任职**：四友在周初多任要职（具体职掌史载不详）。

## 主要事迹
- **赎主**：与散宜生共主其事。
- **近臣护卫**：克商入都时的核心侍卫。

## 金文/考古佐证
- 暂无直接器物证据。

## 传说层辨析
- 事迹极简，多与散宜生连称，独立记载极少。
- 「闳夭」之「闳」为氏（一说名闳），字夭（或反之），古书互见。

## 后世评价
- 作为四友之一，属「周初贤者集团」的组成，个人形象模糊。
- 《孟子》将闳夭列为周之贤者（与散宜生并称）。

# 姬高（毕公高）

## 基本信息
- 时代：商末周初——成康之际（约前 11 世纪）
- 身份：周文王第十五子、武王之弟、毕国始祖、周初四圣之一（与周公旦、召公奭、太公望并称）
- 封地：毕（今陕西西安、咸阳一带）
- 活动：武、成、康三朝

## 生平年表
1. **武王克商**：毕公与周公夹辅武王入朝歌，「周公旦把大钺，毕公把小钺」（《史记·周本纪》）。
2. **克殷善后**：奉命释放被纣囚禁的百姓、平反冤狱、表彰商之忠臣（《史记·周本纪》）。
3. **成王时期**：周公东征时坐镇后方（镐京），安关中；后任太师，教导成王。
4. **成王临终顾命**：与召公奭同受顾命，辅佐康王（《尚书·顾命》）。
5. **康王命治成周**：康王命毕公「分居里，成周郊」，治理殷遗民，作《尚书·毕命》。
6. **卒年不详**：其后裔毕万仕晋，封于魏，为战国魏国之远祖。

## 主要事迹
- **戡黎主将**：清华简《耆夜》载其参与戡黎之役（学界采信度较高，标注为出土文献）。
- **定民心**：克殷后释囚、平反、表忠，迅速稳定新政权民心。
- **稳后方**：东征期间守镐京、抚关中，为前线提供稳定后方。
- **治成周**：划分居里、整顿吏治、推行礼乐，使成周成为周室东方屏障（《尚书·毕命》）。
- **成康之治**：与召公共辅，成就「刑错四十余年不用」的盛世。

## 金文/考古佐证
- 清华简《耆夜》《顾命》相关篇章；
- 毕国地望（西安、咸阳一带）有考古调查，但毕公高本人器物尚无确证出土。

## 传说层辨析
- 「毕公高为魏之远祖」为后世世系追述（《史记·魏世家》），中间世系有缺环。
- 「周初四圣」为后世概括语，非当世称谓。

## 后世评价
- 《尚书·毕命》以「旌别淑慝，表厥宅里」称其治绩，是西周吏治的范本。
- 相较周公之显、召公之名，毕公以「低调守成」著称，被后世视为「治国大管家」型贤相。

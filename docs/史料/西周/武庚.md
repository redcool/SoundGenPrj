# 武庚（禄父）

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：商纣王之子、名武庚、字禄父（一说名禄父）；周初封于殷，以续商祀
- 结局：三监之乱兵败被诛（《史记·周本纪》《鲁周公世家》）

## 生平年表
1. **商亡**：牧野之战纣自焚，商亡；武庚时为纣子，未随父死。
2. **受封续殷（约前 1046）**：武王「封纣子武庚禄父，以续殷祀，令修行盘庚之政」——以殷治殷，殷民大悦（《史记·周本纪》）。
3. **三监监视**：武王以管叔、蔡叔、霍叔「监殷」，武庚实际处于半独立状态。
4. **武王崩，周室动荡**：成王年幼，周公摄政；管叔、蔡叔疑周公，散布流言。
5. **三监之乱（约前 1042）**：武庚与管叔、蔡叔、霍叔联合，并联络淮夷、徐、奄等东夷诸国反周。
6. **周公东征三年**：武庚被诛，殷遗民被迁（一部分封于宋，由微子启统之；一部分迁洛邑）。

## 主要事迹
- **复国尝试**：作为商室唯一合法继承人，其叛乱是商遗民复国情绪的集中爆发。
- **联东夷**：把殷遗与东夷势力整合，使叛乱规模远超周室预期，迫使周公进行长达三年的东征。
- **殷祀的转移**：其死后，周以微子启封宋续殷祀，商祀以「宋」的形式延续。

## 金文/考古佐证
- 西周早期青铜器（如利簋、何尊）记克商与营洛；殷遗民迁洛的记载与洛阳出土殷遗民墓群可对读。
- 「武庚」其人未见自身器物出土。

## 传说层辨析
- **武庚之名**：「武庚」或为谥/号，「禄父」为字，古书互见。
- **「殷民大悦」**：属政治宣传性叙述，实际殷民情绪复杂。

## 后世评价
- 传统史评：以「叛乱」定性；但现代研究多视为「亡国之后复国」的必然反应。
- 与管蔡并称「三监之乱」，是周初分封与宗法制度被迫加速成熟的催化剂。

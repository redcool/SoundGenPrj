# 姬胡（周厉王）

## 基本信息
- 时代：西周晚期（在位约前 877—前 841，共和元年前出奔）
- 身份：夷王之子、西周第十任王；中国历史确切纪年（前 841）前的最后一位「在位王」
- 名臣：芮良夫、召穆公（姬虎）；佞臣：荣夷公

## 生平年表
1. **即位**：夷王崩，子胡即位；时王室已衰，诸侯不朝。
2. **好利近荣夷公**：「厉王即位三十年，好利，近荣夷公」，芮良夫谏「专利」之害，不听（《史记·周本纪》《国语·周语上》）。
3. **专利政策**：山林川泽之利收归王室，与民争利；「匹夫专利，犹谓之盗；王而行之，其归鲜矣」。
4. **弭谤（约前 845）**：国人谤王，厉王怒，得卫巫使监谤，「以告则杀之」；国人莫敢言，「道路以目」（《国语·周语上》）。
5. **召公谏**：「防民之口，甚于防川」——厉王不听。
6. **国人暴动（前 841）**：国人攻王宫，厉王出奔于彘（今山西霍州）；太子静藏于召公家，召公以子代之。
7. **共和行政**：厉王在彘，周召二相共理国政十四年。
8. **卒于彘**：前 828 卒；召公、周定公立太子静为宣王。

## 主要事迹
- **专利**：中国历史上最早被明确批评的「与民争利」政策。
- **弭谤**：以杀戮压制言论，「道路以目」成为言论禁锢的经典成语。
- **国人暴动**：中国历史上第一次有明确纪年的大规模民众暴动。
- **共和行政**：其出奔直接导致「共和」这一无王共治时期的出现。

## 金文/考古佐证
- 厉王时期青铜器（如㝬簋/胡簋，厉王自作器）铭文可证其在位与祭祀活动；「㝬」即厉王名「胡」的通假。
- 彘地（今山西霍州）有相关地名传承。

## 传说层辨析
- **「卫巫监谤」**：《国语》《史记》均载，属史实性叙述，细节（告则杀之）为概括。
- **厉王「暴虐」评价**：先秦文献已定型，但现代研究指出其改革或含强化王权、抑制贵族之意（争议，本档并列）。

## 后世评价
- 「防民之口，甚于防川」成为历代谏臣的第一引语。
- 与幽王并列，为西周「亡国双恶」的代表；但史家亦区分：厉王失国而未失位（出奔），幽王身死国亡。

# 姬封（卫康叔）

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王第九子、武王与周公同母弟、卫国始祖、周初司寇
- 初封：康（今河南禹州一带），故称康叔封；后徙封于卫（殷墟，今河南淇县）
- 活动：武、成、康三朝

## 生平年表
1. **初封康国**：武王克商后，封弟封于畿内康地；时年尚少。
2. **三监之乱**：管叔、蔡叔、霍叔联合武庚叛乱，康叔未参与。
3. **徙封卫国（约前 1040）**：周公东征平叛后，以殷墟故地封康叔，建卫国，镇抚殷遗民（《史记·卫康叔世家》）。
4. **受三诰**：周公作《康诰》《酒诰》《梓材》以戒之（《尚书》）：
   - 《康诰》：「明德慎罚」「必求殷之贤人君子长者，问其先殷所以兴，所以亡」；
   - 《酒诰》：以纣酗酒亡国为戒，严禁聚饮；
   - 《梓材》：以治木喻治国，勉其为政有法。
5. **治理卫国**：和集殷民，「殷民大说（悦）」；卫国成为西周东方屏障，驻「殷八师」。
6. **入朝为司寇**：成王亲政后，召康叔入朝任司寇（掌刑狱），赐卫室祭器。

## 主要事迹
- **问兴亡**：以「殷之所以兴、所以亡」为治国第一问，成为后世「以史为鉴」的原型。
- **明德慎罚**：宽民、慎刑、禁酒，殷遗民由敌视转为归附。
- **卫国长存**：卫为周代存续最久的诸侯国之一（至秦二世时始绝），其制度基础由康叔奠定。
- **殷八师驻地**：卫国是西周东方的军事重镇。

## 金文/考古佐证
- **康侯簋**（又称沬司土疑簋，现藏大英博物馆）：铭文记「令康侯啚（鄙）于卫」，是「康叔封卫」的第一手证据。
- 浚县辛村卫墓、淇县卫国故城等考古发现可与文献对读。

## 传说层辨析
- 《康诰》开篇「王若曰：孟侯，朕其弟，小子封」——「王」为成王还是周公代言之争，学界有讨论（本档取周公代成王命之说）。
- 康叔排行（第九子）依《史记·管蔡世家》所记同母兄弟次序，具体年龄无确证。

## 后世评价
- 《尚书》三诰为后世「新君就国」的教科书，汉代以《康诰》为治狱之要。
- 孔子整理《书》，以《康诰》为「仁政」范本之一。

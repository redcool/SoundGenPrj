# 虢石父

## 基本信息
- 时代：西周晚期（周幽王时，前 8 世纪）
- 身份：幽王之卿士、虢国（今陕西宝鸡/河南三门峡一带）之君（虢公）
- 定性：《史记·周本纪》「善谀好利，国人皆怨」

## 生平年表
1. **入朝用事**：幽王时以虢石父为卿，专擅朝政。
2. **善谀好利**：迎合幽王，加重赋敛，排斥直臣，「国人皆怨」。
3. **与褒姒之宠相表里**：幽王废申后、立褒姒，朝中无敢谏者。
4. **犬戎之祸（前 771）**：申侯引犬戎攻周，幽王死骊山；虢石父结局史无明载（一说死于乱军）。

## 主要事迹
- **谀臣标本**：与厉王时的荣夷公并列，为西周两大佞臣符号。
- **「国人皆怨」**：其聚敛与专权加速了西周末的民心离散。
- **「烽火」叙事的共谋者**：后世将烽火戏诸侯的荒唐与虢石父的谄谀并置。

## 金文/考古佐证
- 虢国墓地（三门峡上村岭、宝鸡虢镇）出土大量虢国青铜器，其中「虢季」「虢仲」等器可证虢国世系；虢石父本人器物未见确证。
- 西周晚期王室器铭文可见财政与军事压力。

## 传说层辨析
- **虢石父之名**：金文中「虢石父」见于「虢石父鼎」等器（学界多认为即此人），但其与幽王的关系细节为文献叙述。
- **结局**：史书未载其死，后世戏曲（如《烽火戏诸侯》）安排其被诛，属演绎。

## 后世评价
- 传统：亡国佞臣的典型，「善谀好利」四字定评。
- 现代：其用事反映幽王对旧贵族的倚重与王室财政困境，非单纯个人品德问题（并列注明）。

# 姬诵（周成王）

## 基本信息
- 时代：西周初（约前 1055？—前 1021 在位：约前 1043—前 1021）
- 身份：武王之子、西周第二任王；幼年即位，由周公摄政七年
- 母：邑姜（齐太公望之女）
- 弟：唐叔虞（晋之祖）

## 生平年表
1. **幼年即位**：武王崩，成王年少，「周公恐诸侯畔周，公乃摄行政当国」（《史记·周本纪》）。
2. **三监之乱与东征**：管叔、蔡叔、霍叔挟武庚作乱，周公东征三年平定。
3. **营成周（洛邑）**：成王五年，周公营洛，成王亲至洛邑「烝祭岁」，定东都（何尊「唯王五祀」）。
4. **桐叶封弟**：与弟叔虞戏，削桐叶为圭曰「以此封若」，史佚曰「天子无戏言」，遂封叔虞于唐（《史记·晋世家》；《吕氏春秋》亦载，带传说色彩）。
5. **亲政（前 1036 后）**：周公还政，成王亲理国政，「兴正礼乐，度制于是改」，大封诸侯。
6. **东征东夷**：成王亲政后，周公（或召公）继续东征，践奄、伐淮夷，周势力达东海。
7. **成康之治开端**：与子康王并称，「成康之际，天下安宁，刑错四十余年不用」（《史记·周本纪》）。
8. **临终顾命**：命召公奭、毕公高辅佐太子钊（《尚书·顾命》）。

## 主要事迹
- **还政与亲政**：顺利完成「摄政—还政」交接，为后世幼主即位提供范式。
- **大封诸侯**：封鲁（伯禽）、齐（太公）、燕（召公）、晋（叔虞）、卫（康叔）等，完成周初封建格局。
- **营洛成周**：建成东都，周室得以控御东方。
- **君无戏言**：桐叶封弟，成为「天子一言」的政治伦理典故。

## 金文/考古佐证
- **何尊**（宝鸡出土）铭文「唯王初迁宅于成周……宅兹中国」，与成王营洛互证。
- 琉璃河燕墓（克盉克罍）、曲阜鲁故城、天马-曲村晋侯墓地均对应成王时期的分封。

## 传说层辨析
- **桐叶封弟**：《史记·晋世家》有载，但《吕氏春秋》等所述细节（史佚谏言）为后世层累，学界多视为「传说定形」。
- **「成王年幼」之年岁**：无确证，传统「在襁褓」说多被认为夸张。

## 后世评价
- 与康王并称「成康之治」，为西周黄金时代。
- 后世以「成王」为守成之君的典范（与「开创」的文武相对）。

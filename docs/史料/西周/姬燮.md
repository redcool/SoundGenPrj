# 姬燮（周夷王）

## 基本信息
- 时代：西周中期偏晚（在位约前 885—前 878）
- 身份：懿王之子、西周第九任王；一说继孝王之位（孝王为懿王叔父）
- 特点：王位继承两次异常（孝王以叔继侄、夷王以侄复辟），王室威信大损

## 生平年表
1. **继位背景**：懿王崩，共王之弟辟方（孝王）立；孝王崩，诸侯复立懿王之子燮，是为夷王（《史记·周本纪》）。
2. **诸侯复立**：作为被「诸侯所立」的君主，其合法性先天不足。
3. **下堂见诸侯**：夷王「下堂而见诸侯」，礼制失守，「礼坏之始」（《礼记·郊特牲》《史记·周本纪》有相关记载）。
4. **烹齐哀公**：夷王听纪侯之谮，烹齐哀公于鼎（《史记·齐太公世家》）——以酷刑立威，反失诸侯心（一说此事的王为夷王，学界有讨论）。
5. **王室益衰**：「夷王之时，王室益衰」，诸侯朝觐益稀（《史记·周本纪》）。
6. **崩**：子胡（厉王）继位。

## 主要事迹
- **下堂之礼**：天子降阶见诸侯，象征王权对诸侯的实际让步。
- **烹齐哀公**：以极端手段干预诸侯内政，短期立威、长期失心。
- **王纲进一步解纽**：为厉王时的国人暴动与共和行政埋下伏笔。

## 金文/考古佐证
- 夷王时期青铜器（如师㝨簋等）铭文涉对淮夷、猃狁的战争，可见王室仍在用兵，但控制力下降。

## 传说层辨析
- **烹齐哀公**：《史记·齐太公世家》载「哀公时，纪侯谮之周，周烹哀公」，未明确王之谥号；后世系于夷王，学界有不同意见。
- **「下堂见诸侯」**：礼仪描述见于礼书，具体场合（是否朝会常制）不详。

## 后世评价
- 传统史评：非暴君，而是「弱世之君」——在错误的时机低了不该低的头。
- 礼学视角：夷王下堂是「礼坏」的标志性事件，与「礼乐征伐自诸侯出」同步。

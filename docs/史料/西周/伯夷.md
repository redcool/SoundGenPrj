# 伯夷

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：孤竹国（今河北卢龙一带）国君之长子、与弟叔齐并称「伯夷叔齐」
- 事迹定性：让国、叩马而谏、义不食周粟、采薇首阳；孔子称「古之贤人」，孟子称「圣之清者也」

## 生平年表
1. **让国**：孤竹君欲立三子叔齐；君卒，国人欲立长子伯夷，伯夷曰「父命也」，遂逃去；叔齐亦不肯立而逃，国人立中子。
2. **归周**：闻西伯昌「善养老」，兄弟往归之；至则文王已卒，武王载木主东伐纣。
3. **叩马而谏**：兄弟叩马而谏：「父死不葬，爰及干戈，可谓孝乎？以臣弑君，可谓仁乎？」左右欲兵之，太公曰「此义人也」，扶而去之（《史记·伯夷列传》）。
4. **义不食周粟**：武王克商，天下宗周，兄弟耻之，隐于首阳山，采薇而食。
5. **饿死**：或传妇人讥「子义不食周粟，此亦周之草木也」，遂绝食，作歌而卒（《史记·伯夷列传》所载歌辞）。

## 主要事迹
- **兄弟让国**：中国政治伦理中「让」的极致样本。
- **叩马而谏**：以「孝」「仁」两问质疑武王伐纣的正当性。
- **义不食周粟**：以生命坚持政治立场，成为「不食周粟」成语本源。
- **《采薇歌》**：「登彼西山兮，采其薇矣。以暴易暴兮，不知其非矣」——中国最早的隐逸/抗议诗之一。

## 金文/考古佐证
- 孤竹国地望（河北卢龙、迁安一带）有考古发现（孤竹青铜器），可证孤竹为商末方国。
- 首阳山地望有山西永济、甘肃陇西等多说，无定论。

## 传说层辨析
- **叩马而谏的言辞**：《史记》所载为司马迁整理，细节可能经加工，但「义不食周粟」的核心叙事在先秦已流传（《论语》《孟子》均提及）。
- **采薇歌**：或为后人所拟。
- **「让国」的动机**：孔子称「求仁得仁」，但亦有学者解为政治避祸。

## 后世评价
- 孔子：「伯夷、叔齐不念旧恶，怨是用希」（《论语·公冶长》）；「求仁而得仁，又何怨」。
- 孟子：「圣之清者也」——圣人中最清高的一类。
- 司马迁以《伯夷列传》为《史记》列传之首，寄寓「天道无亲，常与善人」之疑。

# 姬囏（周懿王）

## 基本信息
- 时代：西周中期（在位约前 899—前 892）
- 身份：共王之子、西周第七任王
- 特点：王室由盛转衰的转折期，「诗人作刺」之始

## 生平年表
1. **继位**：共王崩，子囏即位；时昭穆扩张之后国力疲敝。
2. **王室遂衰**：「懿王之时，王室遂衰，诗人作刺」（《史记·周本纪》）——变风变雅由此起。
3. **戎狄交侵**：懿王时期猃狁、西戎为患加剧，周室由攻转守（青铜器铭文多见「伐猃狁」记载）。
4. **迁都？**：一说懿王曾迁都犬丘（槐里），以避戎患（《世本》《汉书·地理志》引，学界有讨论）。
5. **崩**：叔父辟方（孝王）继位，王位继承出现异常。

## 主要事迹
- **诗人作刺**：中国诗歌史上「变雅」传统的政治起点——诗成为批评现实的工具。
- **由盛转衰**：昭王南征不返、穆王西征耗国，至懿王时财政与军力双弱。
- **戎患加剧**：西周中晚期西北边防压力的开端。

## 金文/考古佐证
- 懿王时期青铜器（如五年琱生簋等，年代有争议）铭文涉土地纠纷、军事行动，反映王权仍在运作但贵族势力上升。

## 传说层辨析
- **迁都犬丘**：文献记载零散，考古尚无确证。
- **「诗人作刺」的具体诗篇**：传统多指《诗经》变雅部分，但具体对应难以逐篇坐实。

## 后世评价
- 史评多作「衰世之君」：非失德，而是承接了一个下行的时代。
- 在礼乐文明史上，「作刺」的出现反而被视为政治尚有弹性的证明（允许批评）。

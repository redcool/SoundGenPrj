# 姬鲜（管叔）

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王第三子、武王之弟、管国（今河南郑州一带）之君、三监之首
- 结局：三监之乱兵败被周公所诛（《史记·周本纪》）

## 生平年表
1. **武王克商**：管叔为武王同母弟，参与克商与分封。
2. **受封于管，监殷**：武王封管叔于管，与蔡叔、霍叔共同监视武庚（三监）。
3. **武王崩，疑周公**：成王年幼，周公摄政当国；管叔以「兄终弟及」之序自认当政，疑周公将不利于成王，散布流言（《尚书·金縢》「管叔及其群弟乃流言于国」）。
4. **联合武庚叛乱（约前 1042）**：与蔡叔、霍叔挟武庚，联络淮夷反周。
5. **东征被诛**：周公东征三年，诛武庚、杀管叔（《史记·鲁周公世家》）。

## 主要事迹
- **三监之首**：三监之乱的主谋与组织者。
- **流言动周**：以宗室身份散布「周公将不利于孺子」，动摇周初政局。
- **宗法冲突的牺牲品**：其举事的核心是继承秩序之争（兄终弟及 vs 父死子继 + 摄政）。

## 金文/考古佐证
- 郑州管城（管国地望）有考古线索；管叔本人器物未见。
- 《尚书·金縢》《大诰》为其事的关键文献。

## 传说层辨析
- **管叔之死的细节**（被诛/自尽）：史书仅言「杀管叔」，细节为后世演绎。
- **管叔动机**：传统以「猜忌」定论，现代研究强调制度性冲突（摄政合法性）。

## 后世评价
- 传统：宗室作乱的反面教材。
- 现代：周初权力交接未制度化的必然产物——「兄终弟及」传统与「父死子继」新制的碰撞。

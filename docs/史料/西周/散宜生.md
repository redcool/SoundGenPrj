# 散宜生

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王四友之一、周初重臣
- 文献：《史记·周本纪》《尚书大传》《孟子》等

## 生平年表
1. **归周**：与南宫括、闳夭、太颠同归文王。
2. **救文王出羑里**：文王被囚，四友「求美女奇物善马」献纣；其中散宜生与闳夭出力尤多（《史记·周本纪》）。
3. **佐武王**：参与克商及周初政制建设。
4. **「散宜生、太颠、闳夭皆执剑以卫武王」**：克商入朝歌时，四友执剑护卫武王（《史记·周本纪》）。
5. **卒年不详**。

## 主要事迹
- **赎主之功**：以财物与美色赎回文王，是周人由弱转强的关键转折。
- **克商护卫**：入商都时的仪仗与护卫，体现四友的近臣地位。

## 金文/考古佐证
- 散氏盘（散国器，西周晚期）可证「散」为西周重要族氏，但与本条人物非同一时期，勿混。

## 传说层辨析
- 四友的具体分工（谁献何物）史载简略，后世叙述有增饰。
- 散宜生之「散」为氏，其名「宜生」为名（一说字）。

## 后世评价
- 作为「四友」之一，其价值在于「以财赎贤」的政治智慧。
- 孟子以「散宜生」为周之贤者之一（《孟子·尽心下》列举）。

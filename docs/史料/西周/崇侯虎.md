# 崇侯虎

## 基本信息
- 时代：商末（约前 11 世纪）
- 身份：崇国（今陕西户县一带）之君，商纣之诸侯（崇侯）
- 定性：谮西伯于纣，致文王被囚羑里（《史记·周本纪》）

## 生平年表
1. **商末诸侯**：崇为商西土大国，崇侯虎为纣之亲信。
2. **谮西伯（约前 1060）**：西伯昌积德累善、诸侯归之，崇侯虎谮于纣曰「西伯积善累德，诸侯皆向之，将不利于帝」；纣遂囚西伯于羑里（《史记·周本纪》）。
3. **文王伐崇**：西伯获释后，「伐崇侯虎而作丰邑」（《史记·周本纪》）——崇灭，丰邑成为周都。
4. **身后**：崇国故地入周，其名成为「谮臣」的符号。

## 主要事迹
- **一句谗言，七年囚**：直接导致文王羑里之囚，是周商关系转折的触发点。
- **崇国灭亡**：文王伐崇是「剪商」进程中最关键的一步（丰邑即由此而建）。
- **「崇侯虎」的形象**：《封神演义》将其塑造为反派，属文学演绎。

## 金文/考古佐证
- 崇国地望（户县）有考古线索；「崇」器铭文存世，可证崇国存在。
- 文王伐崇、作丰邑与丰镐遗址考古可对读。

## 传说层辨析
- **谮言的原文**：《史记》所记为史家拟语，具体措辞不可考。
- **《封神演义》中的崇侯虎**：小说形象（北伯侯、助纣为虐），与史书所载「谮西伯」的单一事迹差距很大。

## 后世评价
- 传统：谗臣的早期样本，「谮」这一政治行为的第一批记录之一。
- 历史作用：其谗言反而加速了周人的凝聚与剪商进程（反讽式评价）。

## 交叉索引
- 相关：姬昌（被谮者）、商纣（听谮者）

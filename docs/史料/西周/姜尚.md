# 姜尚（太公望·姜子牙）

## 基本信息
- 时代：商末周初（约前 1128—前 1015，传说寿高）
- 身份：周文王、武王之师（号「师尚父」）、齐国始祖
- 氏姓：姜姓、吕氏，名尚，字子牙（一说字牙）；又称太公望、吕望、吕尚
- 封地：齐（营丘，今山东淄博临淄一带）

## 生平年表
1. **渭水垂钓遇文王**：文王出猎，遇尚于渭之阳，「与语大说」，曰「吾太公望子久矣」，号「太公望」，立为师（《史记·齐太公世家》）。
2. **佐文王剪商**：「天下三分，其二归周者，太公之谋计居多」。
3. **牧野之战**：武王以尚为「师尚父」，总戎事；《诗经·大雅·大明》「维师尚父，时维鹰扬」。
4. **封齐就国**：武王封尚于齐营丘；尚「修政，因其俗，简其礼，通商工之业，便鱼盐之利」，齐遂为大国。
5. **成王时**：管蔡之乱，齐参与平叛（《史记·齐太公世家》「及周成王少时，管蔡作乱，淮夷畔周，乃使召康公命太公曰：东至海，西至河，南至穆陵，北至无棣，五侯九伯，实得征之」）。
6. **卒**：卒年不详，子丁公吕伋继位。

## 主要事迹
- **兵家之祖**：《六韬》托名于其，后世尊为兵家鼻祖。
- **牧野首功**：以谋略与战阵之术助武王克商。
- **齐国奠基**：因俗简礼、通商工、便鱼盐，奠定齐「滨海大国」的基础。
- **尊贤尚功**：齐文化与鲁「尊尊亲亲」形成对照（《吕氏春秋》《史记》）。

## 金文/考古佐证
- 齐故城（临淄）考古、齐国早期青铜器可为封建背景；
- 高青陈庄西周城址（「齐公」铭文）为齐国早期历史提供新线索（学界讨论中）。

## 传说层辨析
- **直钩钓鱼、愿者上钩**：不见于《史记》，为后世民间传说。
- **《六韬》**：战国至汉初成书，托名太公，非其亲撰。
- **寿一百三十九岁**：传说数字。
- **「太公在此，百无禁忌」**：民俗信仰层。

## 后世评价
- 儒家以「师尚父」为王者之师的典范；兵家尊为始祖；民间奉为「太公」神明。
- 与周公并称周初两大奠基者：一为「武功/权谋」、一为「文治/礼乐」。

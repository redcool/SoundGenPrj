# 太颠

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王四友之一、周初重臣
- 文献：《史记·周本纪》

## 生平年表
1. **归周**：与散宜生、南宫括、闳夭同归文王。
2. **救文王**：参与献物赎文王之事。
3. **克商护卫**：「散宜生、太颠、闳夭皆执剑以卫武王」。
4. **后续不详**。

## 主要事迹
- 与四友共事，个人事迹几无独立记载。
- 「太颠」一作「泰颠」，音同形异。

## 金文/考古佐证
- 暂无直接器物证据。

## 传说层辨析
- 记载最少的一位四友，其名多见于合称中。
- 《孟子》「太颠」列于周之贤者。

## 后世评价
- 作为「文王四友」的第四人，主要价值在于集体象征：周初以「聚贤」立国。

## 交叉索引
- 相关：姬昌、散宜生、南宫括、闳夭
- 曲目：暂无专曲

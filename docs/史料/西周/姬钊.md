# 姬钊（周康王）

## 基本信息
- 时代：西周前期（生年不详—约前 996 卒；在位约前 1021—前 996）
- 身份：成王之子、西周第三任王；与成王并称「成康之治」
- 名臣：召公奭、毕公高（顾命大臣）

## 生平年表
1. **即位**：成王崩，召公、毕公率诸侯奉太子钊见先王庙，立为康王（《尚书·顾命》）。
2. **命毕公治成周**：康王命毕公「分居里，成周郊」，作《尚书·毕命》——治理殷遗民、整顿东都。
3. **成康之治全盛**：「成康之际，天下安宁，刑错四十余年不用」（《史记·周本纪》）——刑罚搁置四十余年，是西周最安定的时期。
4. **北征/西征**：小盂鼎铭文记康王命盂伐鬼方，大胜献俘（学界多系于康王时期）。
5. **康王卒**：子瑕（昭王）即位，西周由盛转缓。

## 主要事迹
- **刑错不用**：不是无法，而是「法立而民不犯」，被后世视为治世最高标准。
- **治理殷遗**：以毕公「分居里」的办法，把殷遗民编户、分治、教化，消解复国情绪。
- **守成不折腾**：延续文武成之政，不兴大役、不轻用兵（除边患），国势稳定。

## 金文/考古佐证
- **小盂鼎**（一说康王时）：铭文详细记载伐鬼方、献俘、赏赐，是西周早期军事制度的重要材料。
- 康王时期青铜器（如大盂鼎，多认为康王时）铭文强调「酒无敢酖」「敬天保民」，与《酒诰》传统呼应。

## 传说层辨析
- 「刑错四十余年不用」为史家概括语，非逐年实录，但反映康王时期刑罚罕用的总体印象。
- 小盂鼎的年代（康王/昭王）学界有讨论。

## 后世评价
- 与成王并称「成康」，成为中国政治史上「治世」的原型符号。
- 后世多以「守成之君」评之：无功业之奇，而有无事之福。

# 南宫括

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：周文王四友之一（与散宜生、闳夭、太颠并称）、周初重臣
- 文献：《史记·周本纪》《尚书大传》等

## 生平年表
1. **归周**：文王「礼下贤者」，南宫括与散宜生、闳夭、太颠同往归之（《史记·周本纪》）。
2. **救文王**：文王被囚羑里，四友「求美女奇物善马以献纣」，纣释西伯（《史记·周本纪》）。
3. **佐武王克商**：四友参与克商与周初建制。
4. **武王克商后的善后**：据《史记·周本纪》，「命南宫括散鹿台之财，发钜桥之粟，以振贫弱萌隶」；又「命南宫括、史佚展九鼎保玉」。
5. **后世**：其名见于《论语》——孔子以「南宫适（括）」问「羿善射，奡荡舟，俱不得其死然；禹稷躬稼而有天下」，孔子不答，其人出而叹（《论语·宪问》）；一说即南宫括。

## 主要事迹
- **文王四友之一**：周初「聚贤」政治的代表。
- **救主之功**：以财物赎文王，是周商博弈中的关键一手。
- **散财发粟**：克商后安抚殷民、赈济贫弱，是周初德政的具体执行。

## 金文/考古佐证
- 「南宫」为周初大族，南宫乎钟、南宫柳鼎等器可证南宫氏在西周的活动（但与本条人物关系需谨慎）。

## 传说层辨析
- 《论语》中的「南宫适」是否即南宫括，学界多认为同一，但无确证。
- 四友救文王的具体过程（献美女奇物）为《史记》叙述，细节可能有加工。

## 后世评价
- 作为「文王四友」之一，是周初「人才集团」的象征。
- 孔子对其「尚德不尚力」的评价，使其成为儒家话语中的正面人物。

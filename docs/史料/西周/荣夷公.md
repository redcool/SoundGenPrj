# 荣夷公

## 基本信息
- 时代：西周晚期（周厉王时，约前 9 世纪）
- 身份：厉王卿士、荣国（今陕西户县一带）之君（荣公）
- 定性：《国语》《史记》列为厉王朝佞臣，「好专利而不知大难」

## 生平年表
1. **入朝用事**：厉王好利，荣夷公以「专利」之说进，得宠用事。
2. **推行专利**：将山林川泽之利收归王室，禁止平民采樵渔猎——「夫利，百物之所生也……王而行之，其归鲜矣」（芮良夫谏语）。
3. **芮良夫谏**：芮良夫直斥其「好专利而不知大难」，厉王不听。
4. **国人暴动（前 841）**：专利与弭谤激起国人暴动，厉王奔彘；荣夷公的下场史书未明载（一说被逐/被杀，无确证）。

## 主要事迹
- **专利政策的设计者/推动者**：把「与民争利」制度化的关键人物。
- **「不知大难」**：史家给出的定性——只算财政账，不算人心账。

## 金文/考古佐证
- 荣国地望（户县）有考古线索；荣夷公本人器物未见。
- 厉王时期「㝬簋」等王室器铭文可反映当时财政与祭祀压力。

## 传说层辨析
- 荣夷公的结局史无明载，后世戏曲/小说中的下场属演绎。
- 「荣公」与春秋时「荣成伯」等荣氏人物非同一人。

## 后世评价
- 与虢石父并列，为西周「佞臣」的两个标本：一在厉王（专利），一在幽王（善谀）。
- 现代研究指出：专利或含强化王室财政的理性考量，但执行方式彻底激化矛盾（争议，并列注明）。

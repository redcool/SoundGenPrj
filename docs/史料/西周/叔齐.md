# 叔齐

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：孤竹国君之三子、伯夷之弟；与兄并称「伯夷叔齐」
- 事迹：让国、随兄归周、叩马而谏、义不食周粟、采薇首阳

## 生平年表
1. **父命立己**：孤竹君偏爱叔齐，欲立之。
2. **让而不立**：父卒，叔齐让位于兄伯夷；伯夷以「父命」不受而逃；叔齐曰「立弟非义」，亦逃。
3. **随兄归周**：与兄同往周地，投文王养老之政。
4. **叩马而谏**：与兄同谏武王伐纣（同伯夷条）。
5. **隐于首阳**：与兄同隐，采薇而食，终饿死。

## 主要事迹
- **「亦不以国累其身」**：兄弟互让，使「让国」成为完整叙事（缺一不成）。
- **同死首阳**：与兄同赴死，构成「义」的完整性。

## 金文/考古佐证
- 同伯夷条（孤竹国考古、首阳山多地说）。

## 传说层辨析
- 叔齐的独立事迹极少，几乎总与伯夷并称；史书未单列其言论。
- 「叔齐让兄」的细节属《史记》叙述，可靠度与伯夷条同。

## 后世评价
- 与伯夷合称「夷齐」，成为「让国」「守节」的复合符号。
- 「夷齐」并称在先秦文献中已固定（《论语》《孟子》《庄子》均见）。

## 交叉索引
- 相关：伯夷（兄）、姬发、姜尚
- 曲目：《采薇》（义名-西周-卷1，与伯夷合曲）

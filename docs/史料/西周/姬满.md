# 姬满（周穆王）

## 基本信息
- 时代：西周中期（在位约前 976—前 922，约五十五年，为西周在位最久者）
- 身份：昭王之子、西周第五任王
- 名臣：祭公谋父、吕侯（甫侯）

## 生平年表
1. **即位**：昭王南征不返，子满即位，时年已五十（《史记·周本纪》「穆王即位，春秋已五十矣」）。
2. **修德行义**：初即位，「闵文武之道缺，乃命伯臩申诫太仆」。
3. **作《甫刑》（吕刑）**：命吕侯制刑，以「祥刑」为名，确立赎刑制度（《尚书·吕刑》）。
4. **西征犬戎（约前 965）**：祭公谋父谏「先王耀德不观兵」，穆王不听，征之，得四白狼四白鹿以归，「自是荒服者不至」（《国语·周语上》《史记·周本纪》）。
5. **东征九夷、徐偃王之战**：穆王东巡，徐偃王率九夷伐周，穆王造父驾车西归，破徐（《史记·秦本纪》等，细节多传说）。
6. **穆天子传西巡**：《穆天子传》载其乘八骏西行，会西王母于瑶池——战国以降的传说/小说层。
7. **卒**：子繄扈（共王）即位。

## 主要事迹
- **甫刑/吕刑**：中国早期刑法与赎刑制度的重要文献，强调「刑期无刑」。
- **西征犬戎**：扩张与「荒服不至」的代价，是西周由盛转缓的转折点之一。
- **东巡徐夷**：维持东西两线的宗主权威。
- **八骏西巡**：成为后世「远行/拓界」的文化母题（《穆天子传》）。

## 金文/考古佐证
- 穆王时期青铜器（如班簋、录伯簋等）铭文涉及其征伐与册命；「吕刑」的传统亦与西周中期法制演进相符。
- 学界对《穆天子传》地理（昆仑、西王母）多有考辨，属传说地理。

## 传说层辨析
- **《穆天子传》**：西晋汲冢出土，性质近小说/游记，其中八骏、西王母、瑶池之会均属传说层。
- **在位年数（55 年）**：依《史记》及夏商周断代工程推排，学界仍有讨论。
- **徐偃王**：其人其事的文献层累严重，可靠性有限。

## 后世评价
- 传统史评：有为之君而「王道衰缺」——扩张消耗国力，为共懿之后的衰退埋因。
- 文学形象远大于史实形象：八骏、瑶池、西王母使穆王成为最「传奇」的周王。

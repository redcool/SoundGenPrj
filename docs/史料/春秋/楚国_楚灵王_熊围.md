# 楚国 · 楚灵王 熊围

## 基本信息
- 在位：前 540—前 529
- 身份：楚共王之子、楚康王之弟；弑侄（郏敖）自立
- 关键事件：弑君夺位、筑章华台、乾溪之难众叛亲离、自缢

## 生平年表
1. **为令尹**：康王时掌军政，权势极盛。
2. **弑郏敖（前 541）**：康王卒，子郏敖立；熊围绞杀郏敖及其二子，自立为灵王（《左传·昭公元年》）。
3. **会盟与征伐**：前 538 年会诸侯于申；灭陈、蔡（前 531、前 529 复之）；伐吴。
4. **章华台**：筑章华之台，极尽奢丽，「国民疲焉」（《国语·楚语》）。
5. **乾溪之难（前 529）**：灵王在乾溪，弃疾（平王）等在国内作乱，杀太子禄；灵王众散，独行山中，饿不能起。
6. **自缢**：申亥收之，灵王自缢于申亥家（《左传·昭公十三年》）。

## 主要事迹
- **弑君得位**：楚国「弑君—自立」链条中的一环（后续平王亦以类似方式上位）。
- **章华台**：与吴之姑苏台并称，成为「穷奢亡身」的符号。
- **众叛亲离**：其败不在外敌，而在国内人心尽失——「王在乾溪，国已非王之国」。

## 史料辨析
- 《左传·昭公十三年》记载极详（含「雨雪，王皮冠」「王曰：余杀人子多矣」等细节），可信度较高。
- 章华台的具体规模、位置有考古讨论（湖北潜江龙湾遗址被多数学者关联为章华台）。

## 后世评价
- 传统：穷奢极欲、失德失国的典型；「楚灵王好细腰，国中多饿人」（《墨子》《韩非子》）为其文化形象的延伸。
- 现代：其扩张（灭陈蔡、会诸侯）显示楚国国力正盛，其败亡是统治方式而非国力问题。

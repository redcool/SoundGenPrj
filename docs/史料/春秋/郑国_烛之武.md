烛之武是春秋时期郑国（今河南新郑一带）的一位传奇外交家和爱国志士。他在历史上的生平记载极为简练，其一生最大的高光时刻，莫过于在年逾古稀、垂垂老矣之时，凭借绝佳的政治眼光与雄辩口才，孤身一人劝退秦国大军，从而拯救了命悬一线的郑国，这就是名垂青史的“烛之武退秦师”。
关于烛之武的生平，可以从以下几个维度进行深度解析：

1. 怀才不遇的前半生（前半生履历）

在著名的外交危机爆发之前，烛之武在郑国只是一个“圉（yǔ）正”。
• 职级低微： “圉正”是掌管养马、管理畜牧的小官。
• 长期被埋没： 烛之武极具政治才华和外交远见，但在郑文公在位期间一直不被重用，空有一身抱负却无处施展，直到满头白发、人至暮年，依然默默无闻。

2. 临危受命：一战成名的时代背景

公元前630年（鲁僖公三十年），郑国迎来了灭国级别的灾难——秦、晋两国合兵围攻郑国。
• 起因： 晋国（晋文公重耳）因当年流亡时曾受到郑国的无礼对待，加上郑国在城濮之战中曾倾向于楚国，因而联合秦国（秦穆公）大举讨伐。
• 引荐： 在郑国危在旦夕时，大臣佚之狐向郑文公极力推荐烛之武，称其“才若能用，秦师必退”。
• 经典的一幕（抒发怨气与深明大义）： 当郑文公亲自登门求助时，饱受冷落一辈子的烛之武端起架子发了牢骚：“臣之壮也，犹不如人；今老矣，无能为也已。”（我年轻时都不如别人，现在老了，无能为力了）。郑文公立即放下身段认错道歉，坦言是自己的过错，并晓以大义。烛之武最终放下了个人的恩怨，以国家利益为重，答应临危受命。

3. 外交高光：“夜縋而出”与“五论退秦师”

为了面见秦穆公，当时已是白发苍苍的烛之武，在夜晚用绳子绑在身上，从戒备森严的郑国城墙上“缒”（顺着绳子滑下）了出去，私访秦国兵营。
他在游说秦穆公时，展现了极高明的外交艺术，史称“五论救弱国”：
1. 以退为进，博取好感： 一上来就承认郑国快灭亡了，但这与他无关，他是站在秦国的利益上考虑。
2. 分析地理，直击痛点： 越过晋国去把远方的郑国当作秦国的边疆，这在地理上很难统治；亡郑实际上只是在“亡郑陪邻”（让旁边的晋国增加土地和实力），邻国强大了，秦国相对就变弱了。
3. 抛出诱饵（东道主）： 如果保留郑国，让郑国作为秦国向东交往的“东道主”，秦国使者来往时，郑国可以负责提供行李、住宿和物资供应，这对秦国百利而无一害。
4. 揭露旧账，挑拨离间： 提醒秦穆公，晋国（晋惠公）是个过河拆桥、不讲信用的人，当年答应给秦国的焦、瑕两地，至今都没给。
5. 预测未来，引发恐惧： 晋国贪得无厌，等它往东灭了郑国扩张完毕后，接下来必然会向西侵犯秦国的利益。
结果： 秦穆公被彻底说服，不仅当场撤军，甚至还留下杞子等三位大将帮助郑国守城。失去盟友的晋文公见势不妙，也只能被迫撤兵，郑国奇迹般地转危为安。

4. 烛之武的后半生与历史评价

在《左传》等正史中，关于烛之武退秦师之后的结局并无太多笔墨记载，但他的历史形象已经通过这一战定格为永恒。
• 智勇双全的爱国义士： 面对秦晋两个超级大国的兵临城下，他敢于黑夜孤身入敌营，表现出超人的胆识（勇）；在游说中不卑不亢，不谈郑国之危、只谈秦国之利，展现了高超的政治谋略（智）。
• 公而忘私、不计前嫌： 虽大半生被朝廷冷落，但在国家生死存亡关头能深明大义，摒弃个人恩怨挺身而出。
• 大器晚成的典型： 他的一生告诉后人，只要有真才实学，哪怕一辈子处于底层、哪怕年龄再大，只要机会来临，依然能一举改变历史的走向。

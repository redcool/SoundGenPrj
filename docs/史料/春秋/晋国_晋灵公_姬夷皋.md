# 晋国 · 晋灵公 姬夷皋

## 基本信息
- 在位：前 620—前 607
- 身份：晋襄公之子；幼年即位，由赵盾（赵宣子）执政
- 关键事件：厚敛以雕墙、从台上弹人、杀宰夫；被赵穿弑于桃园

## 生平年表
1. **幼年即位（前 620）**：襄公卒，太子夷皋年幼；赵盾欲立公子雍，穆嬴（夷皋母）抱子哭于朝，遂立夷皋（《左传·文公七年》）。
2. **赵盾专政**：国政尽出赵氏，灵公长而不得亲政。
3. **失德三事**：「厚敛以雕墙」「从台上弹人，而观其辟丸」「宰夫胹熊蹯不熟，杀之，置诸畚，使妇人载以过朝」（《左传·宣公二年》）。
4. **鉏麑之刺**：灵公使鉏麑刺赵盾，鉏麑见赵盾盛服将朝、坐而假寐，感其恭敬，触槐而死。
5. **伏甲之宴**：灵公设宴伏甲欲杀赵盾，提弥明与灵辄救之，赵盾出走。
6. **被弑（前 607）**：赵穿弑灵公于桃园；赵盾未出境而复，太史董狐书「赵盾弑其君」，赵盾辩，董狐曰「亡不越竟，反不讨贼」（《左传·宣公二年》）。

## 主要事迹
- **「不君」典型**：《左传》以「晋灵公不君」开篇，是中国史书最早的「失君德」判词之一。
- **董狐直笔**：「赵盾弑其君」与齐国太史并称，成为中国史学「书法不隐」的双峰。
- **君臣相疑的极端**：君欲杀执政，执政出走而君被其族人所弑。

## 史料辨析
- 《左传》记载最详；《史记·晋世家》大体同源。
- 「弹人」「杀宰夫」等细节是否夸大，学界有讨论，但「不君」的定性自先秦已定。
- 赵盾是否主谋：董狐的书法断为「弑」，但《左传》明言赵穿动手，赵盾「亡不越竟」是定罪关键。

## 后世评价
- 传统：失德之君的样本，「君不君则臣不臣」的注脚。
- 史学意义：其死与董狐之笔，共同构成「史权高于君权」的象征。

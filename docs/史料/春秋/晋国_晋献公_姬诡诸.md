# 晋国 · 晋献公 姬诡诸

## 基本信息
- 在位：前 676—前 651
- 身份：晋武公之子；晋国由小转强的关键君主
- 关键事件：并国十七、服国三十八；宠骊姬、杀太子申生、逐重耳与夷吾

## 生平年表
1. **即位与扩张**：武公卒，诡诸立；前 671 年伐骊戎，得骊姬；前 668 年「城聚」，前 661 年灭耿、霍、魏（《左传·闵公元年》）。
2. **假道伐虢（前 658—前 655）**：用荀息之计，假道于虞以伐虢；灭虢、还灭虞，「唇亡齿寒」典故所出。
3. **并国十七、服国三十八**：《韩非子》《国语》所称其疆域功业。
4. **骊姬之乱**：宠骊姬，欲立其子奚齐；骊姬谮太子申生置毒于祭肉（前 656）。
5. **杀申生、逐二子**：申生自缢于曲沃；重耳奔蒲、夷吾奔屈，皆出奔（《左传·僖公四年》）。
6. **托孤与卒（前 651）**：病重，托奚齐于荀息；卒后里克杀奚齐、卓子，荀息死之，晋乱。

## 主要事迹
- **开疆**：灭耿、霍、魏、虢、虞，使晋据有山西高原与豫西通道，为晋文公霸业奠基。
- **家祸**：以宠爱乱嫡庶，逼死一子、逐出二子，导致晋国十余年内乱。
- **「假道伐虢」**：中国军事外交史上最著名的计谋之一。

## 史料辨析
- 《左传》对骊姬之乱的叙述最完整；《国语·晋语》提供大量对话细节（有加工）。
- 「并国十七，服国三十八」为概括数字，含夸张成分。

## 后世评价
- 传统：功过并存的典型——「外并诸侯，内乱骨肉」。
- 现代：其扩张奠定了晋国百年霸业的地理基础；其家乱则暴露「嫡庶无定」的制度风险。

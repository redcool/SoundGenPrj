百里奚（约公元前726年—公元前621年），春秋时期楚国宛（今河南南阳）人，是秦国历史上著名的政治家和贤臣。他的一生充满传奇色彩，从前半生的孤苦颠沛、沦为奴隶，到后半生被秦穆公重用，辅助秦国开疆拓土，被称为“五羖大夫”（“羖”意为公羊皮，即用五张黑公羊皮换来的大夫）。
以下是百里奚的主要人生经历：

1. 早年困顿与出游求官

• 出身贫寒： 百里奚自幼家境贫寒，但他饱读诗书，才华横溢。由于在楚国得不到重用，他在三十多岁时决定离开家乡，周游列国以求出路。
• 妻子送别： 临行前，妻子杜氏杀掉了家里唯一的一只下蛋母鸡，烧毁了木门闩作柴火，为他做了一顿饯行饭，并嘱托他富贵后不要互相遗忘。

2. 流落诸国与虞国为官

• 颠沛流离： 百里奚先后去过齐国、周天子王室等地，但都因没有门路或看透政局动荡而离开。期间他曾沦落到乞讨度日，结识了挚友蹇叔。
• 出仕于虞： 在蹇叔的劝说和引荐下，百里奚前往虞国（今山西平陆），出任大夫。当时虞国国君昏庸，百里奚虽然知道虞君难成大事，但因为生活所迫且为了施展抱负，最终留了下来。

3. 亡国之奴与沦为媵臣

• 唇亡齿寒： 公元前655年，晋献公向虞国借道去消灭虢国。百里奚看穿了晋国的“假道伐虢”之计，但知虞君不会听从，便闭口不言。最终，晋国在灭掉虢国后，顺手也灭了虞国。
• 沦为媵臣： 虞国灭亡后，百里奚不愿投降晋国，成为俘虏。恰逢晋献公把女儿穆姬嫁给秦穆公，百里奚便被作为媵臣（陪嫁的奴隶）送往秦国。

4. 逃亡楚国与五羖赎身

• 逃亡被捉： 百里奚深感屈辱，在前往秦国的途中逃跑，一路流亡到楚国边境。楚国人见他擅长养牛，就让他留在楚国喂牛。
• 羊皮赎贤： 秦穆公得知百里奚是位难得的奇才，想用重金去楚国赎人。但大臣公孙支提醒：用重金赎人会暴露百里奚的价值，楚国人绝不会放人。
• 智赎计谋： 秦穆公于是派使者对楚国人说：“我们家的陪嫁奴隶百里奚逃到了这里，我们想用五张黑公羊皮（五羖）把他换回来，按秦国的法律惩罚他。”楚国人信以为真，便把七十多岁的百里奚装在囚车里交还给了秦国。

5. 秦国拜相与开疆拓土

• 三日长谈： 百里奚到达秦国后，秦穆公亲自为他打开刑具，并与他谈论国家大事长达三天三夜。秦穆公大喜过望，决定拜他为相。百里奚推辞，并推荐了自己的好友蹇叔，秦穆公遂将二人一并重用。
• 辅佐称霸： 百里奚执掌秦国国政期间，对内“谋无不中，举无不当”，实行教化，实行简朴宽厚的政治；对外辅助秦穆公东争中原、西讨诸戎，使得秦国“兼国二十，拓地千里”，称霸西戎，为后来秦国统一中国奠定了坚实的物质和政治基础。

历史佳话：相堂认妻

百里奚当了秦国宰相后，声名远扬。他的发妻杜氏因家乡遭遇灾荒，流落到秦国，在相府做洗衣谋生的女工。一天，相府举行宴会，杜氏认出了百里奚，便主动上前弹琴唱了一首歌：
“百里奚，五羊皮。忆别时，烹伏雌，炊扊扅，今日富贵忘我为？”
百里奚听后大为震惊，夫妻当场相认。这成了历史上不离不弃、富贵不忘发妻的一段佳话。

总结

百里奚的一生，是典型的“大器晚成”与“逆境崛起”的代表。孟子曾在《生于忧患，死于安乐》中高度评价他：“百里奚举于市”，将其作为在困境中磨练成长、最终成就伟业的千古典范。

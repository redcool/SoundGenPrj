孙叔敖（约公元前630年－公元前593年）是春秋时期楚国的著名令尹（宰相），被司马迁在《史记·循吏列传》中列为“天下第一循吏”（即最优秀的奉公守法、爱民清官）。他的一生不仅辅佐楚庄王成就了“春秋五霸”的伟业，同时也是一位极其卓越的政治家、军事家和水利专家。
以下是孙叔敖生平的详细讲解：

1. 少年隐居与“埋蛇”传说

• 出身与变故： 孙叔敖本名蒍敖，芈姓，蒍氏，字孙叔。他原本出身于楚国贵族世家，但幼年时父亲蒍贾在朝廷内斗中被杀，导致家道中落。他随母亲隐居于期思邑（今河南淮滨一带），过着清贫的耕读生活。
• 斩蛇埋蛇： 少年时，他在路上看到一条“两头蛇”。当时楚国风俗认为，看到两头蛇的人很快就会死。孙叔敖为了不让别人再看到这条蛇而丧命，便把蛇打死并埋入土中。回家后他哭着跟母亲诀别，母亲安慰他：“你存有善念，为他人着想，上天一定会善待你。”这个故事广为流传，体现了他自幼便具有舍己为人的仁德之心。

2. 拜相治楚：三年而楚国霸

公元前601年左右，孙叔敖因博学多才、名声在外，被楚庄王重用，拜为令尹（宰相）。
• 施教导民： 他主张“宽刑缓政”，用道德教化百姓，不轻易动用严刑峻法。在他的治理下，楚国社会风气良好，官吏廉洁，盗贼绝迹。
• 发展经济： 孙叔敖非常重视农业和商品流通。他倡导百姓利用秋冬农闲时上山砍伐竹木，春夏多水时通过河道运出贩卖，极大地活跃了物资流通，增加了百姓收入。
• 巧妙理政（史记记载的小事）：
	• 恢复货币： 楚庄王曾嫌货币太轻而下令改铸大钱，结果导致市场混乱、商人罢市。孙叔敖发现后，立刻劝说楚庄王恢复旧币，平息了市场风波。
	• 智改高车： 楚王认为百姓坐的矮车不便驾马，想下令强制加高车身。孙叔敖劝阻说：“政令频繁百姓会无所适从。”于是他建议加高街坊和城门的门槛。百姓为了坐车通过时方便，便自发地把车子底盘改高了。

3. 了不起的水利专家

毛泽东曾称赞孙叔敖是“一个了不起的水利专家”。他在治水和灌溉方面的成就影响了中国两千多年：
• 期思雩娄灌区： 他出任令尹前就在家乡主持兴修了水利，建成了中国最早的大型渠系水利工程。
• 芍陂（安丰塘）： 公元前597年，他在今安徽寿县一带主持修建了我国历史上最早的蓄水灌溉工程——芍陂（què bēi）。它将淮河水蓄入陂塘中，旱时灌溉，涝时蓄洪，使江淮一带成为旱涝保收的楚国粮仓。该工程历经2600多年，至今仍在发挥灌溉效益。

4. 军事成就：辅助邲之战

除了治国，孙叔敖在军事上也颇有建树。他整顿楚国军队，制定了严密的军法和纪律。公元前597年，在楚国与北方霸主晋国的邲之战中，孙叔敖辅佐楚庄王果断出击、出奇制胜，大败晋军。此役之后，楚庄王正式在中原饮马黄河，确立了“春秋五霸”的霸主地位。

5. 廉洁离世与智留寝丘

• 两袖清风： 孙叔敖一生虽然贵为宰相，但他极其节俭，家无余财。公元前593年，因长年积劳成疾，孙叔敖病逝，年仅38岁。他死的时候，家里甚至穷得连买棺木的钱都没有。
• 嘱子孙索贫地： 孙叔敖临终前深知“功高震主，富贵难久”的道理，对儿子孙安交代：“我死后，大王一定会封赏你。你千万不要接受肥沃的土地，只要索取‘寝丘’（今河南固始一带）就可以了。那里土地贫瘠，名声不好，别人不会去抢，我们家族才能世代守住它。”
• 优孟衣冠： 孙叔敖死后，儿子果然穷困到只能靠砍柴为生。楚国的宫廷艺人优孟非常同情他，便穿戴上孙叔敖的衣服和帽子，模仿孙叔敖的言谈举止去见楚庄王。楚庄王大为感动，想起了孙叔敖的功勋，于是召来孙叔敖的儿子，按照孙叔敖的遗愿，将贫瘠的寝丘封给了他。正因如此，孙叔敖的子孙在动荡的春秋战国时期得以避开政治风波，得以保全绵延。

总结

孙叔敖是中国历史上清官与能臣的完美结合体。他身居高位而自奉俭约，治国以爱民为本，既有开疆拓土、修筑百里水利的宏图大略，又有洞察人性的政治智慧。他的生平完美诠释了中国古代儒家和法家共同追求的“鞠躬尽瘁、利物济人”的良吏典范。

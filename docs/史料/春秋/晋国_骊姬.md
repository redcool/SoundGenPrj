# 晋国 · 骊姬

## 基本信息
- 身份：骊戎之女，晋献公夫人；奚齐之母
- 关键事件：谮杀太子申生、逐重耳与夷吾、立奚齐；「骊姬之乱」

## 生平年表
1. **入晋（前 671）**：献公伐骊戎，骊戎求和，献骊姬（及妹少姬）。
2. **得宠生子**：生奚齐，献公欲废嫡立庶。
3. **设计去太子**：使申生祭于曲沃，置毒于祭肉，诬其弑父（《左传·僖公四年》）。
4. **申生自缢**：申生不辩、不逃，自缢于新城；重耳、夷吾出奔。
5. **立奚齐**：献公卒，奚齐立；里克杀之，又杀卓子。
6. **结局**：其子死、其谋败，《左传》未详载其终（一说被里克所杀，一说被囚）。

## 主要事迹
- **「骊姬之乱」**：以一女子之谋，倾覆晋国嫡嗣，引发十余年内乱。
- **制度土壤**：其恶的成立，依赖「宠妃可干预立嗣」与「国君可废嫡」的双重条件。
- **后世叙事**：与妲己、褒姒并列为「祸水」典型，但《左传》笔下的她更接近「政治行动者」而非单纯的妖媚符号。

## 史料辨析（重要）
- 《左传》详载其谮杀过程，但**动机叙述有「红颜祸水」框架**，需注意史家立场。
- 《国语·晋语》增饰较多对话，文学性强。
- 本工程处理：**给她自己的声音（女声视角）**，写「一个只能靠儿子活的女子，必然为儿子杀人」的结构性处境，而非单纯骂她。

## 后世评价
- 传统：乱晋的祸首，「骊姬之乱」成为固定成语。
- 现代：史家多强调其行为背后的制度缺陷——不是「妇人干政」四字可以了结。

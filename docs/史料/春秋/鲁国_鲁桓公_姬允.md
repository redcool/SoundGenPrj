# 鲁国 · 鲁桓公 姬允

## 基本信息
- 在位：前 711—前 694（春秋初）
- 身份：鲁国第十五任君，鲁隐公之弟；母宋武公之女
- 关键事件：与公子翚谋弑隐公自立；娶齐女文姜；死于齐国（彭生扼杀）

## 生平年表
1. **隐公摄政期**：隐公为庶长，摄政而不称王；姬允为嫡子，久居储位，心中不安。
2. **谋弑隐公（前 712）**：公子翚求太宰之位不得，转而与姬允合谋；翚弑隐公，姬允即位，是为桓公（《左传·隐公十一年》）。
3. **即位后政治**：与郑、齐修好；前 706 年与齐、郑伐宋；前 702 年「公会齐侯于嬴」，与齐联姻，娶文姜。
4. **文姜之乱**：文姜为齐襄公（姜诸儿）之妹，婚前已有私情；婚后仍与兄往来。
5. **死于齐国（前 694）**：桓公与文姜赴齐，齐襄公命公子彭生扼杀桓公于车中；鲁人请诛彭生，齐杀彭生以谢（《左传·桓公十八年》）。
6. **身后**：子同（庄公）即位；文姜长期留齐不归，鲁国「夫人不返」成为礼制丑闻。

## 主要事迹
- **弑兄得位**：鲁国第一次「弟杀兄而代立」，开鲁国弑君之端。
- **联齐外交**：以婚姻结齐，反被齐所害，暴露「小国托大」的风险。
- **礼崩之始**：《春秋》书「公薨于齐」，不言「弑」，为尊者讳、为亲者讳的写法成为经学公案。

## 史料辨析
- 《左传》明载翚弑隐公、齐杀桓公；《公羊》《穀梁》叙法不同，重点在「讳」。
- 桓公是否直接指使弑兄：《左传》记「羽父请杀桓公」在前、后「反谮隐公」——顺序有异说，本档取「与谋」而非「亲弑」。

## 后世评价
- 传统：以「得位不正、死于非命」为定评，作为「弑君者必不得善终」的早期例证。
- 经学视角：桓公一朝是《春秋》「讳」例最集中的一段（薨、葬、如齐、夫人姜氏）。

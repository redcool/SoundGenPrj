# 鲁国 · 公子翚（羽父）

## 基本信息
- 身份：鲁国公子、大夫，字羽父；鲁隐公、桓公之际的权臣
- 关键事件：请杀桓公求太宰、反谮隐公、弑隐公（前 712）

## 生平年表
1. **隐公朝用事**：为鲁国宗室重臣，掌兵。
2. **求太宰（前 712）**：见隐公，请「杀桓公以求太宰」；隐公不许（《左传·隐公十一年》）。
3. **反谮**：惧事泄，转而向桓公进谮，言「隐公欲去桓公」。
4. **弑隐公**：与桓公合谋，弑隐公于氏（一说寪氏）；立桓公。
5. **结局**：《左传》未明确记载其死；后世注家多认为其后为桓公所杀或失势（无确证）。

## 主要事迹
- **首开鲁国弑君**：以一己之私（求官不得）掀翻君位。
- **「求官—被拒—反噬」三段式**：成为后世权臣作乱的经典模板。
- **史笔的焦点**：《春秋》书「翚帅师」，不书其弑，被认为「罪在君不在翚」的讳例之一。

## 史料辨析
- 翚的最终下场史载不明，后世戏曲与演义中的「伏诛」属演绎。
- 「羽父」为字，其名「翚」（huī）——**别字版易为「辉」**。

## 后世评价
- 传统：鲁国弑君第一人，「求官不成便杀人」的典型。
- 政治学视角：其行为暴露春秋初年「宗室—权臣—国君」三角的脆弱。

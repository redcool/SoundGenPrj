季隗（jì wěi）是春秋时期著名的历史人物，她是晋文公（重耳）流亡时期的第一任妻子。她最广为人知的是与重耳之间关于“二十五年之约”的深情典故，这一故事被记载在《左传》和《史记》中。
关于季隗的生平、背景以及她与晋文公的故事，可以从以下几个方面来了解：

1. 身份背景：异族部落的贵女

• 出身： 季隗本是白狄（北方游牧民族）攻打赤狄部落“廧咎如”时俘获的战俘，但她实际上是该部落首领的女儿（公主）。
• 名字含义： “季”代表排行在后（她是妹妹）；“隗”是她的姓氏。
• 命运交织： 当时，晋国公子重耳因“骊姬之乱”被迫逃亡到母亲的娘家狄国。狄国将俘获的一对绝色姐妹花送给重耳，重耳将姐姐叔隗嫁给了随行的重臣赵衰（生下后来晋国的执政赵盾），自己则迎娶了妹妹季隗。

2. 患难夫妻与流亡岁月

季隗嫁给重耳时，重耳已经43岁，而季隗还很年轻。两人在狄国共同生活了12年，感情非常深厚，季隗还为重耳生下了两个儿子：伯鯈（tiáo）和叔刘。在重耳颠沛流离的前期生涯中，季隗的陪伴和狄国的庇护是他最重要的精神和物质支柱。

3. 千古传诵的“二十五年之约”

晋惠公即位后，视重耳为眼中钉，派刺客到狄国暗杀重耳。重耳被迫仓皇决定离开狄国，继续前往其他诸侯国流亡。
在临行离别时，重耳对季隗说了一段既无奈又有些残酷的话：
“待我二十五年，不来而后嫁。”
（等我二十五年，如果我二十五年后还没回来，你再改嫁吧。）
当时季隗大约25岁，再等25年就是50岁了。面对丈夫给出的这个几乎遥不可及的期限，季隗展现了高度的幽默、隐忍与深情，她笑着回答：
“我二十五年矣，又如是而嫁，则就木焉。请待子。”
（我已经二十五岁了，再等二十五年改嫁，那就直接进棺材了（行将就木）。您放心去吧，我会在这里抚养孩子，一直等您。）
这段话不仅化解了离别时的悲伤和尴尬，更是向重耳表达了终身不嫁、誓死坚守的决心，让重耳能够毫无后顾之忧地去开创自己的复国大业。

4. 结局：苦尽甘来，终成夫人

重耳离开后，季隗带着孩子在狄国坚守了多年的孤独岁月。
19年的流亡生涯结束后，62岁的重耳终于在秦国的支持下回到晋国当上了国君，即晋文公（春秋五霸之一）。
重耳即位后，狄人非常识时务地将季隗风风光光地送回了晋国。虽然此时晋文公为了政治联姻又娶了齐国的齐姜、秦国的怀嬴（文嬴）等多位夫人，但季隗在晋文公的心中始终占有重要地位，在后宫妻妾中位列第三，被尊为“三妃”或文公夫人。

💡 历史评价

季隗在中国古代历史上被视为贤内助和忠贞爱情的典范。在现代的一些衍生文化（如历史策略游戏《英傑大戦》等）中，也经常能看到以她为原型的角色，其技能往往也围绕着“久远的再会”这一极具浪漫色彩的典故来设计。

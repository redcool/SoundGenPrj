# 齐国 · 齐襄公 姜诸儿

## 基本信息
- 在位：前 697—前 686
- 身份：齐僖公之子，齐桓公（姜小白）之兄
- 关键事件：与妹文姜私通；杀鲁桓公；「及瓜而代」失信戍卒，被弑

## 生平年表
1. **即位**：僖公卒，诸儿即位；与异母妹文姜早有私情（文姜后嫁鲁桓公）。
2. **杀鲁桓公（前 694）**：桓公携文姜来齐，襄公命彭生扼杀桓公于车中；鲁人请诛彭生，齐杀彭生以塞责（《左传·桓公十八年》）。
3. **内政失序**：诛杀无常、言行无信；与大夫连称、管至父结怨。
4. **「瓜时而往，及瓜而代」**：使连称、管至父戍葵丘，约瓜熟而代；期至不代，二人怀怨（《左传·庄公八年》）。
5. **被弑（前 686）**：连称、管至父与公孙无知合谋，乘襄公田猎坠车伤足，弑之于贝丘。
6. **身后**：公孙无知自立，旋被杀；齐国内乱，小白（桓公）自莒先入即位。

## 主要事迹
- **乱伦与杀婿**：与妹私通并杀鲁桓公，是春秋前期最著名的宫闱丑闻。
- **失信戍卒**：一句「及瓜而代」的失约，直接导致被弑。
- **齐国乱局的前奏**：其死引发君位真空，反而成就齐桓公与管仲的改革。

## 史料辨析
- 《左传》对私通与杀桓公记载明确；《史记·齐太公世家》叙之更详。
- 「及瓜而代」的细节（谁请代、何时当代）各本略有出入。

## 后世评价
- 传统：淫乱失信的昏君，与鲁桓公之死互为因果。
- 政治史视角：齐国的霸权恰恰建立在他造成的乱局之后——「昏君—乱局—改革」的链条。

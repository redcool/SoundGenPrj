秦穆公（姓嬴，名任好，前659年—前621年在位），是春秋时期秦国的第九代国君，也是被《史记》等古籍列为“春秋五霸”之一的重要人物。他为后来秦国走向统一中国打下了坚实的基础。
以下是嬴任好一生的主要经历与核心事迹：

一、 即位与广纳贤才

• 继承王位：嬴任好是秦德公的幼子、秦宣公和秦成公之弟。前659年，兄长秦成公去世后，他接替成为秦国君主。
• 五羖大夫（百里奚）：他极为重视人才，曾用五张黑公羊皮从楚国赎回流落的贤臣百里奚（被称为“五羖大夫”），并委以国政。
• 重用群臣：他还招揽并重用蹇叔、由余、孟明视、西乞术和白乙丙等来自各国的能臣良将，形成了强大的人才智囊团。

二、 与晋国的恩怨纠葛

• 秦晋之好与扶立晋文公：嬴任好娶晋国公主为夫人，早期与晋国关系密切。晋国内乱时，他曾资助流亡在外的公子重耳回国即位，即后来的晋文公，史称“秦晋之好”。
• 韩原之战：在更早期，他曾与晋国交战并在韩原之战中击败晋军，俘虏了晋惠公。
• 崤之战与东进受挫：晋文公去世后，秦晋联盟破裂。前627年，秦穆公派兵偷袭郑国，在归途中的崤之战中遭到晋军伏击，秦军全军覆没，三位主将孟明视、西乞术、白乙丙被俘。此后秦国向东进军中原的道路被晋国死死扼住。

三、 称霸西戎

• 经略西方：东进受阻后，嬴任好改变战略，将重心转向西方。
• 灭国拓地：他采纳谋士由余的计策，出兵讨伐西戎，先后攻灭了12个（一说20个）西戎部落国家。
• 周王封伯：秦国向西开拓土地上千里，使秦穆公被周襄王册封为“西方诸侯之伯”，正式确立了他在西部的霸主地位。

四、 晚年与身后事

• 逝世与人殉：嬴任好于前621年去世。
• 悲歌《黄鸟》：他死时有177人殉葬（其中包括深受爱戴的良臣子车氏三良：奄息、仲行、针虎），这在当时引发了秦国人民极大的悲痛与惋惜，后人为此创作了《诗经·秦风·黄鸟》一诗。

# 鲁国 · 庆父（仲庆父）

## 基本信息
- 身份：鲁桓公之子、鲁庄公之弟；鲁国上卿，「三桓」之孟孙氏始祖
- 关键事件：弑子般、弑闵公；「庆父不死，鲁难未已」

## 生平年表
1. **庄公朝专权**：庄公在位时，庆父与弟叔牙、季友并掌国政。
2. **庄公之死（前 662）**：庄公卒，子般立；庆父与庄公夫人哀姜私通。
3. **弑子般**：子般即位两月，庆父使人杀之，立闵公（时年八岁）（《左传·庄公三十二年》）。
4. **弑闵公（前 660）**：庆父又弑闵公，欲自立；国人不服，出奔莒。
5. **齐人问责**：齐桓公使仲孙湫来省难，归曰「不去庆父，鲁难未已」（《左传·闵公元年》）。
6. **自缢**：季友以僖公入，赂莒人索庆父；庆父使公子鱼请赦不许，自缢于密（《左传·闵公二年》）。

## 主要事迹
- **连弑二君**：两月弑子般、两年弑闵公，鲁国大乱。
- **成语原型**：「庆父不死，鲁难未已」——后世用以形容祸根不除、国难不止。
- **与哀姜同谋**：其乱兼有私情与夺权双重动因。

## 史料辨析
- 《左传》叙事完整，可信度较高；《公羊》重在「诛庆父」的义理。
- 其「欲自立」的动机，《左传》记为「欲立」而不明言称公，学界有讨论。

## 后世评价
- 传统：宗室乱国的典型，「弑君专业户」。
- 现代：其乱暴露鲁国「公室弱、三桓强」的结构问题——他死后三桓反而坐大。

晋文公（生卒年：前697年－前628年），姬姓，名重耳，是春秋时期晋国的第二十二任国君，也是著名的“春秋五霸”之一（通常与齐桓公并称为“齐桓晋文”）。
重耳的一生极具传奇色彩，他前半生颠沛流离，流亡列国19年，历经磨难；后半生大器晚成，拜相称霸，仅在位9年便确立了晋国的百年霸业。

一、 核心经历：十九年流亡之路 🌍

重耳的流亡是因为晋国内乱（“骊姬之乱”） [3]。他的父亲晋献公宠幸骊姬，骊姬为了让自己的儿子奚齐继位，设计陷害太子申生（迫使其自杀），重耳和弟弟夷吾也不得不逃亡海外。
重耳的流亡路线长达数千公里，途经多个诸侯国，期间人情冷暖、险象环生：
• 狄国（母家）：重耳逃到母亲的故国，在这里安稳地居住了12年，并娶妻生子。
• 卫国、齐国：离开狄国后开始列国周游。在卫国受到冷遇；但在齐国受到了齐桓公的盛情款待，齐桓公还将宗室女嫁给了他。重耳一度想在齐国终老，但随从们认为他应当回国复国，设计将他灌醉带走。
• 曹国、宋国、郑国：在曹国，曹共公无礼地偷看重耳洗澡；在宋国，宋襄公礼待他；在郑国，郑文公不听劝谏，拒绝接待他。
• 楚国：楚成王以诸侯之礼接待重耳。在这里诞生了著名的成语“退避三舍”——楚王问重耳未来若执掌晋国如何报答楚国，重耳承诺若两军交战，晋军将主动退让九十里（一舍为三十里）。
• 秦国：最终，秦穆公决定扶持重耳。他不仅把女儿（怀嬴）嫁给重耳，还派兵护送重耳回国。前636年，62岁的重耳在秦军护送下即位，是为晋文公。

二、 治国成就：文治武功与城濮之战 ⚔️

晋文公即位时已是花甲之年，但他励精图治，迅速将晋国带向巅峰：
1. 内政改革（文治）：他整顿吏治，启用随他流亡的功臣（如赵衰、狐偃、贾佗等）；发展经济，减轻赋税，通商宽刑；建立“三军”体制，扩充军事力量。
2. 勤王定乱：周襄王被弟弟王子带篡位赶出洛邑。晋文公抓住机会，出兵护送周襄王复位，赢得了“尊王”的政治大义。
3. 城濮之战（武功）：前632年，晋国与南方的超级大国楚国爆发决战。晋文公兑现了当年的承诺，下令军队“退避三舍”，诱敌深入。最终晋军大败楚军，轰动天下。
4. 践土之盟（称霸）：城濮之战后，晋文公在践土大会诸侯，周襄王正式册封晋文公为“侯伯”（诸侯之长），标志着晋文公正式成为春秋霸主。

三、 相关成语与文化典故 📚

重耳的故事为后世留下了大量的文化遗产和成语：
• 退避三舍：比喻对人让步或主动回避，挑起事端者理亏。源于重耳对楚成王的承诺，后在城濮之战中兑现。
• 寒食节与清明节的起源（介子推）：
	• 重耳流亡期间，曾一度断粮。随臣介子推“割股奉君”，割下自己大腿上的肉煮汤给重耳充饥。
	• 重耳当政后大赏功臣，唯独忘了介子推。介子推不愿邀功，背着母亲隐居绵山。
	• 晋文公亲自去请，为了逼他下山，下令放火烧山，结果误将介子推母子烧死。
	• 晋文公悲痛万分，为了纪念介子推，下令将这一天定为寒食节（不生火做饭，吃冷食），这便是清明节吃青团、寒食习俗的前身。
• 贪天之功：介子推认为重耳复国是“天意”，那些贪恋功勋的臣子是“贪天之功以为己功”，这也是一个常用成语。

四、 历史评价 👑

晋文公重耳是开创晋国百年霸业的奠基人。历史学家对他的评价极高：
• 大器晚成的典范：六十岁前颠沛流离、受尽屈辱，六十岁后一飞冲天、名动天下。
• 知人善任：“晋文公之霸，文臣武将之功也。”他流亡时有一班生死相随的贤臣，称霸后能人尽其才。
• 齐桓晋文的异同：孔子曾评价：“齐桓公九合诸侯，不以兵车，管仲之力也”；而评价晋文公则称“晋文公谲而不正，齐桓公正而不谲”（意指晋文公更擅长权谋政治）。但不可否认，两人都为春秋时期的中原文明抵御外土、维护秩序做出了巨大贡献。

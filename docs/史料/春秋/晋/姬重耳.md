# 姬重耳（晋文公）

## 基本信息
- 时代：春秋前期（前 697 前？—前 628 年在位：前 636—前 628）
- 身份：晋献公之子、晋国第二十二任君、春秋五霸之二（史称「春秋第二霸」）
- 母：狐姬（戎族）；从亡贤士：狐偃、赵衰、先轸、贾佗、魏犨等
- 关键事件：骊姬之乱、流亡十九年、城濮之战、践土之盟

## 生平年表
1. **骊姬之乱（前 656 前后）**：献公宠骊姬，谮杀太子申生；重耳奔蒲，夷吾奔屈（《左传·僖公四年》《史记·晋世家》）。
2. **流亡十九年（前 655—前 636）**：历狄（居十二年）、卫（卫文公不礼）、齐（齐桓公妻以女，贪安，狐偃醉而遣之）、曹（曹共公窥浴）、宋（宋襄公赠马）、郑（郑文公不礼）、楚（楚成王待以诸侯之礼，问「何以报我」，答「退避三舍」）、秦（秦穆公纳之）。
3. **归国即位（前 636）**：秦穆公发兵送重耳入晋，杀怀公，即位为文公；时年约六十余。
4. **整顿内政**：作三军（中军、上军、下军），举贤任能，「昭旧族，爱亲戚，明贤良，尊贵宠，赏功劳」（《国语·晋语四》）；教民以礼、以信。
5. **勤王（前 635）**：周襄王弟王子带作乱，文公纳王于王城，杀王子带，得「南阳」之地（《左传·僖公二十五年》）——尊王大旗到手。
6. **城濮之战（前 632）**：楚围宋，晋救宋；文公「退避三舍」（九十里）以报楚成王旧恩，晋军退至城濮；四月，晋大败楚师（子玉）。
7. **践土之盟（前 632）**：周襄王策命文公为「侯伯」（霸主），赐大辂之服、彤弓等；晋始称霸（《左传·僖公二十八年》）。
8. **崤之战前后**：前 628 年文公卒；秦晋关系转为长期对抗（崤之战发生于文公死后，先轸主战）。

## 主要事迹
- **退避三舍**：以九十里退军践诺，被后世视为「守信」典范；《左传》载其言「微夫人之力不及此。因人之力而敝之，不仁；失其所与，不知；以乱易整，不武」。
- **作三军、定霸业**：晋国军政合一的制度基础，「一战而霸」。
- **举贤不避亲仇**：用狐偃（舅）、赵衰、先轸等，形成晋国世卿的源头（也为后来的六卿专权埋因）。
- **赏从亡者而不及介子推**：介子推隐绵山（《左传·僖公二十四年》确有「介之推不言禄」事，割股/寒食为后世传说）。

## 金文/考古佐证
- 春秋晋国青铜器（如晋姜鼎、侯马盟书为晚期）可佐晋国公室与军政形态；城濮、践土具体地望有考古讨论，但史事框架以《左传》为准。

## 传说层辨析
- **割股奉君**：不见于《左传》《史记》，始见于《韩诗外传》等，属传说层。
- **寒食节**：寒食禁火与介子推的关联为后世附会（汉代以后方盛），非春秋当世事实。
- **退避三舍**：属史实（《左传》明载），但「报恩」与「诱敌」的双重动机为后世评说。

## 后世评价
- 《左传》以「谲而不正」评齐桓、晋文（论语·宪问：「晋文公谲而不正，齐桓公正而不谲」）。
- 流亡十九年而成霸业，成为「忍与信」的政治范本；司马迁称「晋文公，古所谓明君也」（《史记·晋世家》赞）。
- 其「赏从亡」的处置，也留下「有功不赏则怨」的政治教训（介子推事）。

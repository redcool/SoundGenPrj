介子推（?－公元前636年），又名介之推，是中国春秋时期晋国（今山西省一带）的著名贤臣。他是中国传统节日寒食节与清明节起源的核心历史人物，以“割股奉君”的极致忠诚和“功成身退”的高洁志向而闻名于世。
以下为您详细讲解介子推的生平事迹：

1. 割股奉君：流亡中的极致忠诚

在春秋时期，晋国发生内乱（骊姬之乱），公子重耳（后来的晋文公）被迫流亡国外长达19年。在这段极其艰苦的流亡岁月中，介子推是少数几个始终追随重耳、不离不弃的忠臣之一。
• 关键事件：有一次，重耳一行人在卫国的荒野中迷路，粮草断绝，重耳饿得头晕眼花，濒临绝境。
• 割股熬汤：在众人束手无策时，介子推悄悄走到僻静处，从自己的大腿上割下一块肉，与采摘的野菜一同熬成汤呈给重耳。重耳吃完后恢复了体力，得知真相后感动得流下眼泪，许诺日后执掌国政必定重重报答他。

2. 功成身退：不言禄的高洁志向

历经19年的流亡，重耳最终在秦国的帮助下返回晋国，登基成为一代霸主——晋文公。
• 论功行赏与遗忘：晋文公即位后，大张旗鼓地赏赐当年陪他流亡的功臣。然而，在论功行赏的过程中，晋文公一时间竟疏忽遗漏了介子推。
• 不言禄：面对名利，介子推并没有像其他人那样主动去争赏。他认为重耳能够回国做君主，是“天道”必然的结果，那些贪天之功以为己力的人是可耻的（即成语“贪天之功”的由来）。
• 隐居绵山：介子推鄙视那些争权夺利、争功讨赏的官场丑态。为了保持内心的清白与高洁，他背着年迈的母亲，悄悄离开了朝廷，隐居到家乡的绵山（今山西介休市境内）之中，过起了隐士生活。

3. 焚树悲剧：寒食节的起源

后来，有人作诗提醒晋文公，晋文公这才猛然想起介子推的救命之恩，心中大为愧疚。他亲自率领满朝文武前往绵山寻找介子推，想要接他下山封官赐爵。
• 绵山搜寻：然而绵山山高路险，树木茂密，介子推执意隐居，任凭晋文公如何呼唤，他都不肯现身。
• 出计放火：这时，有大臣献计，提议从三面放火烧山，留下一面，认为火势一旦蔓延，介子推为了尽孝和自保，一定会背着母亲走下山来。
• 悲剧结果：大火烧了三天三夜，直到火熄灭后，人们才发现介子推和他的母亲抱着一棵老柳树，已经被活活烧死。
• 留下血书：传说在死去的柳树树洞里，晋文公发现了介子推留下的一封血书，上面写着：“割肉奉君尽丹心，但愿主公常清明。柳下作鬼终不见，强似伴君作谏臣……”

4. 后世纪念与文化传承

介子推的惨死让晋文公悲痛欲绝。为了纪念这位忠臣，晋文公下令采取了一系列措施，这些措施演变成了后来的传统文化：
• 寒食节的诞生：晋文公下令，将介子推遇难的这一天定为“寒食节”。在这一天，全国禁止生火做饭，只能吃冷食，以此寄托对介子推的哀思。
• 清明节的延续：第二年寒食节的次日，晋文公素服登山祭奠，发现那棵死去的柳树居然复活了。他赐名该树为“清明柳”，并把这一天定为“清明节”。随着历史演变，寒食节的习俗逐渐融入了清明节中。
• 地名留存：介子推隐居和遇难的绵山所在地区，被后人命名为“介休”（意为介子推长眠、休息的地方），这一地名一直沿用至今。

总结

介子推在中国历史上，是“忠、孝、洁、义”的完美化身。他割股奉君体现了“忠”，背母隐居体现了“孝”，不图富贵、功成身退体现了“洁”，用生命坚守志向体现了“义”。他的一生虽然以悲剧收场，但他所代表的精神却通过清明节，传承了数千年之久。

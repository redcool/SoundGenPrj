狐偃（约前697年—前629年），姬姓，狐氏，字子犯，又称舅犯、咎犯，是春秋时期晋国著名的政治家与军事家。 他不仅是春秋五霸之一晋文公（重耳）的亲舅舅，更是重耳流亡十九年的核心骨干与复国称霸的首席谋士。后世常将他视为忠义与远见的楷模。
以下为您带来狐偃的生平全景中文讲解：

1. 家族背景：戎狄血统与入晋外戚

狐偃出身于大戎狐氏（戎狄部落）。他的父亲狐突博学多才，在晋武公时期出仕晋国。晋献公娶了狐突的女儿“大戎狐姬”生下重耳。作为嫁妆和家族力量的一部分，狐突带着儿子狐毛、狐偃移居晋国。
狐突安排小儿子狐偃去辅佐和教导公子重耳。可以说，狐偃不仅是重耳的舅舅、老师，在重耳缺乏父爱的成长过程中，更扮演了如同父亲般的长辈角色。

2. 流亡十九年：不离不弃的核心大脑

公元前656年，晋国爆发“骊姬之乱”，太子申生被迫自杀。狐偃敏锐地察觉到危险，力劝重耳流亡外国，并为他规划了路线。重耳自此开启了长达19年、辗转8国的流亡生涯。在此期间，狐偃作为流亡团队的“大脑”，留下了数个影响历史走向的经典抉择：
• 五鹿献土： 团队流经卫国五鹿时，饥饿的重耳向当地农民讨饭，农民却开玩笑地给了他一块泥土。重耳大怒准备鞭笞农民，狐偃及时拦住并贺喜道：“土，意味着土地。这是上天赐予您晋国土地的吉兆啊！” 重耳转怒为喜，磕头收下泥土。这极大地稳定了流亡团队的军心。
• 醉招出齐： 在齐国时，重耳沉溺于齐桓公给予的优厚待遇和温柔乡，不愿再复国。狐偃与重耳的妻子齐姜密谋，将重耳灌醉后强行抬上车抬出齐国，逼迫他继续前行。重耳醒后大怒，甚至一度想提刀杀了狐偃，但狐偃坦然面对，促使重耳最终清醒并重新确立大志。
• 退避三舍的底气： 在楚国时，楚成王问重耳未来如何报答他，重耳许下“退避三舍”的诺言。楚国大将子玉认为重耳有野心，建议楚王杀掉他或扣留狐偃。正是在狐偃等人的智谋护航下，团队才得以在秦国的帮助下安全回国。

3. 复国与称霸：首席谋士与治国功臣

公元前636年，在秦穆公的护送以及赵衰、狐偃等人的辅佐下，重耳正式回国即位，是为晋文公。
• 推让高位： 晋国建立三军时，晋文公原本想任命狐偃为上军将。但狐偃坚持长幼有序，主动将主将之位让给兄长狐毛，自己甘居上军佐（副将），彰显了极高的政治情商。
• 富国强兵： 狐偃向晋文公提出了“明贤良、赏功劳、定秩序”的治国方略，主张起用德才兼备的人才，教导百姓知书达理、讲求信用。在狐偃的辅佐下，晋国仅用5年时间便实现了“政平民阜，财用不匮”的盛世景象。
• 城濮之战与践土之盟： 公元前632年，晋楚爆发城濮之战。狐偃作为上军佐随军出征，并主张兑现当年“退避三舍”的诺言，在道德上占据制高点，最终大败楚军。随后，他代表晋国主持诸侯会盟（践土之盟），尊崇周天子，正式助力晋文公登上了春秋五霸的宝座。

4. 晚年与逝世

公元前629年（晋文公八年），狐偃去世。他的儿子狐射姑继承了他的爵位。
历史回响：子犯龢(he)钟
狐偃流传后世最著名的文物是现藏于台北故宫博物院的“子犯龢钟”（又称子犯编钟）。这套青铜器上刻有长篇铭文，详细记录了狐偃辅佐晋文公流亡、回国、并在城濮之战中立下赫赫战功的历史，是印证他一生传奇生平的极其珍贵的国家级文物。

# 齐国 · 崔杼（崔武子）

## 基本信息
- 身份：齐国正卿、崔氏宗主；历惠公、顷公、灵公、庄公四朝
- 关键事件：弑齐庄公（前 548）；太史兄弟三人相继直书「崔杼弑其君」

## 生平年表
1. **拥立庄公（前 554）**：灵公卒，崔杼迎立公子光（庄公），以功专政。
2. **棠姜之祸**：崔杼娶棠公寡妻棠姜；庄公与之私通，且以崔杼之冠赐人，崔杼怀恨（《左传·襄公二十五年》）。
3. **弑庄公（前 548）**：崔杼称病不朝，庄公往问疾，入崔宅；甲士起，庄公登台请和不得，被杀。
4. **太史三兄弟**：太史书「崔杼弑其君」，崔杼杀之；其弟继书，又杀；第三弟仍书，崔杼乃舍之（《左传·襄公二十五年》）。
5. **南史氏**：南史氏闻太史尽死，执简以往；闻已书，乃还。
6. **灭族与自尽（前 546）**：庆封与崔氏内讧，庆封杀崔杼之子崔成、崔强，尽灭崔氏；崔杼与棠姜自缢。

## 主要事迹
- **弑君**：因私怨弑庄公，开齐国「卿族弑君」之例。
- **史祸**：连杀两位太史，仍不能改一字——「崔杼弑其君」成为史官气节的永恒象征。
- **身死族灭**：其结局证明「以力夺权者，终以力亡」。

## 史料辨析
- 《左传》记载最详（含棠姜、太史、南史氏）；《史记·齐太公世家》较简。
- 太史兄弟的具体人数（二弟或三弟）各本有异，本档取「兄弟相继」的通说。

## 后世评价
- 传统：弑君之贼，同时是「史笔不可夺」的反面衬托。
- 文化意义：「在齐太史简」与「在晋董狐笔」并称（文天祥《正气歌》），成为中国史学精神的图腾。

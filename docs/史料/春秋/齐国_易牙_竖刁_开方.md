# 齐国 · 易牙（附竖刁、开方）

## 基本信息
- 时代：齐桓公晚年（前 7 世纪中）
- 身份：易牙（雍人，善调味，名巫）、竖刁（自宫入侍的内侍）、开方（卫国公子，弃亲事君）——合称「三奸」
- 关键事件：管仲临终谏「非人情，不可近」；桓公不听，三人专权，桓公饿死宫中，尸虫出户

## 生平年表
1. **得宠**：易牙以善烹调近桓公；竖刁自宫为内侍；开方弃卫国公子之位，十五年不归家事桓公。
2. **烹子献糜**：桓公言「未尝食人肉之美」，易牙蒸其子以献（《管子·小称》《史记·齐太公世家》所载）。
3. **管仲之谏（前 645）**：管仲病，桓公问谁可为相；管仲曰「杀子以适君，非人情，不可」「自宫以适君，非人情，难亲」「弃亲以适君，非人情」（《史记·齐太公世家》）。
4. **复召与专权**：桓公逐三人，后又召回；三人专擅朝政，与五公子争立。
5. **桓公饿死（前 643）**：桓公病重，三人筑高墙、塞宫门，不给饮食；桓公饿死，尸停六十七日，尸虫出于户。
6. **结局**：易牙、竖刁拥立无诡，后被宋襄公联军所败；易牙逃、竖刁被杀（细节各本有异）。

## 主要事迹
- **「非人情」三人组**：中国政治伦理中最早以「反常之举」为奸的判据。
- **亲佞远贤的代价**：一代霸主死于饿殍，成为「晚年失察」的经典案例。
- **厨神与佞臣的双面**：易牙在后世被奉为厨行祖师，与其佞臣身份形成强烈反讽。

## 史料辨析
- 「烹子」细节见《管子》《史记》，先秦诸子多引用，但具体真伪难考（一说为寓言化叙述）。
- 三人结局各本不一：竖刁之死、易牙之逃均有异说。

## 后世评价
- 传统：佞幸的标准像，「杀子、自宫、弃亲」三事成为衡量「忠」之真伪的试金石。
- 管仲之谏被历代引为「识人」范本。

公孙侨（约公元前582年—公元前522年），字子产，是春秋时期郑国的著名政治家、思想家和外交家。他被誉为“春秋第一人”，也是中国历史上著名的法治先驱和贤相，连孔子都对他推崇备备，称他为“古之遗爱”。
以下是子产（公孙侨）一生的核心经历与主要成就：

1. 出身贵族与临危受命

• 显赫出身：子产是郑穆公的孙子，公子发（字子国）的儿子，属于郑国执政的“七穆”贵族阶层。
• 初露锋芒：公元前563年，郑国发生内乱，子产的父亲子国在叛乱中被杀。面对危机，年轻的子产迅速组织家兵，平定叛乱，展现出卓越的军事和政治果断力。
• 执掌国政：公元前543年，子产开始正式出任郑国正卿（宰相），开始了他长达二十多年的执政生涯。当时的郑国夹在晋国、楚国两个超级大国之间，形势极其危急。

2. 核心成就：对内改革与法治

子产在郑国推行了全面而深刻的内政改革，使弱小的郑国一度实现了富国强兵：
• 铸刑书（中国首次公布成文法）：公元前536年，子产将法律条文铸在鼎上，向全国公开。这是中国历史上第一次正式公布成文法。此举打破了贵族对法律解释权的垄断，限制了贵族的特权，标志着中国从“礼治”向“法治”迈出了历史性的一步（虽然当时遭到了晋国叔向等保守派的强烈反对）。
• 作丘赋（军事与经济改革）：他重新丈量土地，根据土地肥瘠和人口重新制定税赋制度（即“作丘赋”），不仅增加了国家的财政和军事收入，也打破了传统井田制的束缚。
• 不毁乡校（尊重舆论）：当时郑国人常聚在“乡校”（地方学校）议论朝政，有人建议拆毁乡校。子产坚决拒绝，并说：“夫人朝夕退而游焉，以议执政之善否。其所善者，吾则行之；其所恶者，吾则改之。从善如流，何为毁之？”这成为了中国古代尊重民意、言论自由的千古美谈。

3. 外交智慧：在大国夹缝中求生存

郑国地理位置险要，是晋楚争霸的必经之地。子产凭借高超的外交手腕，维护了郑国的尊严与独立：
• 理直气壮的“民间外交”：在面对强大的晋国时，子产毫不妥协。晋国曾因盟主地位对郑国百般刁难、索要巨额贡品。子产数次亲赴晋国，据理力争，直言大国如果不讲道义、一味贪婪只会失去诸侯的拥护。他成功说服晋国减少了对诸侯的赋税，争取了郑国的利益。
• 维护国家尊严：有一次子产出使晋国，晋平公因傲慢不予接见。子产直接下令拆毁了晋国宾馆的围墙，把车马赶进去。晋国人责问他，子产辞令交锋，指出晋国宫殿奢华，却让外宾住在低矮如奴隶住所、连车马都放不下的地方，万一有盗贼或火灾，谁来负责？晋国听后自知理亏，大夫韩宣子亲自向子产道歉。

4. 逝世与历史评价

• 清廉离世：公元前522年，子产因病逝世。他执政二十多年，家无余财，去世时甚至没有钱办丧事，儿子只能用筐子背土为他修墓。郑国百姓闻讯痛哭失声，史书载“老幼皆哭，三月不执琴瑟”。
• 孔子的评价：孔子听到子产去世的消息后，流着泪说：“古之遗爱也。”（他是古人流传下来的仁爱化身）。孔子赞美他具有君子的四种美德：“其行己也恭，其事上也敬，其养民也惠，其使民也义。”

💡 总结

公孙侨（子产）的一生，是在内忧外患中力挽狂澜的一生。他既有法家的雷厉风行（铸刑书、重赋税），又有儒家的仁爱宽厚（不毁乡校、爱民如子）。他的务实精神和政治智慧，为后世的商鞅变法等法制改革开辟了先河。

管仲（约公元前723年－公元前645年），姬姓，管氏，名夷吾，字仲，是中国春秋时期伟大的政治家、经济家、军事家。他辅佐齐桓公成为“春秋五霸”之首，被誉为“圣人之师”和“华夏第一相”。
他的传奇一生可以概括为以下几个主要阶段：

1. 早年坎坷与“管鲍之交”

管仲早年生活非常贫困，为了谋生做过许多底层工作，甚至当过兵。在此期间，他结识了挚友鲍叔牙。
• 经商分利： 管仲和鲍叔牙一起做生意，因为家里穷，分钱时管仲总是自己多拿。鲍叔牙不仅不生气，反而对别人说：“管仲不是贪财，而是家里实在太穷了。”
• 战场退缩： 管仲当兵打仗时曾三次当逃兵。鲍叔牙再次为他辩护：“他不是胆小，是因为家里有老母亲需要他养老送终。”
• 心意相通： 管仲曾感叹：“生我者父母，知我者鲍子也。” 这就是千古传诵的“管鲍之交”。

2. 辅佐纠公子与射中公子小白

齐国发生内乱时，管仲和鲍叔牙分别辅佐不同的公子：
• 管仲 辅佐 公子纠 逃往鲁国。
• 鲍叔牙 辅佐 公子小白 逃往莒国。
齐襄公被杀后，两位公子展开了争夺王位的生死时速。管仲为了帮公子纠夺位，在半路埋伏公子小白，并一箭射中了小白的带钩。小白假装吐血倒地骗过管仲，随后日夜兼程赶回齐国，成功继位，成为齐桓公。

3. 鲍叔牙力荐与拜相

公子小白登基后，齐国打败了鲁国，并要求鲁国处死公子纠，将管仲押回齐国受刑。齐桓公本想杀了这个差点击中自己的仇人，但鲍叔牙极力劝阻。
• 鲍叔牙对齐桓公说：“如果您只想治理好齐国，有我和高傒就够了；如果您想称霸天下，非用管仲不可！”
• 齐桓公展现了宏大的胸襟，不仅赦免了管仲，还举行了隆重的仪式，拜管仲为相国（尊称其为“仲父”）。

4. 尊王攘夷与大刀阔斧的改革

管仲执政后，对齐国进行了全方位的彻底改革，使齐国迅速强盛起来：
• 经济改革： 提出“仓廪实而知礼节，衣食足而知荣辱”。他开发盐铁之利（国家垄断盐铁），鼓励对外贸易，并铸造货币，让齐国成为当时最富裕的国家。
• 政治与军事： 实行“三星制”和“士农工商”分业定居，将军事编制与行政组织合二为一，做到兵民合一（兵源稳定且训练有素）。
• 外交战略： 提出“尊王攘夷”的口号。表面上尊崇周天子的权威，实际上联合各诸侯国共同抵御北方和南方的少数民族（如山戎、楚国）侵扰。这不仅赢得了中原诸侯的拥戴，也确立了齐国的霸主地位。

5. 九合诸侯，一匡天下

在管仲的辅佐下，齐桓公曾九次大会诸侯（九合诸侯），断绝了各国的混战，稳定了中原局势。连后世的孔子都高度评价管仲：“微管仲，吾其被发左衽矣”（如果没有管仲，我们大概早就被外族统治，变成披头散发、衣服扣子开在左边的野蛮人了）。

6. 晚年与离世

公元前645年，管仲病重。齐桓公到榻前询问后继人选。管仲展现了极高的政治远见，他警告齐桓公：易牙、竖刁、开方这三个人违反人性来迎合君主（易牙杀子给齐桓公做菜，竖刁自宫来侍奉齐桓公，开方背弃自己的祖国和父母），绝对不可信任。
管仲死后，齐桓公起初听从了劝告，但后来还是重新任用了这三人。结果齐桓公晚年被这三人幽禁饿死，齐国也陷入了内乱，霸业走向衰落。
总结：
管仲的一生，是从底层贫民到一代名相的逆袭史。他的成功既得益于鲍叔牙的无私推荐和齐桓公的宽广胸怀，更凭借了他自身超群的政治智慧和改革魄力。他留下的著作《管子》，至今仍是中国古代政治和经济思想的瑰宝。

# 楚国 · 费无极（费无忌）

## 基本信息
- 时代：楚平王时（前 6 世纪末—前 5 世纪初）
- 身份：楚平王之少师、佞臣
- 关键事件：谗太子建、谗伍奢，致楚国内乱、郢都陷落（柏举之战）

## 生平年表
1. **为少师**：平王即位，费无极为太子建之少师，不得宠于太子。
2. **谗太子建（前 527 前后）**：太子建聘秦女，费无极劝平王自娶之（「王自取之」），又谗太子与伍奢有异心，太子建奔宋。
3. **谗伍奢**：平王囚伍奢，召其二子；伍尚就死、伍员（子胥）奔吴（《左传·昭公二十年》）。
4. **构陷郤宛（前 515）**：以谗杀左尹郤宛及其族，国人怨之。
5. **被杀**：楚人（一说令尹子常）杀费无极以谢国人（《左传·昭公二十七年》）。
6. **后果**：伍子胥奔吴，十九年后引吴师破郢（柏举之战，前 506），楚国几亡。

## 主要事迹
- **一言乱国**：其谗言链条从「夺媳」到「杀忠臣」到「逼走伍员」，最终引外兵破都。
- **佞臣的连锁效应**：个人谗言通过制度（王权无制衡）放大为国家级灾难。
- **「费无极」之名**：后世作为「谗佞」的代称（《韩非子》《吕氏春秋》多引）。

## 史料辨析
- 《左传》记载连贯，可信度较高；《史记·楚世家》与之相合。
- 「夺媳」情节的细节（谁提议、如何劝）各本略有出入。
- 其被杀的执行者，有「子常」与「国人」两说。

## 后世评价
- 传统：谗臣亡国的典型，与晋之屠岸贾、齐之易牙同类。
- 历史链条价值：楚国由盛转衰的关键一环，其谗言直接造成「伍子胥复仇」这条主线。

熊侣，也就是历史上有名的楚庄王，是春秋时期楚国的国君。他是先秦时期最具传奇色彩的帝王之一，名列“春秋五霸”。他的生平经历是一部典型的从“职场菜鸟”韬光养晦，最终厚积薄发、一统中原霸业的励志史。
他的主要经历可以分为以下四个标志性阶段：

1. 内忧外患：危机四伏的少年即位

公元前613年，年轻的熊侣（不满20岁）继承了父亲楚穆王的王位。他刚一上台，面对的却是一块人人争夺的“烂摊子”：
• 内乱爆发： 掌权的老师和重臣（公子燮与斗克）突然发动叛乱，甚至一度将他劫持绑架，虽然叛乱最终被平定，但国内政局风雨飘摇。
• 外敌环伺： 楚国北边的宿敌晋国正拉拢中原诸侯结盟，准备打压楚国；周边的一些小国和部落（如群蛮、百濮）也趁火打劫，频繁侵扰。

2. 韬光养晦：三年“一鸣惊人”

面对朝中错综复杂的权臣势力，年轻的熊侣没有盲目硬拼，而是选择了装傻与观察。
• 昏君面具： 史书记载，他即位后的前三年，整天不理朝政，日夜沉湎于酒色，左拥右抱，甚至下达了极其荒唐的命令：“有敢谏者死无赦！”（谁敢劝我，乱棍打死）。
• 飞鸟之谜： 大臣伍举实在看不下去，便用隐语（谜语）去试探他：“有一只大鸟停在山上，三年不飞也不叫，这是什么鸟？” 熊侣大笑，对出了那句流传千古的名言：“三年不飞，飞将冲天；三年不鸣，鸣将惊人。”
• 雷霆肃清： 随后，另一位大臣苏从冒死再次进谏。熊侣看清了朝中谁是忠臣、谁是奸佞，时机成熟后，他突然“摘下面具”，罢免、诛杀了数百名真正贪腐无能的权臣，重用伍举、苏从，正式亲政。

3. 尊贤改革：荡平内乱与大修内政

真正掌权后，熊侣展现出了极高的政治铁腕与用人智慧：
• 平定若敖氏： 公元前605年，楚国最大的贵族特权阶层“若敖氏”由于势力过大发动叛乱（斗椒之乱），熊侣果断出兵将其彻底剿灭，把军政大权牢牢收回王室手中。
• 任用贤能： 他不计前嫌、打破常规提拔人才，其中最著名的就是一代名相孙叔敖。在孙叔敖的辅佐下，楚国兴修水利（修建了中国最早的期思陂/芍陂）、发展农业、整顿军队，楚国的国力达到了鼎盛。

4. 饮马黄河：问鼎中原与成就霸业

国力强盛后，熊侣开启了向北方中原挺进的霸业扩张：
• 问鼎中原： 公元前606年，熊侣率军讨伐陆浑之戎，直接把军队驻扎在了周天子的洛阳郊外。周天子派使者去慰劳，熊侣却狂妄地询问周朝王权象征的“九鼎”有多重。这便是成语“问鼎中原”的由来，暴露了他企图取周室而代之的宏大野心。
• 邲之战大败晋国： 公元前597年，楚国与北方的超级大国晋国在“邲（bì）之战”中爆发主力决战。熊侣指挥若定，大败晋军，饮马黄河。此战之后，中原的郑国、宋国、鲁国等诸侯纷纷向楚国低头臣服，熊侣正式成为名副其实的中原霸主。

历史评价与结局

公元前591年，一代雄主熊侣因病逝世，谥号为“庄”（即楚庄王）。

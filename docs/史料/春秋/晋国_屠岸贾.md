# 晋国 · 屠岸贾

## 基本信息
- 时代：春秋中期（晋景公时，前 6 世纪）
- 身份：晋国大夫、司寇（掌刑狱），景公宠臣
- 关键事件：借「赵盾弑君」旧案诛灭赵氏满门（赵氏孤儿叙事）
- **史料性质：其事主要见于《史记·赵世家》，《左传》无载**；学界多判《史记》此段采自传说/战国故事 → **标注使用**

## 生平年表（据《史记·赵世家》）
1. **为司寇**：景公时掌刑，与赵氏争权。
2. **翻旧案**：以「赵盾弑灵公」为罪，遍告诸将，欲诛赵氏。
3. **灭族**：与诸将攻赵氏于下宫，杀赵朔、赵同、赵括、赵婴齐，尽灭其族。
4. **搜孤**：赵朔妻（成公姊）有遗腹子，匿于公宫；屠岸贾搜之，程婴、公孙杵臼以他人婴儿代之。
5. **结局**：赵武（孤儿）长成，韩厥言于景公，复赵氏田邑；攻屠岸贾，灭其族（《史记·赵世家》）。

## 主要事迹
- **「赵氏孤儿」的反派**：中国最著名的复仇叙事中的对手方。
- **以法之名行私怨**：借「弑君」旧案灭政敌，是「合法暴力」的早期样本。
- **忠义群像的对照**：程婴、公孙杵臼、韩厥的义，反衬其奸。

## 史料辨析（重点）
- **《左传》无屠岸贾其人**，亦无「下宫之难」的灭族叙述；《左传》所记赵氏之亡是赵同、赵括因「乱」被诛（前 583），与孤儿故事不同。
- 《史记·赵世家》此段被学界广泛认为**采自战国传说**（与《左传》系统冲突），故本工程按「**史记系统·传说采录**」标注使用。
- 《元曲·赵氏孤儿》进一步文学化，与史实距离更远。

## 后世评价
- 文学形象远大于史实形象：戏剧、歌剧（《中国孤儿》）使其成为世界性的「奸臣」符号。
- 史学提醒：越著名的故事，越需要标注其史料层级。

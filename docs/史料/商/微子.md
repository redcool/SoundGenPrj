# 微子（启）

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：商纣之庶兄（一说诸父辈），名启，封于微（今山东微山一带），故称微子
- 后世：宋国始祖；「殷之三仁」之一

## 生平年表
1. **数谏纣**：「微子数谏不听」（《史记·殷本纪》）。
2. **出走**：与太师、少师谋，遂去（《史记·殷本纪》）；《尚书·微子》记其与箕子、比干问答之辞。
3. **克商后归周**：武王克商，微子「持其祭器造于军门，肉袒面缚」，武王释之，复其位（《史记·宋微子世家》）。
4. **封于宋**：武庚叛乱被诛后，周公以微子启代殷后，封于宋，续殷祀，「作《微子之命》」（《史记·宋微子世家》）。
5. **宋国传承**：宋为殷遗民之国，春秋时为十二诸侯之一（宋襄公曾图霸）。

## 主要事迹
- **存殷祀**：以「殷后」身份延续商人的祭祀系统，是周初「存亡继绝」政策的受益者与执行者。
- **三仁之一**：与箕子（为奴）、比干（死谏）并列，代表「去、奴、死」三种选择中的「去」。
- **宋国文化**：宋为殷商文化保留地，孔子先祖即宋人。

## 金文/考古佐证
- 宋国故城（河南商丘）有考古工作；微子本人器物未见。
- 周初「存亡继绝」的分封政策，与微子封宋、武庚续殷（后废）的逻辑一致。

## 传说层辨析
- **「肉袒面缚」**：《史记》叙述，细节可能经加工。
- **微子与纣的亲属关系**：兄/叔父之说并存。

## 后世评价
- 孔子列其为「三仁」之首（《论语·微子》）。
- 后世对「去国」的评价分歧：孟子许其仁，亦有讥其「不能死谏」者。
- 宋国作为殷遗民国家，成为先秦思想文化的重要土壤。

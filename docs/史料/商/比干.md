# 比干

## 基本信息
- 时代：商末（帝辛/纣时，约前 11 世纪）
- 身份：商王室重臣（一说为纣之叔父/诸父）、少师
- 结局：强谏纣王，被剖心而死（《史记·殷本纪》）
- 后世：与关龙逢并称「龙逢比干」，忠谏殉国的双璧；民间奉为「文财神」

## 生平年表
1. **事纣**：为商末重臣，见纣「淫乱不止」。
2. **强谏**：「纣愈淫乱不止。微子数谏不听，乃与大师、少师谋，遂去。比干曰：为人臣者，不得不以死争。乃强谏纣」（《史记·殷本纪》）。
3. **剖心**：纣怒曰「吾闻圣人心有七窍」，遂剖比干，观其心（《史记·殷本纪》）。
4. **身后**：武王克商后「封比干之墓」（《史记·周本纪》）——以褒忠臣收殷民之心。

## 主要事迹
- **死谏**：以「为人臣者不得不以死争」为信念，是中国谏诤传统中最彻底的一例。
- **「七窍玲珑心」**：其死法成为后世文学（《封神演义》）的核心意象。
- **武王表墓**：周初以「封比干之墓」宣示新政权的价值取向。

## 金文/考古佐证
- 比干其人见于《史记》《尚书》等传世文献；其墓（河南卫辉比干庙）为后世纪念性建筑，非商代原墓。
- 殷墟晚期卜辞与青铜器反映纣时政局动荡，可作背景。

## 传说层辨析
- **剖心观窍**：《史记》有载，但细节（七窍）带文学化色彩；先秦文献（《论语》《孟子》）只言「比干谏而死」。
- **「文财神」**：后世民间信仰，与史实无关。
- **《封神演义》的比干**：文学形象（七窍玲珑心、无心菜），属小说层。

## 后世评价
- 孔子：「比干谏而死」（《论语·微子》），与微子、箕子并称「殷有三仁」。
- 与关龙逢并称，成为「忠臣死谏」的原型。
- 武王封其墓，标志周人对「忠」的价值承认——即使忠的对象是敌人。

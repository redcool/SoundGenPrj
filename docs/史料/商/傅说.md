# 傅说

## 基本信息
- 时代：商中期（武丁时，约前 13 世纪）
- 身份：商王武丁之相，与伊尹并称商代两大贤相
- 出身：传说为傅岩之「版筑」工匠（筑墙工）

## 生平年表
1. **武丁求贤**：武丁即位，思复兴殷，「三年不言，政事决定于冢宰，以观国风」（《史记·殷本纪》）。
2. **梦得圣人**：武丁夜梦得圣人，名曰「说」，以梦中所见形貌求之天下，于傅岩得版筑之囚（《史记·殷本纪》）。
3. **举以为相**：武丁与之语，「果圣人」，举以为相，殷国大治（《史记·殷本纪》）。
4. **作《说命》**：《尚书·说命》三篇（古文）记其进言「非知之艰，行之惟艰」——知易行难之论的源头。
5. **武丁中兴**：傅说辅武丁修政、伐鬼方、征土方、羌方，商势复振，史称「武丁中兴」。

## 主要事迹
- **版筑出相**：中国历史上「起于微贱而至卿相」最早、最典型的样本（早于傅说者仅有传说）。
- **知易行难**：其进言成为中国传统政治哲学的常用命题。
- **武丁中兴的核心**：武丁「修政行德，天下咸欢，殷道复兴」，傅说为相功不可没。

## 金文/考古佐证
- 殷墟卜辞中武丁时期征伐与祭祀记录极多，可与「武丁中兴」对读；
- 「傅说」其人未见甲骨直呼其名，但其存在有《尚书》《史记》与武丁中兴背景支撑。

## 传说层辨析
- **梦得圣人**：典型的「天命—梦兆」叙事，属传说层（但可能源于武丁借神道设教的真实政治操作）。
- **《说命》三篇**：古文尚书，晚出，可信度有限；「非知之艰，行之惟艰」的思想价值独立存在。
- **傅岩地望**：今山西平陆一带，有「傅岩」「圣人涧」等地名传承。

## 后世评价
- 与伊尹并称「伊傅」，为贤相代称。
- 「版筑之间出圣人」成为寒门上升的文化母题。

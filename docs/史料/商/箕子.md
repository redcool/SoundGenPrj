# 箕子

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：商王室贵族（纣之诸父/兄弟辈）、太师；「殷之三仁」之一
- 后世：相传为朝鲜半岛箕子朝鲜的开创者（传说层）

## 生平年表
1. **事纣**：为商末重臣，见纣「为象箸」而叹「彼为象箸，必为玉杯」，预见奢靡之祸（《史记·宋微子世家》）。
2. **谏而不听**：屡谏纣，不听。
3. **佯狂为奴**：或曰「箕子惧，乃详狂为奴，纣又囚之」（《史记·殷本纪》）——以佯狂避祸。
4. **武王访问**：克商后，武王「访问箕子」，箕子陈《洪范》九畴（《尚书·洪范》）——中国政治哲学的纲领性文献。
5. **封于朝鲜（传说）**：「武王乃封箕子于朝鲜而不臣也」（《史记·宋微子世家》）——属传说层，学界多认为系后世追述。
6. **《麦秀》之歌**：后朝周，过故殷墟，作《麦秀》之诗，殷民闻之皆流涕（《史记·宋微子世家》）。

## 主要事迹
- **《洪范》九畴**：五行、五事、八政、五纪、皇极、三德、稽疑、庶征、五福六极——中国最早的系统政治哲学框架。
- **佯狂避祸**：与比干（死谏）、微子（出走）构成「殷之三仁」的三种选择。
- **文化输出**：箕子朝鲜的传说，是中华文化东传叙事的源头之一。

## 金文/考古佐证
- 《洪范》文本属《尚书》，其思想框架与周初政治高度契合，但成书年代有争议（多认为西周或更晚整理）。
- 朝鲜半岛「箕子」相关遗迹（平壤箕子陵等）为后世纪念性建构，考古上未证实商遗民建国。

## 传说层辨析（重点）
- **箕子封朝鲜**：《史记》有载，但先秦文献未见；学界多视为战国秦汉间的传说建构，与考古所见朝鲜半岛青铜文化无直接对应。
- **佯狂**：《论语》「箕子为之奴」——事实框架成立，细节为叙述。
- **《麦秀》诗**：或为后人拟作。

## 后世评价
- 孔子：「殷有三仁焉」（微子、箕子、比干，《论语·微子》）。
- 儒家以箕子为「明哲保身」与「以道事君」的平衡典范。
- 在东亚文化圈（朝鲜半岛）被尊为文明始祖之一。

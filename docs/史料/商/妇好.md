# 妇好

## 基本信息
- 时代：商中期（武丁时，约前 13 世纪）
- 身份：商王武丁之配偶（诸妇之一）、女将军、大祭司
- 庙号：妣辛（辛）
- 墓葬：1976 年河南安阳殷墟妇好墓发掘，是唯一未被盗掘的商王室墓葬

## 生平年表
1. **嫁入王室**：妇好为武丁多位配偶之一，地位尊崇。
2. **领兵征伐**：卜辞记载她多次率军出征，最多一次「登妇好三千，登旅万，呼伐羌」——统兵一万三千人（卜辞）。
3. **征土方、羌方、巴方**：与武丁配合，是中国最早有文字记载的女性军事统帅。
4. **主持祭祀**：作为大祭司主持燎祭、侑祭等重大祭典，沟通神人。
5. **受封领地**：拥有自己的封地与属民，需向王室纳贡。
6. **早逝**：先于武丁去世；武丁为其多次举行祭祀，并「配」于先王（冥婚式安排），可见其地位与武丁之痛。

## 主要事迹
- **女性统帅**：中国信史上第一位有明确记载的女将军（早于花木兰等传说人物）。
- **军政祭三合一**：既是王的配偶，又是统帅与祭司，反映商代贵族女性的实际权力。
- **妇好墓**：出土青铜器、玉器、骨器等 1928 件，其中「妇好鸮尊」「司母辛鼎」为国宝。

## 金文/考古佐证（重点）
- **妇好墓**（殷墟五号墓）：墓主身份由青铜器铭文「妇好」「司母辛」确证。
- **甲骨卜辞**：大量记载其征战、祭祀、生育、疾病。
- 墓中随葬兵器（大钺）象征军权。

## 传说层辨析
- 妇好无传说化叙述，其形象完全建立在**甲骨与考古实物**上，是商代历史「信史化」的代表人物。
- 「妇好」之「好」为名（一说为氏），「妇」为身份前缀。

## 后世评价
- 现代史学：商代女性地位与军事参与的关键证据。
- 文化形象：中国「女将军」叙事的真正起点（非文学虚构）。

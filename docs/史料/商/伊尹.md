# 伊尹（名挚）

## 基本信息
- 时代：商初（约前 17—前 16 世纪，历事成汤、外丙、仲壬、太甲数朝）
- 身份：商开国元辅、右相、师仆；被后世尊为「元圣」（与周公并称）
- 氏名：伊氏（一说名挚，字伊尹；又称阿衡、保衡）
- 出身传说：有莘氏陪嫁之媵臣（《史记·殷本纪》）；另说隐于野、汤三聘而至（《孟子》《墨子》系统）

## 生平年表
1. **归汤**：以烹调喻治国（「负鼎俎，以滋味说汤」），汤举以为相（《史记·殷本纪》）。
2. **佐汤灭夏**：为汤谋划，先剪除葛、韦、顾、昆吾等夏之羽翼，再战于鸣条，夏亡（《史记·殷本纪》）。
3. **建商之制**：作《汤誓》前后的政令，定官制、定贡赋，行「宽以治民」（《尚书》诸篇多有依托）。
4. **放太甲于桐宫**：汤崩，外丙、仲壬相继短祚，太甲立而「不明，暴虐，不遵汤法」；伊尹放之于桐宫三年（《史记·殷本纪》）。
5. **迎太甲复位**：太甲悔过自新，「修德，诸侯咸归殷」，伊尹迎之复位，还政（《史记·殷本纪》）。
6. **卒**：一说沃丁时卒，葬于亳；「伊尹卒，沃丁葬之，以天子之礼」（《史记》）。

## 主要事迹
- **开国元辅**：中国历史上第一位被明确记载的「宰相型」人物。
- **放君与复君**：「放太甲」是后世争论千年的政治命题——臣子可否以国家名义约束君主（孟子称「民为贵」的实践样本；后世亦有「伊尹放君」之讥）。
- **治国理念**：「调和五味」的比喻，是中国「治大国若烹小鲜」的思想源头之一。
- **巫史合一**：甲骨卜辞中伊尹常与先王同受祭祀，地位极高。

## 金文/考古佐证
- **甲骨卜辞**：殷墟卜辞有「伊尹」受祭记录（如「侑伊尹」），是伊尹确为商代真实重臣的硬证据。
- 《尚书》中的《伊训》《太甲》诸篇（今文无、古文有）真伪有争议，但伊尹事迹的核心有卜辞支撑。

## 传说层辨析
- **负鼎说汤**：战国诸子（《孟子》《墨子》《吕氏春秋》）皆有敷演，细节不同，属叙事层。
- **「伊尹放太甲」的性质**：传统视为「忠臣摄政」，另有「伊尹篡位、太甲杀之复位」的异说（《竹书纪年》系统），学界并列。
- **寿百岁**：传说数字。

## 后世评价
- 与周公并称「伊周」，为贤相最高典范。
- 孟子以伊尹为「圣之任者也」（《孟子·万章下》）。
- 「伊尹放太甲」成为历代权臣摄政的正当性论据，也是最敏感的禁区。

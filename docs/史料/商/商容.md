# 商容

## 基本信息
- 时代：商末周初（约前 11 世纪）
- 身份：商之贤臣（一说为纣之乐官/礼官）、被纣废黜的直臣
- 关键事件：武王克商后「表商容之闾」——中国最早的「表贤」记录之一

## 生平年表
1. **事纣**：为商之贤臣，以直道事君。
2. **被废**：纣不听其谏，废之（《史记·周本纪》未详，见《韩诗外传》《帝王世纪》等）。
3. **武王表闾**：「释箕子之囚，封比干之墓，表商容之闾」（《史记·周本纪》）——武王克商后，在商容的里门立表表彰，以示新政权的价值取向。
4. **后世**：其名成为「贤者被废而终获表彰」的典故。

## 主要事迹
- **「表闾」**：周初三大褒忠举措之一（释箕子、封比干、表商容），是周人争取殷民人心的政治操作。
- **贤而被废**：商末「贤者不用」的又一例证。

## 金文/考古佐证
- 无直接器物。相关记载主要见《史记·周本纪》《韩诗外传》等。

## 传说层辨析
- **商容的身份**：礼官/乐官/大夫诸说并存，史载简略。
- **「表其闾」的具体形式**：后世注疏有「立表」「筑门」等说，无考古实证。
- **本工程采用**：义名-商-卷1《表闾》为其立曲，主题为「公道会迟到，但有人记得」，不虚构具体事迹。

## 后世评价
- 传统：商末贤臣的代表之一，与箕子、比干并提。
- 政治文化意义：「表闾」开创了「表彰前朝忠贤」的政治传统（后世多有仿效）。

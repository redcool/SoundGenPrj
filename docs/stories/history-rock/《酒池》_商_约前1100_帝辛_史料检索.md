# 《酒池》· 史料检索（开曲必做 · 2026-10-19）

> 检索：simpleMCPServer web.search · 2026-10-19。分层：正史=主诉；辨析层=标注。

1. 身份：纣（帝辛），商末君主；《史记·殷本纪》“帝纣资辨捷疾，闻见甚敏；材力过人，手格猛兽”。
2. 酒池（正史层·太史公笔）：《史记·殷本纪》“以酒为池，县（悬）肉为林，使男女裸相逐其间，为长夜之饮。使师涓作新淫声，北里之舞，靡靡之乐”——并为“大冣乐戏于沙丘”之景。
3. 辨析层（标注不主诉）：后世有“酒池肉林经不起推敲、商亡另有原因”之辩（有文章质疑细节）；成语形态定型于《元史·裕宗传》“肉林酒池”。
4. 关联：《尚书·牧誓》记纣“酗于酒”（当时檄文）；鹿台（搜罗珍宝，牧野败后自焚）。

## 分层结论与立意

- 主诉（正史层）：**长夜之饮、荒政失序**——酒池不是酒，是王朝把耳朵喝没了；
- 辨析层不入词（或轻点“后人说这是假的——可酗酒之训，是真的”作争议收尾可选）；
- 立意：警戒（荒淫误国）；意象：**酒池（一池浊水 / 笑声与民怨的反差）**；
- 歌曲：①《酒池》（本曲）②《酒池》为纣第二首（剖心已产）。

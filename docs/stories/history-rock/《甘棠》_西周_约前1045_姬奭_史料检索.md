# 《甘棠》· 史料检索（开曲必做 · 2026-10-19）

> 检索：simpleMCPServer web.search · 2026-10-19。分层：诗经/史记 = 主诉。

1. 身份：召公奭（姬奭），周文王庶子、武王之臣；封于燕（召公），与周公并称“二公”；甘棠遗爱之主角。
2. 《诗经·召南·甘棠》（原文·三章）：“蔽芾甘棠，勿翦勿伐，召伯所茇。蔽芾甘棠，勿翦勿败，召伯所憩。蔽芾甘棠，勿翦勿拜，召伯所说。”——纯用赋体，颂召伯德政。
3. 《史记·燕召公世家》：“召公之治西方，甚得兆民和。召公巡行乡邑，有棠树，决狱政事其下，自侯伯至庶人各得其所，无失职者。召公卒，而民人思召公之政，怀甘棠不敢伐”——甘棠树下断狱、遗爱（正史铁证）。
4. 孔子/德治语境：召南·甘棠被儒家引为“官民互爱的德治”典范（学理注）。

## 分层结论与立意

- 主诉（正史层）：**一棵树下的公道**——召公在甘棠树下决狱，公侯庶人各得其所；
- 立意：仁政遗爱（鼓励向）；核心=**仁政（公道不必在堂上，一棵树下也行）**；意象=**甘棠树（勿翦勿伐）**；
- 风格策略：民谣骨+电子肉（录曲风偏好实证）；
- 歌曲：《甘棠》（西周卷1 #5，姬奭）。

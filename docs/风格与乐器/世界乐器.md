世界乐器通常按照发声原理分为四大类，即国际通用的“萨克斯-霍恩博斯特尔分类法”（Hornbostel-Sachs system），涵盖了全球各地独特的传统与现代乐器。
以下用中文为您系统讲解世界乐器的核心分类与代表性乐器：

1. 弦鸣乐器（Chordophones）

依靠张紧的琴弦振动发声，通过手指拨动、琴弓摩擦或敲击来演奏。
• 东亚代表：
	• 中国古筝 / 古琴： 古筝音色清亮华丽，常用指套弹奏；古琴音色深沉内敛，是文人雅士的传统乐器。
	• 日本三味线（Shamisen）： 三根弦的拨弦乐器，琴身蒙有皮膜，音色清脆带有打击感，常用于歌舞伎伴奏。
• 南亚与中东代表：
	• 印度西塔琴（Sitar）： 拥有主奏弦和大量共鸣弦，音色空灵迷幻，具有极强的滑音表现力。
	• 中东乌德琴（Oud）： 梨形琴身、无品格的短颈拨弦乐器，被誉为“中东乐器之王”，也是欧洲鲁特琴的前身。
• 欧美代表：
	• 小提琴 / 吉他： 现代西方音乐的核心弦乐器，小提琴属于擦弦乐器，吉他属于拨弦乐器。

2. 气鸣乐器（Aerophones）

依靠乐器内部的空气柱振动发声，通常通过吹气或风箱鼓风来演奏。
• 东亚代表：
	• 中国竹笛 / 笙： 竹笛依靠笛膜产生清脆明亮的音色；笙是少数能吹奏和声的簧管乐器。
	• 日本尺八（Shakuhachi）： 竹制竖吹乐器，音色苍凉、富有禅意，常能吹出模拟自然风声的音效。
• 美洲与大洋洲代表：
	• 南美排箫（Panpipes / Zampoña）： 由多根长短不一的竹管或芦苇管捆绑而成，音色空灵纯净，充满安第斯山脉风情。
	• 澳洲迪吉里杜管（Didgeridoo）： 澳大利亚原住民使用白蚁蛀空的桉树干制成的管乐器，演奏时需运用“循环呼吸法”，发出低沉连续的嗡鸣声。
• 欧洲代表：
	• 苏格兰风笛（Bagpipes）： 依靠皮囊储存空气并挤压吹奏，音色高亢嘹亮，具有强烈的民族仪式感。

3. 膜鸣乐器（Membranophones）

依靠绷紧在共鸣腔上的动物皮或合成薄膜振动发声，即各类鼓乐器。
• 非洲与拉美代表：
	• 非洲金贝鼓（Djembe）： 源自西非的高脚杯形手鼓，能敲出低、中、高三种截然不同的音色，节奏感染力极强。
	• 拉丁康加鼓（Conga）： 狭长桶状手鼓，是萨尔萨（Salsa）和拉丁爵士乐的灵魂。
• 亚洲代表：
	• 印度塔布拉鼓（Tabla）： 由一大一小两个鼓组成，鼓面中央涂有特殊黑膏，能敲出丰富且带有音高变化的复杂节奏。
	• 日本和太鼓（Taiko）： 体型庞大，用粗木棒击打，声音震撼有力，常用于祭典和大型舞台表演。

4. 体鸣乐器（Idiophones）

不依赖弦、膜或空气柱，直接依靠乐器本身的材质振动发声，包括敲击、摇晃、刮擦等。
• 非洲代表：
	• 卡林巴琴（Kalimba / 拇指琴）： 木盒上装有长短不一的金属弹片，用拇指拨动，音色清脆灵动，宛如八音盒。
• 东南亚代表：
	• 印尼甘美兰（Gamelan）： 这是一套以金属敲击乐器（如金属琴、锣）为主的合奏乐团，音色金碧辉煌，具有独特的律动和音阶体系。
• 现代与拉美代表：
	• 瑞士手碟（Handpan）： 21世纪初发明的金属打击乐器，外形像飞碟，用手拍击即可发出空灵疗愈的和声。
	• 加勒比钢鼓（Steelpan）： 起源于特立尼达和多巴哥，用废旧油桶底部敲击出凹槽制成，音色欢快明亮，充满热带海岛风情。

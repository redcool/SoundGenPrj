## 二、专辑描述（喜马拉雅简介，约 200-300 字）

### 版本 A（意境向）
> 关掉灯。戴上耳机。星海在头顶铺开。
>
> 这是一张关于"神秘"的专辑——关于我们为何仰望，关于时间如何流动，关于生命在宇宙中的一次闪烁。合成器的低频像深空的心跳，钢琴的颗粒像漂浮的尘埃，层层音景从耳畔铺向无穷远。
>
> 从大爆炸的轰鸣余响，到星云缓慢的旋转；从时间的褶皱，到一粒原子里的宇宙。十一段旅程，十一段冥想：探索者，请坐稳，我们出发。
>
> 适合：睡前 / 冥想 / 深度思考 / 写作阅读 / 独自放空。让星海漫过你，再慢慢沉下去。

### 版本 B（功能向）
> 神秘宇宙主题氛围音乐，为"入睡、冥想、专注"而生。
>
> 中慢速、低声压、无突刺音色：合成器氛围垫底 + 钢琴/弦乐/人声采样点缀，音景由远及近再远去，模拟"潜入深空"的听觉曲线。
>
> 失眠？焦虑？思绪停不下来？让思维的转速降下来，跟着星海的节奏呼吸。
>
> 每首 5-10 分钟，动态平缓，可整夜循环；也适合冥想、瑜伽、阅读、写代码时的背景宇宙。

### 版本 C（短版摘要）
> 星海漫游指南：时空与生命的冥想音景。深空低频、星云般的音色、时间的褶皱。从大爆炸到一粒尘埃，戴上耳机，在群星之间漂流。神秘、宁静、无限。

## 三、卖点（专辑页卖点区 / 图文卡）

1. **宏大主题**：空间/时间/生命三合一宇宙叙事，超出"白噪音"的层次感
2. **音景设计**：由远及近再远去的"潜入深空"听觉曲线，非单调循环垫乐
3. **多场景适用**：入睡 / 冥想 / 专注 / 阅读 / 放空，一专多用
4. **神秘叙事感**：每首一个宇宙意象（星云、黑洞、时间、生命起源），故事性拉满
5. **动态平缓低刺激**：无突发高频，助眠友好，可整夜循环
6. **原创配乐**：可作视频/直播/冥想课程的授权背景乐

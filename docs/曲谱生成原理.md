# 曲谱生成原理

> 适用：YuE2（`cot=full`）产出的 `score.abc` → abcjs 渲染的一页曲谱（`tools/abc-render`）。

## 0. 一句话

`score.abc` 是一份**文本乐谱语言**（像代码），abcjs 把它**解析 → 排版 → 画成 SVG 五线谱**，同一份数据再走 **MIDI 事件 → Web Audio** 播放；YuE2 生成时模型先规划这份谱，再以谱为剧本生成音频——**看到的谱 = 音频的依据**。

## 1. ABC 文本：乐谱的"源代码"

ABC 是纯文本记号，信息全部在字符串里：

```
X:1           编号          T:             标题
M:4/4         拍号          L:1/16         最小音符单位
Q:1/4=145     速度(BPM)     V: Vocal ...   声部定义
K:D#m         调号
"D#m"C2G2A2   和弦(引号内) + 音符
z/Z           休止符        |              小节线
% verse       注释/段落标记
```

- 音符：字母唱名（A-G）+ 逗号/撇号定八度；**数字后缀定时值**（按 `L:` 基准换算）
- 多声部：每个 `V:` 是一行独立旋律（本项目 Vocal=主唱 / Ins=伴奏织体），小节线处对齐
- 和弦符号写在 Vocal 声部行内，用引号包裹（YuE2 的约定）

## 2. 解析引擎：文本 → 音乐事件流

- **词法/语 legal 分析**：逐字符解析出音符、时值、和弦、休止、小节线、注释
- **音高计算**：字母 + 升降号 + 八度 → MIDI 音高数
- **时值计算**：按 `L:1/16` 把数字后缀换算成拍数
- **小节校验**：按 `M:4/4` 把事件切成小节；每小节时值必须恰等于拍号（不齐 → 报错，`abc_tools.py inspect` 的职责）
- **输出结构**：`tune/visualObj` 对象——行(lines)→小节(bars)→音符(notes) 层级 + 元信息（标题/调号/速度/拍号）

## 3. 排版引擎：算坐标

纯数学布局：

- **分行**：每行放几小节、按页面宽度换行（`responsive: resize` 响应式）
- **坐标**：每个音符的 x（横向节拍位）、y（谱表五行线位置）
- **画图参数**：符干朝上/朝下、符尾是否连成一束（beaming）、临时升降记号、连音线(tie/ slur)、和弦纵向排布
- 产出"画图指令"（absolute elements：线/椭圆/文本）

## 4. SVG 渲染：矢量五线谱

- `ABCJS.renderAbc(el, abc, { add_classes: true, ... })` 把排版指令逐元素画成 `<svg>`
- 元素：谱线、符头（椭圆）、符干/符尾（线）、拍号/调号（文本）、和弦标记、段落注释
- **矢量图**：浏览器缩放无锯齿，打印成 PDF 无损
- `add_classes: true` 额外给每个音符加类名（如 `.abcjs-note`）——播放高亮的基础

## 5. 播放管线：同一份数据，另一个出口

1. 解析结果 → **MIDI 事件**（音高/时长/力度/乐器 program 号），按时间轴排序
2. `SynthController` 调度：`TimingCallbacks` 按 BPM 逐拍/逐音符触发回调
3. **Web Audio API** 实时合成试听（音色库默认网络 soundfont，可离线内置）
4. **播放高亮**：`cursorControl.onEvent` 在每只发声音符触发时，给对应 SVG 音符加 `playing` 类 → CSS 橙色高亮随旋律推进

## 6. 与 YuE2 生成的关系

- `cot=full`：模型先规划**乐谱（ABC）**，再以乐谱为条件生成语义音频 → 谱与声同源
- 改和声 = 改 ABC 和弦/声部（技能 `abc_tools.py` 校验），重生成
- 本工具只是把模型自己写的谱**可视化 + 可听**，不含任何生成能力

## 7. 常见坑

- 打印空白页/末行裁半：abcjs 给 SVG 写内联固定 `height`——打印与长谱会被裁；修复：渲染后清除内联尺寸、让高度由 viewBox 比例决定（`fixSvg()`，见 `tools/abc-render/template.html`）
- 和弦标记必须是 abc_tools 白名单（`m/aug/sus2/sus4/7/maj7...`），扩展写法会校验失败
- 谱面不改声部名：`abc_tools` 硬校验 Vocal/Ins 原生定义

## 8. 小节编号（与标准谱一致）

**方法**：渲染时自动向 ABC 注入 `%%barNumbers 1`（每小节标号；不修改 YuE 源谱文件）。
abcjs 解析该指令后在对应小节上方绘制 `.abcjs-bar-number` 文本元素（谱面显示 1,2,3…），小节线为 `.abcjs-bar`。注入点：K: 行之后。若需每 N 小节标一次改 `%%barNumbers N` 即可。
（实现在 tools/abc-render/render_sheet.mjs）
